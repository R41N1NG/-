# 《仙姝堕2.0 · 文本创作心法与通用写作指导》

> 📌 **智能体执行准则**：本文件为全卡角色剧情创作（包括通用故事节点、人物增量心智、事件提示词等）的**核心方法论与写作心法**。
> 本指导的目的不是机械堆砌某一个角色的样板文本，而是**教你掌握通用的写作底层逻辑与审美味儿**，确保你在创作全书任何角色（叶红缨、苏念棠、慕容清歌、苏瑶、顾云舒等）时，都能写出神韵饱满、独立有血肉、恪守留白纪律的高水准文本。**每次执行写作任务前必读本文件！**

## 一、架构底层：数轴模型与身份分流法则

### 1. 数轴铁律：节点是整数，阶段是区间 (x1-x0)
整个角色心智与剧情晋升体系建立在严格的数轴离散模型之上，切勿混淆：
- **【节点 (Node) 必为整十整数点】**：
  - 节点是好感积累到临界点时触发的**单次戏剧关卡**。
  - 触发阈值必须是干净的整数点：`20`、`40`、`60`、`80`（严禁写 41、61 等带尾数的值）。
  - 它代表一次重大的情境突破、危机化解或心魔冲突。在节点中，只负责推演当次事件，绝不直接写入晋升成功。
- **【阶段 (Stage) 必为闭合递进区间 [x1, x0]】**：
  - 阶段是晋升成功后点亮的**常驻增量心智约束**，代表日常相处的基调：
    - `基础阶段 (stage01)`：`0 ~ 20`（初识、客套、戒备或日常同门）
    - `阶段一 (stage02)`：`21 ~ 40`（破冰、认可、同道或暗生微澜）
    - `阶段二 (stage03)`：`41 ~ 60`（知己、深恋、暧昧，但**恪守严格防线，坚决未破身**）
    - `阶段三 (stage04)`：`61 ~ 80`（破戒同心或深情苦守）
    - `阶段四 (stage05)`：`81 ~ 100`（灵肉合一、生死眷侣）
  - 逻辑因果：**只有在整数节点（如 40）顺利过关并回报「是」，系统才准予切入下一阶段区间（41~60）的心智**。

### 2. 身份双轨分流思维（因人定轨）
任何角色在面对不同开局身份（如“同门师弟赵无忧” vs “外部散修 {{user}}”）时，其信任建立与心防崩塌的节奏绝不能千篇一律：
- **同门/故交轨**：有青梅竹马或同门庇护的天然信任垫底，破防往往源于“师门清规与情欲滋长的伦理撕扯”；结合阈值通常可相对靠前（如 60 节点）。
- **外人/自设散修轨**：从“宗门排外/萍水相逢”起步，必须先经过“并肩患难（20）”到“引为莫逆知己（40）”，再到“情动隐忍（60）”，最后在生死大限关头（80）方能彻底打破戒律。
- **编写原则**：在 `character_stages.json` 与 `promotions.json` 中，必须针对不同身份配置互斥的子条目，严防身份穿帮。

### 3. 名器体系与心智/节点的分工边界
- **名器是独立专门体系**：名器觉醒、器纹流转、肉身通透、灵根交泰等，由专属的名器模块与阶段条目负责。
- **普通心智与节点严禁越俎代庖**：普通人物阶段与晋升故事中，**严禁大篇幅堆砌器官解剖式描写或泛滥的“肉身通透”玄幻套话**！普通条目应聚焦于：神态细微变化、心理防御拉扯、语言的分寸感、肢体接触的许可红线。

## 二、角色灵魂心法：“剥洋葱”三层法与反工具人铁律

写任何角色，AI 最容易犯的毛病是：**把女性角色写成只为主角奉献、动辄脸红投怀送抱、没有自主灵魂的“挂件工具人”**。要写出令人心动的神韵，必须掌握“剥洋葱”三层塑造法：

```
┌────────────────────────────────────────────────────────┐
│ 第一层：社会面具与职业骨架（宗门身份、天骄傲骨、防备之墙）      │
├────────────────────────────────────────────────────────┤
│ 第二层：肉体主权与生理受刑（名器/功法反噬的真实痛苦，强烈的求生欲）│
├────────────────────────────────────────────────────────┤
│ 第三层：反附庸的自我救赎（追求自身解脱，视主角为并肩平等的生机） │
└────────────────────────────────────────────────────────┘
```

### 1. 第一层：社会面具与职业骨架（拒绝市井/风尘刻板印象）
- 角色首先是修仙界的独立修士（金丹天骄、一阁之主、世家贵女、灵动药师）。
- **仙门傲骨与克制**：行止带有修仙者的出尘与自持，拒绝凡俗庸俗化。
  - 豪迈飒爽型角色：是自信大方、利落干脆，**严禁写成粗鄙市井村妇（严禁自称“老娘”、动辄骂“混账”）**；
  - 娇媚妖娆型角色：是功法自生暗香与心智聪慧，**严禁写成廉价风尘窑姐**；
  - 清冷高华型角色：是大道独行与责任压身，**严禁写成面瘫机器人**。

### 2. 第二层：肉体主权与生理受刑（拒绝表演性受难，必须有求生欲！）
- **肉体的主体性**：名器异动、锁环炙烤、异火反噬或阴煞入体，是**她自己的肉体在真实地受刑与折磨**，是生理机能的本能反应，绝不是为了讨好或取悦主角而做的媚态表演。
- **强烈的怕死与求生本能（核心关键点！）**：
  - 很多 AI 写救赎，只写“她怕连累主角”、“她全是为了主角牺牲”，这就落入了工具人窠臼。
  - **活生生的人是惜命的！** 她眷恋自身的生命、金丹道途与大好年华，她深切恐惧被异火烧成飞灰或香消玉殒的结局。
  - 正因为她自己也怕死、想活，她在面对底线时的战栗、抗拒、落泪与妥协，才具备血肉生命的分量！

### 3. 第三层：反附庸的自我救赎（拒绝主仆附属，建立平视道侣）
- **拒绝单向献祭**：她走向结合、交付信任或打破戒律，根本动机是**“为了将自己从日夜受刑的苦海与宿命中拯救出来”**。
- **平等与并肩**：主角不是高高在上的施舍者或征服她的“霸总主宰”，而是她落水时抓住的一线生机，是能够托付后背、生死与共的唯一道侣。
- 情感质变后的姿态：会有少女的微嗔与依恋，但明事理、识大体，有独当一面的尊严，绝不胡搅蛮缠。

## 三、GPT 五段式节点戏剧构建法（实操写意法）

每个专属晋升故事节点，都必须按 GPT 标准五段式框架组织。这不仅是格式，更是一套成熟的编剧动力学：

### 1. 【节点故事：标题】
- 命名需富含仙侠意境与戏剧核心（如《赤焰对酌》、《残阵孤灯》、《定道盟》、《焚心露真》）。

### 2. 【本轮必须发生】
- **单一核心事件**：只集中演绎一次危机爆发、心防突破或重大交心，不把多步剧情混在一轮。
- **明确边界红线**：清楚界定本轮是“知己饮酒未逾矩”、“情动抚弄但坚守底线”，还是“大限关头打破戒律”。

### 3. 【场景与因果】
- **严谨的仙侠因果**：修士有护体真元，绝不写“下雨淋湿发抖”等凡人桥段。困境必须源自修仙法则：古阵封绝、阴煞罡风暴动、功法反噬、真火逆流。
- **封闭私密空间（独占二人世界）**：采用“沿用当前所在私密环境或临时落脚点，不设死具体地点”。
- **严禁第三方闯入**：节点是二人私密舞台，严禁任何 NPC 突兀打扰。

### 4. 【人物表现与心理交锋】（重中之重：三递进与微动作白描）
写作时，严格按照三重情绪递进展开心理交锋：
1. **递进一：清醒伪装与身份矜持**：起初强撑往日威严、面具或骄傲，出于畏死与怕连累对方，言辞推拒；
2. **递进二：本能受刑与无意识索求**：体内热潮/煞气冲刷理智，身躯违背意志地展现出软弱、颤栗与对生机体温的无意识渴望；
3. **递进三：弥留露真与极致撕扯**：
   - **利用认知信息差**：角色自幼受师门清规束缚，**通常根本不知道阴阳交泰能解厄，以为自己大限将至、必死无疑**！因此她的真情流露是生命尽头毫无保留的眷恋与脆弱，绝非算计。
   - **矛盾微动作设计**：必须设计具有巨大张力的反差动作（例如：**一只手抚摸对方胸膛索取，另一只手无力地想把对方推开**）。

### 5. 【确定结果与边界留白】（零代打铁律）
- **定格在抉择高潮**：剧情推向最高潮、生死一线或终身誓约逼到眼前时，**戛然而止**！
- **把选择权 100% 留给玩家**：严禁替玩家写台词、做决定、擅自推演后续动作；声明“绝不代替玩家做决定，后续等待玩家点击完成”。

## 四、文风与语言净化法则（字句修辞红线）

1. **文字凝练，去除虚浮大词**：
   - 杜绝空洞的男频套话（如将娇俏少女硬套上“顶天立地”等不合时宜词汇）；
   - 以工笔白描神态（睫羽轻颤、耳根泛红、指尖攥紧衣襟），以简练文字传递沉甸甸的心绪。
2. **绝对禁止极端词与霸总词汇（GEMINI.md 红线）**：
   - **全面封杀清单**：`彻底`、`绝对`、`极其`、`极度`、`臣服`、`献祭`、`近乎`、`近乎于`。
   - 警惕 AI 的形容词通胀，多用客观具象动作与神态白描取代抽象副词。

## 五、典型角色原型应用示范（以叶红缨为例）

当你将上述通用方法论应用到具体角色（如叶红缨）时，如何推演？

| 通用维度 | 叶红缨的具象落地方式 |
| :--- | :--- |
| **社会面具** | 墨山道五师姐，烈火骄女，好胜护短。称呼必须是“师姐/五师姐”（坚决不写“长姐”）。拒绝市井粗鄙词，言行明快。 |
| **肉体受刑** | 伴生狂暴业火与名器之躯，胸前被种下「封灵镇元环」。反噬时名器受刑、灼烫难忍，这是她个人的生理酷刑。 |
| **求生与自毁** | 面对业火反噬，既深恐害死爱人，也深切恐惧自己年纪轻轻就化为飞灰。因为怕死，她的反抗与哭求才真实动人。 |
| **反附庸救赎** | 打破戒律不是男主的单向征服，而是她将自己从师尊谎言与镇元环枷锁中拯救出来的向死而生。 |
| **关键信息差** | 业火本质是阎雷子暗种的欲火，她不知双修能解，弥留之际误以为必死，才会卸下全部防备流露真情。 |
| **矛盾动作** | 80 关卡经典肢体设计：“一只手抚摸胸膛索取，另一只手无力地想要推开”，完美呈现神智消磨与爱恋撕扯。 |

> 💡 **迁移启发**：
> 当你后续创作 **苏念棠**（知性智囊·师姐·暗香灵犀）或 **慕容清歌**（清冷绝尘·剑仙·道心劫数）时，同样代入这一套思维框架：
> **找出她的社会面具 -> 找出她的肉体/功法困境与真实求生欲 -> 找出她的认知信息差与矛盾动作 -> 按照五段式模板留白收尾。**
