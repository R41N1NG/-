## 插件注册与生命周期

核心在父页面暴露 `window.XSD2`。后加载的插件调用：

```js
const unregister = window.parent.XSD2.registerPlugin(plugin);
```

先加载的插件可放入父页面 `XSD2_PLUGINS` 数组。核心启动会读取数组。

```js
const plugin = {
  id: 'youjigu_map',
  select(snapshot, nodeId) { /* 返回受信任节点配置，不能返回Promise */ },
  async settle(snapshot, pending, body) { /* 返回本楼结算结果 */ },
  getPrompt(snapshot) { /* 可选：自由行动期间的当前场景约束 */ },
  mount(slotElement, runtimeApi) { /* 返回 unmount() */ }
};
```

HUD保留 `data-xsd-slot="map"`。mount必须使用 `slotElement.ownerDocument` 创建节点，不能把脚本iframe的document当成宿主document。每次HUD重绘会卸载旧挂载再装配；卸载必须取消订阅、移除地图浮层与监听器。注册插件返回的unregister移除插件和挂载。

地图打开只显示地图、圆点和短地点名，不恢复行程列表、身份下拉、额外“深入”按钮或技术说明。没有底图素材时应在开发交接中标明，不能私自用另一张图替换。

## 权威快照与通知

`runtimeApi.getSnapshot()`同步返回深拷贝；未选择身份或正在换聊天时返回null：

```js
{
  chatId, branchId, floor, revision,
  identity, calendarDate: { year, month, day },
  storyCount, inventory, known, relics,
  stat_data, pluginState, activeEvent, pending, manual, receipts
}
```

- 世界日期只用calendarDate整数日；仙盟历浮点值仅为旧世界书门禁的兼容投影。
- storyCount是已完成的助手叙事轮次；不能用原生消息楼号差计算TTL（用户消息也占楼）。
- pluginState[id]是插件状态的唯一恢复来源；不可用UI本地副本作为第二账本。
- subscribe(fn)返回取消订阅函数。通知名为 `floor_advance`、`branch_change`、`rollback`、`gm_override`、`pending`、`identity_change`、`initialize`、`plugin_registered`、`identity_menu`，均含snapshot。没有 `ASSISTANT_REPLY`、`ACTION_CONFIRMED` 或任意 `STATE_UPDATE`。
- 数据存原生消息候选变量 `stat_data.xsd2[0]`，完整正文轨迹校验后才能恢复；聊天stat_data只是给世界书使用的投影，不能当存档权威。复制分支以复制的消息快照为基准，不从上一聊天的内存拿状态。

## 点击与配置校验

```js
const s = runtimeApi.getSnapshot();
await runtimeApi.dispatchIntent({
  type: 'SELECT_NODE', pluginId: 'youjigu_map',
  expected: { chatId:s.chatId, branchId:s.branchId, floor:s.floor, revision:s.revision },
  payload: { nodeId:'cave' }
});
```

只允许UI提交节点ID与当前令牌。行动文案、奖励、期限、前置条件由已注册插件的select返回，不信任payload同名字段：

```js
{
  id:'cave', allowed:true, actionText:'进入洞府', prompt:'只演绎进入洞府，不提前打开机关。',
  identities:['赵无忧'], // 可选；身份名单由具体事件配置决定，框架不默认限制某个身份
  open:{year:1578,month:3,day:1}, close:{year:1578,month:4,day:30}, // 可选
  requires:['map_youjigu'], // 可选
  ttl:3, openedAt:10, // 可选：按storyCount计算；两者须为整数
  reservedState:{}, // 可选：仅预留状态，不授予奖励、不确认到达
  rewards:['草药'], grantsKnown:['map_youjigu'], // 当前节点可授予的白名单
  exitDays:2, confirmText:'确定离开幽寂谷？' // 仅结束节点配置；正常2日，提前1日
}
```

框架执行：校验→退出确认（取消不写）→保存pending和before→填入原生输入栏→点击原生发送。无需玩家再手动发送。进入节点只登记待执行，助手完整回复完成后才授予奖励、确认地点和开放后续节点。停止、取消及发送失败撤回预留状态。

## 助手结果结算

settle由核心调用，仅拿到对应新用户行动及最新助手完整回复。插件不得自行订阅正文再直接发奖或写变量。

```js
{
  outcome:'success', // success | failure | retry
  pluginState:{},
  activeEvent:{id:'youjigu', pluginId:'youjigu_map', step:'cave', place:'幽寂谷·洞府'},
  rewards:[{name:'草药',count:1}], known:['map_youjigu'],
  elapsedDays:2, // 只能等于pending.selection.exitDays；普通探索省略
  body:'...' // 可选：有依据的正文规范化；不能虚构原正文没有的取得事实
}
```

失败/重试也要返回可恢复的pluginState，清除pending让玩家重新选择；不得永久禁用地图。activeEvent结束返回null。框架只提交success的白名单奖励、事实和退出耗时，按回执ID幂等结算。

证据要求：回执标签是辅助，不可越过正文实证。取得物品须确认玩家取得；否定、未发生、旁观他人取得不能放行。无奖励的移动节点也须核验真实到达，不能让空正文或“没有进入”自动成功。地图指引内容及名称须来自当前配置，铁匣不等于地图。

## 保留的业务行为

六套源开局及其独立时点、19个核心XML字段、17个HUD槽位、三组默认折叠、纳戒进出与点击使用、在场关系微卡、立绘大图和缺图降级、13名器阶段规则、GM人工优先及回锁、撤回/候选/分支恢复均继续保留。普通对话的明确历时支持日/夜/时辰/小时，按分钟累计到整数日；“距启程7日”之类倒计时不计为本轮耗时。地图期间由事件出口统一结算，防止双重推进。

GM意图：GM_PATCH白名单为identity、calendarDate、inventory、段位、known.<字段>、owner.<名器ID>、relicStage.<名器ID>。relicStage为0—4且压过归属兜底。GM_RELEASE只释放人工标记，让后续自动规则接管，不倒推重算历史；CANCEL_PENDING取消本次待执行。日期被GM固定时须先交还自动才能结算事件退出。
