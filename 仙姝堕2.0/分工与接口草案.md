## 二、 核心通信接口规范草案

### 1. HUD 插件挂载插槽（DOM 契约）
HUD 状态栏在适当位置（如顶部次栏或菜单栏）渲染一个标准插槽容器：
```html
<div class="xsd-slot-container" data-xsd-slot="map">
  <!-- 地图插件挂载于此，内部可渲染轻量按钮或弹出地图浮层 -->
</div>
```
- **生命周期规范**：
  插件导出一个标准装配接口：
  ```javascript
  export function mount(slotElement, runtimeApi) {
    // 渲染地图入口按钮与轻量 DOM
    // 监听与订阅事件
    return function unmount() {
      // 必须彻底清理 DOM、定时器与事件监听器，防止切卡内存泄漏
    };
  }
  ```

### 2. 运行时 API 规范（Runtime API · 纯单向通信）
严禁任何插件直接读写全局 `window.stat_data` 或私自维护第二套世界时钟。所有与游戏状态交互的行为必须经由 `runtimeApi`：

#### A. 读取权威快照 (`getSnapshot`)
```javascript
const snapshot = runtimeApi.getSnapshot();
// 返回值（深拷贝或只读对象）：
// {
//   chatId: '...',
//   branchId: '...',
//   floor: 18,
//   identity: '赵无忧',
//   calendarDate: { year: 1578, month: 3, day: 3 }, // 世界时钟
//   inventory: [...],
//   known: { ... },
//   activeEvent: { id: 'youjigu', step: 'valley_fork', pending: true },
//   relics: { ... }
// }
```

#### B. 状态与生命周期订阅 (`subscribe`)
```javascript
const unsubscribe = runtimeApi.subscribe((event) => {
  // event.type: 'floor_advance' | 'branch_change' | 'rollback' | 'gm_override'
  // 地图插件据此刷新 UI 或重算 TTL
});
```

#### C. 提交行动意图 (`dispatchIntent`)
```javascript
runtimeApi.dispatchIntent({
  pluginId: 'youjigu_map',
  type: 'SELECT_NODE',
  payload: {
    nodeId: 'cave',
    actionText: '进入洞府探查', // 填入输入框的自然语言
    ttl: 3,
    requires: []
  }
});
```
- **Dispatcher 校验规则**：
  1. 校验当前是否处于合法探索窗口（仙盟历 1578.3 - 1578.4）；
  2. 校验前置门禁（若选密室，检查 `known.map_youjigu`）；
  3. 注册 `pending` 状态，将单步探索指示注入 Prompt 扩展；
  4. 待玩家发送并在最新模型故事中捕获确认后，由统一生命周期统一提交结算。

## 三、 第一条可玩路线的交付标准

双方协同先打通首条闭环链路：
1. **开局**：0楼选择身份（如赵无忧），世界书物理开启【身份】赵无忧；
2. **看盘**：状态栏 HUD 渲染水墨面板，显示 17 个槽位与图链立绘；
3. **开图**：点击 HUD 插槽中的【地图】，展开南疆底图与幽寂谷节点；
4. **探险**：点击进入幽寂谷 $\to$ 输入框自动填入自然语言 $\to$ 发送后模型生成正文描写与回执 $\to$ 获得草药或地图钥匙写入纳戒；
5. **退场**：确认离开幽寂谷 $\to$ 正确结算推进天数 $\to$ 存档/刷新/回退均能准确恢复。
