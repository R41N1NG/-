# v75：修为面板独立显示已确认归属

基于 v74 修改，保留原有一键修复与备份功能。诊断版本应为 `2.0-framework.75`。

境界与突破面板新增“已确认归属”清单，显示归属玩家的全部名器、归属姓名和当前阶段。一阶、二阶及未确认阶段的已归属记录也会显示，不再只能通过三阶突破资格栏间接查看归属。逐项条件详情也直接显示归属姓名和阶段。

本次诊断中的归属数据已经保存，且归属玩家判定为真；原面板没有独立的全部归属列表，造成误解。新增清单不改变突破资格：三阶条件只计第三阶段及以上，其他路线仍校验其各项必要记录。不会从归属推断其他事件或执行者，也不会修改玩家已保存的事实。

新增回归覆盖自设姓名、一阶归属、GM状态标记与执行者记录分别判断、刷新恢复、他人归属和文本转义。验证使用模拟酒馆与DOM，真实酒馆实例仍需导入验收。

验证结果：290 项源码/模拟宿主测试与13项成品集成检查，共303项通过。PNG为7,935,569字节。
