# 正文范围模板

共享函数：[buildNarrativeScope](../src/runtime/narrative_scope.js)。输入：

```js
{place:"当前场景",cast:["在场人物"],facts:["已确认事实"],
 options:[{label:"行动名",description:"当前可见路线描述"}]}
```

场景、事实和可见选项由插件根据后台动态生成，不把整个事件树或所有未来奖励注入模型。

约束：正文与状态栏地点/目标一致；不擅自新增改变路线的来客；不代选路线；不提前开机关；不反复邀请已关闭或过期分支；不改写已入账奖励；不向玩家输出节点代码和阶段ID。

允许自然环境描写、交谈及同义表达。幽寂谷地图可称地图/残图/残卷，不要求逐字拟合。正文约束是提示，不保证模型每次遵守；后台仍以合法选择为准。
