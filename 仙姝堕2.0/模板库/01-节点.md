# 节点模板

实际配置为JavaScript对象，目前在[事件树](../src/plugins/youjigu_map/event_tree.js)。插件select把配置提交中控，settle承接回复完成。

```js
节点ID: {
  id:"节点ID", label:"玩家显示名称", actionText:"行动自然语言含义",
  prompt:"本轮必须发生的事与演绎边界",
  from:"前置场景", to:"目标场景",
  // 以下按需添加，不填写则不启用该限制/效果
  identities:["赵无忧"],
  open:{year:1578,month:3,day:1}, close:{year:1578,month:4,day:30},
  ttl:3, requires:["已注册known键"], conditions:[],
  group:"互斥组ID",
  reward:"物品名", rewards:["物品名"], grantsKnown:["已注册known键"],
  metricChanges:[{character:"已注册人物",key:"好感",delta:1}],
  summaryNote:"后台记录本次经历",
  completesExploration:true,
  settlement:{mode:"none"}
}
```

样例不能直接当新节点运行：须把节点加入插件场景/坐标和配套故事配置，确认奖励与known在白名单里。数值变化是格式展示，不是正式+1规则；超出已配置范围会拒绝本次行动，不静默截断。

固定奖励及互斥按合法点选同一快照入账，回复不重复发奖；停止/删楼根据before恢复。移动子节点在成功故事回复完成后开放，不能靠反复点击提前进入深处。

终点可配置finish或early、exitDays、confirmText。幽寂谷正常出口和密室出口2日、早退1日；确认后先推进后台日期再发送。离开洞府/山涧只是内部导航，直接进入谷中岔路，不额外点“深入”。

settlement.mode支持none/inline/separate。普通节点默认none；三个整段退出节点配置separate。不得把每个子节点都设成结算。

持续背景与区域归属的已认可后续方向见[11](11-持续背景与场景判定.md)，尚未接入当前节点配置。

## 晋升流程的适用边界

上述from/to及点选即确定结果是现有普通探索节点约定，不能无差别套用晋升流程。独立专属晋升不要求先到目的地；入口开启邀请引导，完成终点才提交阶段。可嵌入型保留原探索状态，见[12](12-晋升节点与引导流程.md)。两个新类型尚未作为运行字段接入。
