# 节点故事条目模板

真源：[node_stories.json](../src/config/node_stories.json)。现有17个幽寂谷节点均有条目；当前内容来自已确认节点提示和公共边界，并非已经填完详细故事。

```json
{
  "g7p2": {
    "title": "进入幽寂谷",
    "content": "【本轮必须发生】\n玩家已入谷。\n\n【场景内容】\n填写当前可见环境。\n\n【人物表现】\n填写对白要点。\n\n【当前可见去向】\n洞府小径与山涧溪路，未替玩家选择。\n\n【演绎边界】\n不进入未选分支，不揭露其内部与奖励。"
  }
}
```

构建生成世界书条目 `【节点故事】g7p2`，关键词是稳定前缀 `XSD2_g7p2_`。实际消息如 `XSD2_g7p2_1234abcd`：前缀匹配节点，末尾8位流水摘要用于本次行动去重与核验。玩家看到友好行动名称，存储保留代码。

条目默认关闭、非常驻、防递归，扫描深度1并配置用户消息匹配。中控在合法点击之后、发送之前只开启当前节点条目，完成/停止后关闭；即使宿主不支持角色消息过滤，也有当前授权门禁限制历史误触发。原生扫描选项在主人的实际酒馆仍需验收。

v15起：当前绑定的预期同名2.0主书缺少管理条目时，从PNG内嵌脚本配置自动补齐缺项并分配新UID，保留已有条目及用户改动，不操作其他书。补齐或同步仍报错则取消发送并恢复点选前状态；正式交付只PNG，不要求单独导入JSON。禁止给它加“洞府”“地图”等自然词备用关键词或改成常驻条目。

详细故事可填写环境、对白要点、关键事件与自由空间；确定奖励/地点以后台为准。父节点只介绍当前可见入口，不注入子节点的秘密。

源码：[条目构建](../src/runtime/story_entries.js)、[门禁](../src/host/worldbook.js)、[代码协议](../src/runtime/action_wire.js)。
