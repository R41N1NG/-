# 重要节点结算模板

```js
settlement:{mode:"separate",title:"幽寂谷行程结算"}
```

mode为none（默认无展示）、inline（简短卡）、separate（完整独立摘要卡）。普通节点无结算卡；幽寂谷正常出口/密室出口/提前离开配置完整结算。

中控在回复完成时创建唯一摘要记录：id、完成楼、标题、模式、行动、耗时、最终日期、奖励、关键经历、退出类型。展示只读这些回执，不靠模型重新判断奖励和日期。重复结算调用/重新渲染不重复加卡、领奖或耗时。

完整卡按顺序显示标题、退出类型、关键经历、本次所得、耗时和日期；简短卡省略经历。位置为该回复楼的HUD之外独立区域。卡自身不发送、不增加storyCount，不插入新的酒馆原生消息楼层。模型润色、原生编号结算消息尚未实现，不把本版界面卡说成原生楼。

快照随有效聊天分支走；切分支/删楼恢复对应记录，不在另一个全局缓存保存。

源码：[中控](../src/runtime/dispatcher.js)、[独立展示](../src/ui/settlement_panel.js)。
