# 身份开局模板

六身份：赵无忧、自设、焚欲殿主、欢喜殿主、浊龙殿主、魂欢殿主。开场在[text_data](../src/text_data/_card_greetings.txt)，按@@@分组；起手库存在[starting_inventory](../src/runtime/starting_inventory.js)，只在新开局发一次，旧存档补元数据不补余额。

开场保留Status_block的时间、身份、修为、地点等字段供自动识别，显示数字月日。自设需道号、修为、有效日期，可填地点/来历。时间滑块只填写字段，确认身份/自设后更换开场，不发送一轮剧情。

开局人物剪影用于图鉴查看，不偷偷提交赵无忧身份；身份按钮才切对应开场。不得以首次渲染默认值覆盖已经读到的有效身份。

时间预设真源：[timepoint-slider.cjs](../tools/opening/timepoint-slider.cjs)，展示来自[menu-builder.cjs](../tools/opening/menu-builder.cjs)。新身份还需注册规则/世界书/开场，不能只加一个按钮。
