# 按钮行为模板

| 当前行为 | 是否发送 | 已实现的例子 |
|---|---|---|
| 查看界面 | 否 | 地图、背包展开、物品介绍、立绘、翻页、关闭 |
| 本地修改 | 否 | 丢弃1件、GM保存与交还自动 |
| 填入输入栏 | 否；主人自行发送 | 交谈、自由行动 |
| 直接发送 | 是 | 观察、合法剧情节点、消耗品使用 |
| 确认后发送 | 确认后才发送 | 提前离开、整段最终出口 |

快捷按钮真源：[button_actions.js](../src/runtime/button_actions.js)。send和fill分别通过宿主send/fillInput执行。地图退出确认、UI查看、本地库存操作是对应意图的既有处理；没有另一个通用YAML按钮加载器。

物品useMode为send或view；默认为send，地图/秘籍/书册预置view，物品元数据可覆盖。view不消耗、不增加剧情轮数、日期不推进；不能把消耗品配置为view使用。

所有修改仍受当前聊天、pending与生成门禁约束，禁止跨聊天误写。查看和关闭不需要发起事务。交谈/自由行动只填入，不会替玩家补齐决策内容。

丢弃在当前楼快照保存，不新增消息，没有“停止丢弃发送”这一概念；若误丢，使用GM恢复数量。本版尚无独立撤销丢弃按钮。
