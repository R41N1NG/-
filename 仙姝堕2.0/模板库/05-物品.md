# 物品模板

```js
{id:"唯一标识",name:"物品名称",count:1,consumable:false,
 description:"物品介绍",effect:"具体使用效果及限制",aliases:[],useMode:"view"}
```

源：[item_catalog.js](../src/runtime/item_catalog.js)。来源/source可保留；unknown物品默认非消耗，无已配置效果，不编造药效、修为增益或奖励。

点库存物品打开子面板：数量、类型、介绍、效果、×关闭、查看/使用、丢弃。打开不发送。

send使用：向模型注入介绍与效果；消耗品后台扣1、归零移除，非消耗不扣。发送失败/停止/删楼可恢复发送前快照；模型申报不再次扣同物品。

view使用：仅后台使用记录，内容已在详情面板查看，不发送、不扣数、不移动玩家、不改变事件日期。地图查看不会把南疆大地图换成道具名称。

丢弃：任何类型扣1，归零移除，无模型调用；下一次请求的背包基准带最新余额。人工覆盖库存时禁止自动消耗和丢弃，需GM交还自动。

当前预置奖励仍为通用名；详细药性/法宝能力需真实材料配置，不能自行补造。
