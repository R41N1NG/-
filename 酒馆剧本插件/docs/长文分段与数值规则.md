# 长文分段与数值规则（v1.4.2）

默认流程：粘贴整篇 → API规划分段 → 本地按边界取原文 → 每段分析并校验 → 整合 → 编辑草稿 → 本地转化。单段建议2000～4000字，默认约3000字符；整篇每批建议2万～10万字。规则密集时减少单段目标。全文上限100万字符、512段、1024节点；不代表任何模型服务都支持相同额度。事件包仍最多128个，分析独立事件最多512项。

默认输入预算由16000上调为64000字符，分析/基础整理输出分别由8192/4096上调为16384 Token。输入预算包括system/user、要求和JSON转义，不等于模型Token上下文。API“判断与预算”集中设置规划开关、目标字数和输出预算；分析页有直达按钮。历史默认值精确迁移，其他自定义额度与提示词保留，恢复默认提示词后仍需保存。

## 分段与完整性

本地按换行/句号边界给原文编号，超长自然段会先切成不超过1500字符的小片。模型返回sections[].end及complete:true。每个结束编号递增，最后必须覆盖本次最后一片；程序取回原文，不接受模型改写全文。超过规划输入预算会分多个窗口规划，最终逐字符核对拼接完整。无效、遗漏或截断规划回退本地分段并警告；取消/超时停止任务。规划本身不能恢复为剧本草稿。

一段超过输入预算会进一步切小，保留完整已知规则。每段收到完整JSON后验证原文出处、数值、条件和引用。finish_reason=length时保留半截结果供排查，缩小当前段重试，每条缩小链最多三次；很短段仍截断则停止并提示输出预算。网络、政策拒绝、语义字段校验错误不会伪装为完成或无限重试。既有成功段不重跑。

最终整合保留本地节点、出口、条件和数值规则。摘要超预算时使用精简索引，完整规则不由模型改写；仍过长或输出截断时分组整合，最多三层缩小。各组可引用完整节点ID目录，最后全部重映射、校验再形成草稿。恢复其中一组时其余节点保留原草稿，并明确标为局部整合，需要核对跨组关系。规则本身过多、模型输出能力不足仍需提高预算或分篇。

成功响应次数/实际请求、规划、分段及整合进度可查看。单段文本只需规划＋分析，多段额外整合；重试增加调用。原始请求文本累计保留200万字符、原始响应正文累计200万字符，恢复上下文累计约250万字符。全文和证据复用本轮原文，历史节点以精简索引存储；达到预算明确标记展示截断或恢复上下文不可用，不将截断当作完整结果。

## 数值规则格式

变量仍用variables定义：id/title/type:number/default/evidence，min/max须bounds_evidence。有原文依据的增减/设置量用以下字段提取：

```json
{
  "numeric_effects": [
    {"operation":"add","variable":"alert","value":20,"evidence":"实际听见异常增加20"},
    {"operation":"set","variable":"alert","value":30,"evidence":"解除戒备后调整至30"}
  ]
}
```

每个效果必须引用已定义数值变量，变化量有限且有原文摘录。add负数扣减；set调整到指定值。单行为min/max配bounds_evidence，与变量总上下限独立。程序验证出处和结构，不证明摘录语义支持该数量，作者仍须核对。

一次阶段完成的奖励放在节点numeric_effects，必须有完成标准和完成证据；重复/独立行为放在events。每项event有id/title/description/completion_criteria/evidence/exclusions/condition/scope/numeric_effects；condition非默认须condition_evidence。默认once；once_per_accepted_turn须repeat_evidence，同一回复同一规则仅一次。max_occurrences须正整数和max_occurrences_evidence。到达某数值停止生效用事件condition，例如alert<60；同一行为只加到70用该numeric_effect.max:70。未明确次数默认一次，语义待核对。单轮多次计数不支持，不乘倍数。

事件可用result_ids取得有定义的结果，用于不可逆选择、警戒/暴露等事实。降低数值不会自动清除事实。节点与独立事件不得重复配置同一奖励。补写构想不能自动产生数值效果，未知变量/结果、非法范围/重复策略、虚构证据均拒绝；任意原始effects和代码不执行。

## 转化与结算

numeric_effects校验后变为本地add/set效果，独立事件默认用辅助API核验且证据通过后自动结算；不靠点击行动就加减。节点只在完成后结算。数据→数值载体显示当前值和来源；事件页编辑次数上限、条件、奖励限制。正式入口与事件包读取同一聊天数值，重复回复去重、总次数、上下限、回退由本地执行。阶段对应完成事件共用节点回执，避免双领奖。整合和本地恢复保留规则，不允许模型覆盖既有变化量。

## 页面入口与验证

分析、API、数据、记录页顶部固定横向功能导航，直接跳至对应功能并保留未保存表单。恢复JSON成为独立入口，快速整理/仅保存原文默认收起；API系统提示词逐项折叠。快速整理适合少量文本的基础草稿，分析提供全文规划、条件/数值、走向/结局/伏笔和整合。

129项单元测试、完整安装JSON桌面1366px及手机390/320px模拟回归通过，包括超过旧20万字符的文本、截断分段/分组、数值转化及本地限次、导航、恢复和刷新。没有调用真实付费模型；真实模型对原文的逻辑理解仍需作者检验。主模型短报告、自然结束按钮、集中核验节奏仍待后续实现，日常辅助判定流程保留。
