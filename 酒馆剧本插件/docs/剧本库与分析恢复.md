# 剧本库与分析恢复（v1.4.5）

面板标题显示当前运行版本。确认是v1.4.5后再使用新功能；安装时仍应停用旧脚本，备份剧本/聊天进度后导入完整JSON。

## 恢复已有失败回复

分析页 → 恢复后台结果 → 选择失败的原始回复 → 读取这份原始回复。

先点“校验后台结果并生成草稿”，不调用API。空白或支持的Markdown标题/平衡粗体排版差异，且文字/顺序连续唯一一致时，程序取回真实原文。实际改写、漏句、拼接不连续内容或匹配歧义仍不能强制作为原文。

仍是节点来源或变量依据问题时，点“补修来源或变量依据并恢复（必要时调用 API）”：先本地校验，必要时最多两次定向补修来源或变量依据。变量缺失type/default且原文明示时可以补齐；已有值、条件和奖励保持不变。完整原始节点规则保存在本地，模型额外奖励/条件不覆盖它们；来源和所有规则仍校验。失败回复及新的补修请求/回复继续保留。成功后清除已解决错误，再点“转化为剧本、事件与分支”。选中分块只能恢复本块，需核对全篇关系；截断回复不能作为完整草稿。

新分析遇到来源错误自动执行相同的最多两次补修，不重做整篇分析；会增加实际请求数。变量细节见[变量分析与恢复](变量分析与恢复.md)。这个过程只属于作者分析/恢复，不增加每轮游玩的固定请求。取消、其他规则证据错误、拒绝、网络或JSON错误按对应原因停止。真实模型的来源选择及规则推断仍需作者核对。

## 管理多份剧本

所有页面顶部“当前剧本”下拉可以切换；旁边“剧本库”进入列表，剧本页也有同名子栏。列表支持名称搜索、新建、复制、导入、世界书多剧本读取以及确认移出。

旧本地草稿和当前剧本自动入库，各项目分别保留内容、分析/整理草稿、原始请求与回复、编辑输入。切换会关闭剧情注入，准备好后到运行页启用。聊天进度仍按聊天＋剧本ID分别保存，切回继续原进度。当前只有选中的项目用于注入；独立事件包仍在项目内交叉推进。

复制产生新的剧本ID，内容与规则复制，聊天进度/已得物品从零开始。移出必须先切到其他项目，并确认删除本地缓存和工作草稿；世界书原件及聊天进度保留。需要重回旧进度时重新导入相同项目ID。辅助任务进行中需先等待或取消再切换/移出。

世界书剧本切换会重新读取实体，并保持保存到原世界书的关联；不会覆盖同书里的其他剧本或普通条目。同一项目ID代表同一剧本，若需要完全独立的副本，用“复制”生成新ID，再写入目标世界书。项目未保存的编辑表单在切换、关闭及字段变更时保存；API配置全局共用，其编辑表单和密钥不写入各项目编辑工作区。

165项单元及完整安装包浏览器回归通过，含桌面1366px和实际手机viewport390/320px的来源补修、剧本库、确认移出、独立草稿/收集与刷新。测试使用模拟模型，未调用真实付费API。
