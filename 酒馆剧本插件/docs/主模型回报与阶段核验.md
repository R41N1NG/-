# 主模型回报与阶段核验（v1.5.0）

优先保持故事连贯和玩家沉浸感；条件、奖励和数值由本地规则执行。主模型负责演绎及简短事实判断，辅助模型在关键结果与固定节奏处复核。两者都可能判断错误，引用真实只能证明出处。

## 安装与运行

先备份剧本和进度、停用旧脚本，再导入完整安装 JSON。API 页默认运行方式是「主模型回报 + 本地结算」，集中核验间隔默认 3 回合，可设 1～20。兼容方式「旧版每轮辅助判定」继续保留。

面板显示当前角色卡；剧本库按角色卡身份隔离，每张卡下各剧本独立保存编辑内容和分析工作区。各聊天保存独立进度与选择。优先使用角色卡 extensions.bse_card_id，其次头像身份；名称仅用于显示。换头像可能被视为新卡，迁移前应备份。群聊使用群身份。未能识别时明确显示未识别，不猜角色卡。

旧剧本库首次升级归属当时打开的卡。需要在另一张卡使用的内容，导出后在目标卡重新导入。主模型没有看到整个剧本库。

## 一轮如何推进

1. 点击「进入阳台」只填入行动文字。发送后本地验证入口、记录选择并注入当前内容。原样快捷行动无需辅助 API；自由输入由主模型从实际正文报告行动，只有仍合法的候选可推进，目标指引从下一轮注入。
2. 阳台内继续自由互动。在节点配置自然结束行动：例如按钮「离开阳台」、行动「我离开阳台」、标准「正文实际离开阳台」。尚未完成时展示此行动，不提前展示下一分支。按钮不会直接完成阶段或领奖。
3. 正文末附隐藏 HTML 注释，主模型只报告候选 ID、完成/拒绝/待定及最多160字连续正文依据，不计算奖励或数值。
4. 本地检查完整标记、回合标识、候选 ID、主体与对象、引用、重复及规则。普通事件按预设规则本地结算；例如确实接受赠礼后好感30→31，拒绝或待定不加分。
5. 取得物品、影响解锁门槛的数值/结果、结局或作者指定关键节点先进入待核验。阶段结束或固定回合间隔集中核验；没有候选不发送请求。相关后续入口在通过前关闭，同场景普通互动可以继续。
6. 辅助核验完整通过且本地条件仍满足，才执行奖励、完成阶段并显示后续分支。关闭自动结算的候选在后台显示「作者确认结算」，不会强迫玩家点技术性的完成按钮。

阶段完成必须同时满足目标和配置的结束行动。自由输入「离开阳台」与按钮同等处理；只有要求、意图、假设或进入动作都不是已完成。分析新故事也提取自然结束行动；旧剧本缺标准时需作者补齐，升级不凭空猜测。

报告格式示例（由主模型填写，玩家无需操作）：

```html
<!--<bse-report>{"turn":"本轮标识","complete":true,"stages":[{"id":"N1","status":"in_progress","quote":"你仍站在阳台上。"}],"events":[{"id":"gift","status":"completed","actor_id":"player","recipient_id":"wang","quote":"小王接过了花。"}],"present":["wang"]}</bse-report>-->
```

同轮 ID 错误、缺尾标记、截断、引用仅出现在报告内或主体不符，都不当作成功。兼容旧的非注释 bse-report 标签，安装包同时尝试隐藏它。不同主题可能改变渲染，需要真机检查。

## 数值与角色卡状态栏

角色定义保存在 project.actors；变量 owner 对应角色 ID；节点 context_actors 声明在场候选。发送给主模型的是当前相关角色，避免泄露未来人物。正文报告新角色出现后，下一轮才有对应确认数值；无法在正文尚未生成时知道所有新出场者。

角色卡状态栏用 DOM 占位读取本地值，数值不再由主模型抄写：

```html
小王好感：<span data-bse-variable="aff"></span>
```

可加 data-bse-project、data-bse-card 限定归属。已生成消息使用该楼快照，最新场景使用当前确认值；缺值或归属不符显示「—」。不覆盖整段正文。扩展脚本也可使用 插件脚本窗口的 window.__branch_story_plugin__.getValue('aff')或监听 bse:state-changed/BSE_STATE_CHANGED；只读接线不会证明自然语言判断正确。

## 核验、容错和边界

集中核验发送候选及对应正文：当前事件对话、待定尝试的初始和本轮对话、每个活跃阶段最近最多8轮。只接受候选自身来源的连续引用，不借用其他候选的正文；报告元数据先移除。

网络、格式或截断失败最多重试3次（初次加重试，最多4次）；预算超限或取消立即停止。完整回复必须含匹配 check_id、complete:true 和每个候选恰好一个结果。失败/待定不发奖励，不截断正文后冒充完整核验。已有引用不代表语义无误，关键结果仍有双模型同错风险。

任务绑定聊天、项目版本和完整来源。切卡、切聊天、改配置或编辑来源后，晚到结果不结算。待定事件复用尝试 ID，结算同一尝试一次；数值上下限、单行为停止门槛、次数限制、AND/OR/NOT、互斥及原有账本继续执行。

已结算的正文后被修改或删除时，不自动删楼或重写故事。默认保留正文并暂停；可选择保留当前场景互动、阻止后续推进。作者需通过账本回退或备份处理错误后继续，不自动编出修补分支、补发缺失物品或改条件为 true。尚未通过核验的关键结果不能解锁依赖，但主模型仍可能自行编造未注入的情节；插件不能绝对控制生成文字。

回报候选最多32个独立事件，待核验上限128项；阶段正文只保留最近8轮用于核验，日志最近100条，已结束尝试保留最近200条。历史数值快照保留以防旧状态栏被当前数值覆盖。长阶段的重要证据若超出8轮窗口，可能需要作者检查/调整阶段粒度；不会猜成功。

云环境测试使用模拟酒馆宿主和 API，覆盖完整安装包桌面/390/320px；未调用付费模型，也未宣称真实模型的语义识别率。
