# 长文条件分析（v1.4.2）

目标是自然、有选择且有后果的故事。分析阶段提取作者已经写明的规则，不把叙述顺序机械地改成必经任务链，不为玩家编造通行方式或补偿失去的机会。分析结果先生成可编辑草稿，核对后再转化、启用。

## 提取什么

默认的全文分析、基础整理和跨段整合提示词检查以下内容：

- 可替代路径：A 或 B 满足任意一个即可；失去 A 不等于失去所有入口。
- 共同前提与括号层级：例如 `(A 或 B) 且 D 且没有 E`。
- 明确例外、排除、失效、放弃和互斥；互不相同不等于互斥。
- 原文明示的数值门槛及特殊许可替代方式。
- 进入条件、实际完成标准、取得结果的前提，三者分开。
- 选择代价和永久失去机会。仅全部合法路径均明确不可恢复时才分析为永久关闭。

程序支持 `all`、`any`、`not`、`collected`、`completed`、`visited` 和变量比较。分析不接受任意effects或代码；原文明示的增减/设置量及独立行为规则可通过numeric_effects/events提取，初始值、触发量、重复/次数上限和边界均须有原文依据。节点实际成功完成后才能获得 `result_ids` 对应结果。

## 可执行字段与原文依据

| 规则 | 字段 | 依据字段 |
| --- | --- | --- |
| 分支通行 | `routes[].condition` | `condition_evidence` |
| 节点进入 | `entry_condition` | `entry_condition_evidence` |
| 结果取得前提 | `collections[].requires` | `requires_evidence` |
| 明确互斥 | `collections[].exclusive_with` | `exclusive_with_evidence` |
| 事件包触发 | `packages[].condition` | `condition_evidence` |
| 事件包持续 | `packages[].continue_condition` | `continue_condition_evidence` |
| 数值初始值 | `variables[].default` | `evidence` |
| 数值上下限 | `variables[].min/max` | `bounds_evidence` |

依据兼容一个连续原文字符串，或 1～8 条连续原文字符串组成的数组。数组内每条都必须存在，不能用其中一条真实摘录掩盖其他虚构条款。结果公开说明 `description` 仍只接受一个连续原文字符串，不能泄露隐藏用途。

未知 ID、非法互斥、空 AND/OR 组合、未经原文支持的进入/取得/持续条件和数值边界会拒绝。出口已有非默认条件却缺少依据时，保留原来的安全处理：改为 `false` 并警告，不能当作无条件通行。

原文不明确或当前表达式无法完整表达的规则列入 `analysis.uncertainties`，相关明确入口建议暂阻、交由作者核对；程序不能识别所有自然语言遗漏。连续摘录校验能验证出处，不能证明模型理解了逻辑。尤其应检查“除非”“只有”“任一”“同时”“之后失效”等条款。

## 分块与整合

后文收到前文已提取的完整结果规则、数值定义和紧凑的节点 ID→标题映射，而非只有结果名。已提取规则占用输入预算时会继续分割剩余原文；不删除条件来凑预算。仍限制512段、1024节点，规则本身占满预算时提示提高预算或分篇处理。

整合保留所有原节点、既有出口、完成标准、排除项、前提、互斥和持续条件。模型遗漏出口或返回 `true` 不会抹除原先的限制。原先没有限制的字段可以补充有原文依据的跨段条件；已有明确限制仍保留，不能借合并放宽。未知或重复的结果/变量/事件包定义拒绝。

跨块 `completed/visited` 引用以及结果取得前提中的节点引用按实际节点重映射。全部条件最终重新通过完整项目校验。后文分块恢复携带原来节点上下文，仅代表局部草稿；完整整合恢复才代表全篇。

各块待核对事项在全篇结果中保留。即使整合报告省略它们，也不会自动视为已解决；作者核对后可编辑清理。暂阻的 `false` 不会被整合自动放宽。

## 提示词升级与验证边界

新版默认提示词只替换与历史默认值完全一致的设置，作者自定义提示词保留。在分析页或 API 页恢复默认并保存后才能使用新默认；只打开编辑器并不等于已保存。实际请求仍可查看，失败后的原始响应与本地恢复保留。

v1.4.2 共129项单元测试通过；v1.4.1的12项条件测试覆盖嵌套条件、替代路线、放弃后的剩余路径、正式入口/奖励保护、数值边界、互斥、分散证据、持续条件、默认迁移、跨块保存/合并/恢复及定义冲突。浏览器回归使用实际安装 JSON 和模拟宿主/API；没有调用用户付费服务。真实模型提取质量需要用实际原文核对，测试不保证任何模型都不会遗漏条件。
