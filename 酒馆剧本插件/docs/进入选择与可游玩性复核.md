# 进入选择与可游玩性复核（v1.6.0）

目标是自然、允许选择并承担后果的故事。不能靠放宽解锁门槛修复卡点，也不能把原作者一次游玩的全部动作强制给玩家。

## 运行报告与自由行动

`stages`仅报告本轮给出的活跃阶段；`routes`是可进入的候选，不代表可以报告其完成。N1已完成时，选择N2可以成立，但同时报告“N2已完成”会单独忽略，不领取N2结果。

结构完整、回合一致后，各段分别处理：坏列表仅丢该列表；越界、未知状态、重复ID的项单独丢弃，重复ID所有项均不结算。合法事件和进入选择继续独立校验。JSON/注释截断、重复报告或错误turn仍整体拒绝。候选、版本、来源、主体对象、本地前提、互斥、奖励上限和关键复核门槛继续执行。

玩家选择可以来自明确的自由输入，不要求主模型代写玩家动作：

```html
<!--BSE_REPORT {"turn":"原样复制输入标识","complete":true,"stages":[],"events":[],"choice":{"target":"N2","source":"user","quote":"继续跟上"},"present":[]} -->
```

本轮提供`player_input`供报告引用，引用只能取当前玩家消息，不能引用旧楼层、讨论或假设。它只作为入口选择依据，不证明完成或允许领奖。阶段与事件完成仍需要正文的实际事实，关键结果先集中复核。兼容旧choice格式及assistant正文引用，但模型仍可能在语义上误判；连续引用只是出处证明。回合标识不能自造，输入修改后旧报告不推进。

记录页显示被忽略的具体项。旧版失败报告仅在当前轮绑定仍成立时可重读；不会批量回填历史、猜补前提或倒带正文。

## 作者分析与复核

默认流程：规划分段 → 每段剧情/规则提取 → 独立结构复核 → 独立可游玩性复核 → 多段整合 → 转化后复核。每段错误最多定向重提取两次，每次重新进行两种复核；仍错保留原始回复与草稿，不冒充通过。

可游玩性复核专查：

- 完成目标是否被偶然事故、原作者具体台词/地点/时间绑死；原文明确必要的约束仍保留。
- 是否把章节分组当分支，遗漏明确替代路线，或把未展开的路线编成无条件成功。
- 是否混淆场景结束、独立事件与结果领取；失效/暴露必须有实际触发事实。
- 是否漏掉后续需要的凭证/物品/许可及获取来源，OR/AND、消费/归还和失去机会的范围是否准确。
- 自然结束动作是否缺失、过于技术化、与边界冲突或要求先完成下一阶段未注入的内容。
- “不能像今晚这样接近”等限定句是否扩大成任何情况下永久关闭；已描述情节是否被误列成未展开。

提取提示词与两种复核/转化复核提示词各自独立，可在分析页/API页修改和查看实际请求。旧默认逐字匹配迁移，自定义保留。独立事实事件允许无数值变化、只登记结果；原文没有初值或增减规则时不编造数值。原文未写清的替代路线列待作者补，不自动编剧情或奖励。

本地还会对缺自然按钮、技术性按钮和非结局无出口发作者警告；它只能查结构，不能证明语义正确，不自动改规则。

## 调用与旧草稿

自动独立复核开启时，单段基础4次，规划另加1次；多段基础为规划+3×段数+必要整合+转化复核。预算造成分组、截断缩段和补修会更新预估/实际次数。每轮玩家正常行动不因此增加API；作者成本与玩家节奏分别处理。

旧草稿或手动修改后需“复核可游玩性及转化结果”（基础2次，长篇按预算分组）。只有本版复核通过且内容未改，才复用复核结果。错误阻止替换当前剧本；警告供作者核对。可点击“将复核问题带入重新分析”填入原文和问题，核对调用预估后发起分析，此按钮本身不调用API或改变当前剧本/进度。

已经开始的故事保留原条件。升级不会自动创造凭证、删掉严格条件或批量补完成历史；建议备份后重新分析原文，并用新测试对话验证。两种模型都可能犯错，模拟回归不等于真实模型语义保证。
