# 名器上下文检索工具（xsd-search）

用途：在《仙姝墮》原文里**准确找到某个名器/触感关键词的出现场景**，输出带【章名】+ 行号的上下文。
适用于设定提取、写作考据、核对某个描写到底属于谁。

---

## 1. 基本用法

```powershell
# 单关键词（默认 ±60 字上下文，Char 模式）
E:\角色卡制作\仙姝堕\tools\xsd-search.ps1 璎珞茶蕊

# 多关键词：逗号 / 中文逗号 / 竖线都可以，默认「任一命中」
E:\角色卡制作\仙姝堕\tools\xsd-search.ps1 "璎珞茶蕊,茶蕊,紫金触须" -Radius 200 -Max 20

# 只看整段（看完整场景，推荐做设定提取时用）
E:\角色卡制作\仙姝堕\tools\xsd-search.ps1 冰棱漩涡 -Mode Paragraph

# 输出整章（看场景的完整因果）
E:\角色卡制作\仙姝堕\tools\xsd-search.ps1 冰心泪 -Mode Chapter -Max 1 -MaxChars 6000

# 严格 AND：同一段落内必须同时出现所有词（找「冰与火同场」这类交叉场景）
E:\角色卡制作\仙姝堕\tools\xsd-search.ps1 "璎珞,吮吸" -Match All -Mode Paragraph

# 只统计，不输出正文（先看词频再决定读哪些）
E:\角色卡制作\仙姝堕\tools\xsd-search.ps1 "冰棱漩涡,冰晶龙鳞" -Count

# 结果存文件（UTF-8，便于后续再消化）
E:\角色卡制作\仙姝堕\tools\xsd-search.ps1 酒香 -Radius 120 -Out 灼酒_酒香.txt
```

## 3. 参数速查

| 参数 | 说明 | 默认 |
|---|---|---|
| `-Keyword`（位置参数） | 关键词，支持 `a,b,c`；可多个 | 必填（或用 `-Preset`） |
| `-File` | 原文路径 | 已指向 `E:\火狐下载\[仙姝墮] 1-49+番外 作者：_肉山佛.txt` |
| `-Radius` | Char 模式上下文半径（字符） | 60 |
| `-Mode` | `Char` / `Paragraph` / `Chapter` | Char |
| `-Match` | `Any`（任一）/ `All`（同段同时命中全部） | Any |
| `-Max` | 最多输出多少条（0=不限） | 0 |
| `-MaxChars` | 单条输出上限 | 4000 |
| `-NoChapter` | 不显示章名（只要行号） | 关 |
| `-Count` | 只统计命中数与每词词频 | 关 |
| `-Regex` | 关键词按正则解释（如 `冰.{0,4}漩涡`） | 关 |
| `-IgnoreCase` | 忽略大小写（英文/拼音关键词有用） | 关 |
| `-Out` | 结果写入指定 UTF-8 文件 | 不写 |
| `-Preset` | 使用内置名器词表 | 无 |
| `-ListPresets` | 列出全部预设 | 关 |

## 4. 实现要点与已知限制

- **快**：启动时一次构建「行 / 段 / 章」三级索引（80 万字约 100–200 ms），之后用二分查找定位，全部检索通常 < 1 秒。
- **段落判定**：连续非空行算一段（网文常见的空行分段）；原文中若出现无空行的长段，`-Mode Paragraph` 会输出较长内容，可用 `-MaxChars` 截断。
- **章名来源**：识别 `第X章`／`番外`／`尾声`／`后记`／`楔子`／`第X节`。本书因插了 2 篇番外与 1 篇作者话，**切片编号 chNN 与书内印刷章号有偏差**（最多偏 3），本工具直接输出的是**书内印刷章名**，与设定集口径一致。
- **`-Match All` 的粒度是「段」**：只在同一段内共现才算命中。若要跨段共现，请先 `-Count` 看词频，再用 `-Mode Chapter` 逐章读。
- **编码**：脚本带 UTF-8 BOM（保证 PowerShell 5.1 下中文参数不乱码）。若从别处复制脚本内容，请另存为「UTF-8 with BOM」。

## 5. 典型工作流（做设定提取 / 写作考据）

1. `-Preset xinmo -Count` → 先看该名器的触发词各出现几次，判断哪几个词是「高价值词」。
2. `-Preset xinmo -Mode Paragraph -Out 心魔_全部段落.txt` → 一次性导出所有段落。
3. 对可疑段落用 `-Mode Chapter` 回读整章，确认因果与视角（谁在感受、什么阶段）。
4. 交叉场景用 `-Match All`（例：`"璎珞,吮吸" -Match All`）定位「同一段里同时写结构与动作」的地方。
5. 发现原文没写的项，记入「缺口清单」，不要用其他名器的描写顶替。
