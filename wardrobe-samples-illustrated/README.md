## 目录与命名

图片按 `套组名称/分类/服装名称/视角.png` 存放；人物参考置于各套组的 `人物锚点/`，多格合图置于 `套装总览/`。分类使用：头饰、上装、下装、袜子、鞋子。各套组内维护独立索引。

有发型和体型变体时，使用 `套组名称/分类/服装名称/发型/体型/视角.png`，发型命名为长发、马尾、双马尾、短发，体型命名为清瘦、匀称、丰腴。共用素材省略不适用的层级。

视角统一命名为：正面、侧面、背面、四分之三侧面。合图保留为合图，不计作已交付的独立素材。
