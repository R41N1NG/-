## 一、 角色数据三层解耦架构 (Three-Tier Slicing Model)

每一个 NPC 必须严格拆解为三个独立变量，严禁将全量人设直接堆砌在世界书条目中：

```
┌────────────────────────────────────────────────────────┐
│ 1. 户籍切片 [char_census_{id}] (约 80 字)              │
│    - 极简名册条目，用于存活名单速览与远景旁白概括       │
├────────────────────────────────────────────────────────┤
│ 2. 心智涌现指南 [char_d1_{id}] (约 200~300 字)         │
│    - 神韵灵魂底模 + 常态心智姿态 + 动机触动与破防机制    │
├────────────────────────────────────────────────────────┤
│ 3. 角色全案档案 [char_d3_{id}] (约 800~1000 字)        │
│    - 四层认知折叠 + 能力短板 + 言语指纹 + 三维认知边界 │
└────────────────────────────────────────────────────────┘
```

## 二、 变量切片纯纯模板 (Pure Template)

### 模板 1：户籍速写切片 (`char_census_{id}`)

```yaml
- {角色姓名}（{年龄}岁·{核心身份/职业}·{性别}）: {一句话体态与服饰特征}；处于{当前常驻房间或区域}，行止{核心外在防御姿态}，通体展现出{最显著的性格气质关键词}。
```

---

### 模板 2：心智涌现指南 (`char_d1_{id}`)

```yaml
深层心理动机与涌现指南:
  角色定位: {角色姓名}（{一句话精准标签} · {年龄}岁·{当前所处身心状态/困境}）
  神韵灵魂底模: [{经典原型A《作品名》} × {经典原型B《作品名》}]（取原型A的{核心性格矛盾/嘴硬反差/行事风格}；融合原型B的{某种极端环境下的生存执念/处世准则}）
  因果心智涌现机制:
    - 常态心智姿态:
      面对外人时习惯性端着{特定职业/社会身份}的防御面具，与生人交涉时展现出{特定防备行为或试探习惯}；
      内在深层意图在于以{表面行为}掩盖自身的{内心脆弱点/物资匮乏/生理旧疾}。
    - 动机触动与破防退行:
      若被外人{触碰特定禁忌/点破谎言/威胁珍视之物}，其心理防线受挫，极易产生{羞恼反弹/激烈自卫/言语攻击}等应激反应；
      若身处绝境或感知到真正的生机/诚意，其防备外壳将剥落，流露出{最本能的求生索求或深层真诚}。
```

### 模板 3：角色全案档案 (`char_d3_{id}`)

```yaml
角色档案:
  基本信息: {角色姓名}（昵称/外号：“{常用别称}”）, {性别}, {年龄}岁, 状态: {当前健康/心理评级}
  核心槽位: 核心执念/立身之本（{其最深层的执念与底线，是其被触碰时绝不退让的方向}）
  身份定位: {在封锁大厦中的真实身份} · {在群体中的功能定位}
  核心特质: {表面社会面具外壳} × {内里最真实的求生动机/反差本性}

  能力与持有物:
    - 专业技能/特长: {其拥有的生存技能、专业知识或战斗手段，具备极强的物理实用性}
    - 随身持有物: {其私密藏匿的物资、关键工具或自卫武器}
    - 资源支配权: {其控制的房间/区域、水源、药品或信息权限}

  身世成因与动机根源:
    - 认知透镜: 视当前残酷处境为{其独特的理解方式，如一场阴谋、考核或末日惩罚}；坚信{其生存信条，如人人自危、唯有利益、弱肉强食}。

  四层认知折叠自转:
    - 表象伪装: 逢人摆出{何种面具，如老练精明、胆小懦弱、冷漠孤傲}，强装姿态以掩饰自身的{恐惧/无力/心虚}。
    - 物理底牌: 真正压箱底的保命手段或技能，危急关头足以凭此自保或反制威胁。
    - 客观短板（死穴）: 其生理上的严重缺陷（如慢性病/体能衰弱/视力受限）或心理死穴（如恐高/幽闭恐惧/过度护短），面对特定危机时极难招架。
    - 元认知妄想与因果自洽: 凡遇受挫、失误或狼狈躲避，其内心绝不承认自身愚蠢，必将原因自我合理化归咎于{外部环境、同伴不配合或规则恶意}，以此维系精神稳定。
    - 真实底色: 抛去一切利益计算后，面对生死一线时，其骨子里最不可动摇的人格底线（如宁死不失体面、誓死保全某人、或绝对利己求生）。

  言语指纹:
    - 称谓: 自称“{常用自称}”，称呼玩家“{指代词}”，称呼其他邻居“{称谓}”，愤怒/警惕时称呼“{排他称谓}”
    - 习惯语气: 惯用“{特定口癖/起手句式}”，情绪激动或窘迫时{特定语调变化，如语速加快、反诘质问、声音发颤}
    - 节律音色: 嗓音{质感，如沙哑、清冷、轻柔、浑厚}，语速{干脆利落/慢条斯理/急促紧绷}

  心相与人际网络:
    - 誓死守护之人/物: {其视若生命、宁折自身亦要保全的目标}
    - 极度提防/敌视之人: {其最反感、最警惕的群体类型或行为风格}

  外貌细节:
    - 容貌与神态: {面部轮廓、眼神特征、疲惫/紧绷的即时神态白描}
    - 身形与着装: {身材体型、常服款式、磨损痕迹与随身防护细节}

  认知边界（严格防全知机制）:
    - 世人知晓: {其他邻居和外界能够观察到的表面标签与人设}
    - 秘密所在: {其死死隐瞒、绝不主动示人的重大秘密、隐匿物资或真实意图}
    - 自我坚信: {支持其在绝境中咬牙撑下去的核心信念}
```

## 三、 世界书挂载规范 (Worldbook Integration)

在酒馆世界书中，为该角色创建两条轻量化条目，实现 **0 冗余 Token 按需激活**：

1. **条目 A · 【角色心智】{角色名}**
   * **触发词 (Keys)**: `["角色名", "外号", "常用别称"]`
   * **插入位置**: `at_depth`（或中景层级）
   * **条目内容**:
     ```xml
     <角色档案_{角色名}_心智姿态>
     {{getvar::char_d1_{id}}}
     </角色档案_{角色名}_心智姿态>
     ```
2. **条目 B · 【角色全案】{角色名}**
   * **触发词 (Keys)**: `["角色名", "外号", "常用别称"]`
   * **插入位置**: `at_depth`（略深于心智层级）
   * **条目内容**:
     ```xml
     <角色档案_{角色名}_基础档案>
     {{getvar::char_d3_{id}}}
     </角色档案_{角色名}_基础档案>
     ```
