## 三、A 类：规则与契约层（6 条常驻，全部 constant 无关键词）

这 6 条每一轮都会进上下文，是全卡的"宪法"。

### A1. 核心常驻规则（4,499 字）— 最重要的一条
- **只写眼前的戏**：世界书是后台参考，没撞上的路人、物价账本、历史背景一律不许塞正文。
- **开局直接进现场**：亲属/照料者必须第一幕落地；「刚出生」或任何转生一律**空背包**，第一幕按该物种真实诞生方式写（分娩/孵化/凝形/苏醒/萌发/造物启动）。
- **把控制权留给玩家**：绝不替 `{{user}}` 决定动作、台词、想法；**严禁在正文末尾输出"你可以选择：1. 2. 3."**（要给方向只能写进状态栏的`可选行动`）。
- **严禁泄漏内部编号**：正文不许出现 `R001`、`N01–N19`、`LOC_*`、`RT_*`、`[STATUS]`、`[YW_CREATOR_PANEL]` 等字样。
- **去 AI 味铁律**：严禁"魔素耦合/代谢/阈值/信息素/神经节/渗透压/生态位"这类论文词进正文，全部翻译成肉眼可见的画面；少用"不仅…而且…"工整对称句；**禁止每段结尾搞道理总结或情绪升华**；NPC 要带偏见和毛边。
- **一世一命与主动转生**：主角每世只有一条命，死亡后**绝不自动复活回档**，须玩家发 `【主动转生｜开启新一世】` 才从 1 级空背包重开；**世界时间继续走，旧 NPC 保留前世记忆**，但不会凭空认出新身体。
- **好感度阶位**：`-100~-50` 死敌 / `-49~-10` 戒备 / `-9~+14` 中立 / `+15~+34` 友善 / `+35~+59` 信任 / `+60~+79` 深交 / `+80~+100` 生死相托。普通交谈单轮最多 +1~+3，救命级 +5~+12，**严禁无脑拉满**。
- **主动拟名与别名合并**：玩家提到"一个女人"时必须匹配名录具名原住民或当场拟自然姓名；得知真名后须在 `[NPC_RELATIONS]` 附 `别名：旧暂称` 由系统合并，**严禁拆成两个人物**。

### A2. 技能常驻规则（2,428 字）
品质 **F–S** 定上限，熟练度 **1–5** 定当下能使出几成。S 级需**角色达 60 级**才有学习资格。核心判据：「等级给底子，天赋改条件，技能兑现效果」——交战结果不能只按等级高低决定。

### A3. 网文式剧情导演法（1,047 字）
- **防迷雾铁律**：开场前两段必须让玩家看清「① 在哪、处境如何 ② 一件立刻能干的事 ③ 1–2 个看得见的互动目标」。
- **黄金三拍**：起钩 → 碰撞 → 反馈与新钩（办事立刻给银币/情报/好感/装备回报，同时露下个悬念边角）。
- **活人感**：NPC 有自己的日子在过，主角不在场时生活照走；**严禁千人一面套同一副弧光模板**。
- **设定动作化**：严禁连续三行纯背景说明，世界史全揉进闲话、悬赏告示、兵器磨损里。

### A4. 数值交锋（1,220 字）
统一三步：**① 先判行动能否成立**（看得见/够得着/未被地形挡住/付得起消耗/已习得技能）→ **② 算分差**（等级 + 品质对应 0/1/2/3/4/5/6 + 熟练度−1 + 天赋 + 处境修正 −4/−2/0/+2/+4）→ **③ 按命中部位与真实防护结算伤势**。分差 <0 被挡开；0–4 擦中；5–14 正中；15+ 强效果。**石壁挡住的攻击不能隔墙伤人**。

### A5. 适用参考（3,198 字）
1–100 级的分档：1–19 低级 / 20–39 中级 / 40–59 高级 / 60–79 准魔王 / 80–99 魔王 / 100 真魔王（古今不超 20 位，诞生留千年贫魔灾变）。魔力消耗尺度：微术 1 / 小术 8 / 中术 40 / 大术 200 / 要塞 1500 / 战略 10000。

### A6. 世界生活锚点（1,156 字）
开局固定 **共历 1317 年·第 1 日·春**。**1 银币 = 100 铜币**，普通人日挣几到十铜。三大可选主线（苦盐之兆 / 南口封关 / 沉渊旧闸）"绝不强按头，但一直有大戏可追"。

### C2. 六段式的实际写法（以 R064 树懒人为例）

> 上臂显著长于下肢；手足末端 **2–3 根 10–15 厘米不可收回弯钩巨爪** + **肌腱自动锁定构造**（扣住横梁可无消耗倒悬酣睡）；肠道极慢消化，**每日所需食物仅为寻常哺乳族数分之一**，断食数日只表现为更长时间静止节能，**绝不直接掉级**；但精细手工是死穴——**捏不起缝衣针、翻不动薄纸页、握不住人类细剑柄**；血脉寻常 19 级上限，优良 39 级。

这一条把"设定 → 可玩后果"的推导链完整走了一遍，是全卡 306 条的通用范式。

### C3. 三条硬门槛（跨条目一致）
- **S 级技能**：须角色达 **60 级（准魔王档）**，种族的"先天雏形"也不能绕过。
- **真魔王**：古今累计**不超 20 位**，每次诞生留下**千年贫魔灾变**。
- **核心毁灭 = 死亡**：以核心为生命根基的物种，核心彻底碎裂后**绝不再用"核心修复"救活**。

### E3. 三条时代主线（每条 5–6 层：公开征兆 → 地方官报告 → 被推到一起的人 → 可查档案 → 深层真相 → 无人介入走势）

#### 时代线1：苦盐之兆（霍兰草海线）
- **征兆**：淡泉返苦、羊群连拉三天稀、铜釜底厚灰黑硬垢、**暗灰盐晶攥在掌心直吸指尖热气**。
- **幕后**：准魔王顶点（约 **76 级**）孤僻枯水炼金术士 **「枯井公」维尔德**，两百年创不出独属神技，仿盐海君旧灾边缘沿西南水脉暗打 **七根「吸魔盐骨桩」**，已扎四根，剩下三根铜盐构件正借黑熔炉与塞维恩走私商路拆批转运。
- **无人介入时间表**：第 45 日第五根桩运到 → 第 90 日真贤者巴图（85 级）撞破两桩砸半座引槽，遭**趁夜毒盐伏击重伤** → 第 110 日三口淡渗井彻底断甜 → 第 180–240 日引动「苦晶瓮」，**更大可能是过载反噬崩毁**，即使勉强成王也只触发成王点周边千年最低魔力与旱碱灾变。

#### 时代线2：南口封关（阿尔迦—伊瑟林—奥伦线）
- **征兆**：维萨中层硫磺渗漏逼出小哥布林部族与采硫苦力北上，副团长巴伦锁死南口木栅、加严路引盘查；三百多迁民挤在灰石东门与青叶下层木栏外用破油布树皮搭棚。
- **被推到一起的人**：断手老矿匠莫顿一家四口分最后半块硬麦饼；哥布林修锅匠「秃钉」吉克一个铜板不收替迁民焊漏水铁碗，谁焊好就往他豁口木碗里匀半勺热稀粥；玛格丽特要扛烘干杉木板搭雨棚，木匠塞伦蒂尔踩着湿滑横木下来喝止，鹿裔巡林手洛林搭箭死守界木怕一阵山风把灶灰刮进南林防火带。

- **无人介入时间表**：第 45 日彻底闭关 → 第 90 日灰石铁价与青叶粮价双双翻番 → 第 140–180 日初霜落下，木栏外断柴必与巡林冲突见血；真到放野火那天，**真圣者艾莉薇娅的学徒才出面具名止争**，真勇者雷恩·加尔才按马程赶去拦门。

## 九、这张卡的三条设计巧思

1. **分层按"玩家能知道多少"写，不按"真相有多少"写**。同一个真魔王灾区拆成 `公开日常 / 怪事 / 街头传闻边界 / 查证真相 / 档案实录` 五层，每层都是完整可用的内容，而"街头传闻边界"里那些互相打架的说法**不是废案，是故意让玩家选边**。

2. **前置约束写死在规则层，而不是写进每个条目**。728 条里只有 6 条常驻，但把"不许倒设定 / 不许替玩家决定 / 不许泄漏编号 / 不许写论文词 / 好感度不许暴涨 / 别名必须合并"全部压在 `核心常驻规则` 一处，剩下的 722 条只负责提供素材，不负责管纪律。

3. **同一件事给不同种族四条完全不同的解法**。沉渊旧闸线，海族潜水摸闸、史莱姆钻石管、盲族赤足读碑、陆生商旅跑档案馆拼图——**同一个真相，四种代价，四种画面**，而不是让所有玩家走同一条任务链。
