## 一、宏观大势运转模型与临界大限

### 1. 运转核心机理
主线大势以始祖恶龙艾德潜伏在边陲小镇奥克赫斯的暗流为骨架，受艾德的 **`patience`（耐心值，初值 100）** 与古兰的 **`blood_density`（血脉浓度，初值 0）** 双向数值驱动：
* **跨午夜自然流失与催熟补偿**：入队被监听后（`ed_joined && ed.monitored`），每跨午夜基础自然流失 `patience - 1`；若当夜古兰成功获得夜间血脉增长（同在旅店且未被同房阻断），催熟成功补偿 `+1`（净流失为 0）；若被同房阻断或不在同地，古兰不加血脉，艾德无补偿，净流失 `-1`。
* **调息压制扣减**：玩家对古兰执行 `calm` 陪伴调息成功使古兰 `blood_density - 2` 时，触发艾德计划受阻的烦躁反应，同步扣减 `patience - 3`。

### 2. 前三阶段大势演进（纯数值判定 · 与固定天数解耦）
1. **第一阶段 · 潜渊落子 (`patience > 75`)**：初始如常，全镇生态平静，野兽与商队挽马均无异常。
2. **第二阶段 · 惊兽乱局 (`ed_grand_stage_2`，`patience <= 75`)**：龙威微泄，城外魔兽以城镇为圆心向外逃散，近郊任务变轻松，挽马受惊而军马可抗；座狼狂暴导致黑兽人营地警戒升级刺探；外逃魔兽踩踏远郊村庄引发难民潮，涌入大教堂。置入 `world.flags.grand_tier_2 = true`。
3. **第三阶段 · 剪枝封笼 (`ed_grand_stage_3`，`patience <= 25`)**：艾德耐心逼近枯竭暗中震塌峡谷主官道，成百上千吨山岩滑坡阻断外界陆路车马；多疑领主宣布全城实行严酷宵禁，小镇沦为封闭铁笼。置入 `world.flags.grand_tier_3 = true, road_blocked = true, curfew_active = true`。

## 二、第四阶段 · 终局决算 5 大分支全景

终局由两个源头引爆：**果实熟化（`blood_density >= 100`）** 或 **耐心枯竭（`patience <= 0`）**。
总门禁：`world.flags.arrived_oakhaven && world.flags.ed_joined && !world.flags.ed_showdown_done`。

| 分支序号 | 事件 ID | 触发判定条件 | 叙事归宿 | 核心因果与演出白描 |
|---|---|---|---|---|
| **分支 1** | `ed_showdown_good` | `blood_density >= 100`<br>$\land$ `affection >= 90`<br>$\land$ `stage < 3` | **救赎生还<br>（好结局）** | **人性逆鳞 · 真血自立**：古兰真血达到 100 突破凡人极限跻身 V 阶传奇超凡，具备上位同源龙威，不再受血脉位阶压制；好感 $\ge 90$（爱恋阶段）让人性战胜了太古狂暴本能。古兰横重剑立于小队身前，以命立誓正面抗衡生父。恶龙深知与同源超凡搏杀必有折损且残破母体毫无价值，冷哼惩戒后退去。古兰保全自我意志，与伯里守住小队大团圆。 |
| **分支 2** | `ed_showdown_abduction_mature` | `blood_density >= 100`<br>$\land$ `affection < 90`<br>$\land$ `stage < 3` | **牺牲换生<br>（悲壮结局）** | **真血满溢 · 舍身换生**：血脉虽达 100 峰值，但好感处于 70~89 亲密期未达爱恋峰值，古兰无法凭借人性力量正面逼退恶龙；但由于未曾沉沦且珍视小队同伴，古兰拔剑横颈以命相挟：“若伤他们，我当场自绝，让你数百年算计换来一具冷尸。”恶龙为保全鲜活母体放过主角一行，抓走古兰回巢强行繁衍。小队幸存但失去古兰。 |
| **分支 3** | `ed_showdown_dark` | `blood_density >= 100`<br>$\land$ `stage === 3` | **沦陷离散<br>（暗线结局）** | **始祖同化 · 终幕离去**：古兰此前在暗线中早已沉沦，心智完全受龙血本能支配。血脉成熟时响应生父呼唤，化为冷漠的金红龙瞳，视过往同伴为微尘，随艾德腾空回巢繁育上位龙嗣。小队支柱离散，暗线落幕。 |

## 三、代码接口契约与工程防护

### 1. 跨目标显式效果数组规范（消除隐式世界效果报错）
世界事件（`scope: 'world'`）在结算时必须通过显式声明 `target` 的效果数组修改角色状态：
* **好结局 (`ed_showdown_good`)**：
  ```js
  effects: [
    { target: 'world', worldFlags: { ed_showdown_done: true, ed_revealed: true, ed_final_good: true } },
    { target: 'ed', monitored: false, move: 'wilds', npcFlags: { ed_revealed: true } }
  ]
  ```
* **离队结局 (`ed_showdown_abduction_*` / `ed_showdown_dark*`)**：
  ```js
  effects: [
    { target: 'world', worldFlags: { ed_showdown_done: true, ed_revealed: true, /* 分支特定标志 */ } },
    { target: 'ed', monitored: false, move: 'wilds', npcFlags: { ed_revealed: true } },
    { target: 'gulan', monitored: false, move: 'wilds', npcFlags: { gulan_departed: true } }
  ]
  ```

### 2. 离队角色的幽灵日程防护
在 [`奥森德/src/app/okh_app_data.js`](奥森德/src/app/okh_app_data.js) 的 `gulan_train`（下午练武场）与 `return_inn`（夜间返店）中增设守卫：
```js
npc.monitored !== false && !npc.flags?.gulan_departed
```
确保古兰在被掳或离队后，不再被后台日程调度拉回城镇练剑或回店。

### 3. 大势事件防重复锁
在大势二、三阶段（`ed_grand_stage_2` / `ed_grand_stage_3`）的 `when` 判定中加入 `!world.flags?.ed_showdown_done`，避免在耐心急剧归零时大势三阶段与终局事件在同回合重复输出。

### 4. 状态栏与台账（`buildLedger`）呈现标准
根据触发的分支标志，在 `buildLedger` 中展示对应条目：
* `ed_final_good`：`【终局·真血自立】恶龙艾德现身，古兰觉醒超凡真血以命立誓正面逼退恶龙，保全自我意志守护小队。`
* `ed_final_abduction`：`【终局·以命相挟】恶龙艾德现身，古兰以死要挟换取小队众人生路，被迫随龙王回巢繁衍。`
* `ed_final_dark`：`【终局·始祖同化】古兰真血封顶并沉沦于始祖本能，化作金红龙瞳跟随生父回归龙巢。`
