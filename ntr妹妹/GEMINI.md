## 一、设计宪法（核心定稿，不得重议）

1. **效果只认标签**：凡加减益走后台标签栈，叙事口说无效（防 LLM 口胡）。
2. **故事描写后台定果**：LLM 只申报事实，骰子、修正、结算全在中控单一真源。
3. **一切结算汇于状态栏**：插件是器官，状态栏是壳，中控单一真源。状态栏统筹常驻条、抽屉、深页、设备面板与结算台。
4. **LLM 出场判据是「有戏没戏」**：例行走插件（探索、日常检定、例行结算）零楼数零 token；只有出现实质剧情、对话交互、节点事件才请 LLM 进场。
5. **系统做减法**：保留核心载体，避免冗余设计。
6. **Token 与性能纪律**：开发 token 同样是成本，必须纸面先行、公式推演到位、一次做对。玩家可见层严禁开发黑话，使用通俗人话。
7. **动作与标签全量注册**：讨论与设计中提到的每一个动作（如潜行、施法、破拆、交涉、搏斗等）与标签（如紧绷、恍惚、压制等），必须在后台词表/Schema（随状态机脚本内置，如 `sm_schema.js`）与规则/标签栈中全量注册，严禁口头存在黑户。
8. **严禁口头设定，凡讨论必对后台**：策划、交流与机制推演中，严禁使用模糊的自然语言主观臆断效果；所有性格、爱好、特征与交互，必须能直接映射为后台真实字段与代码管道（Tag ID、Category 分类、数值修正 Value、检定 DC 钩子、物证道具与 HUD 展现契约）。杜绝模型口胡乱编，凡无法落入规则、词表与引擎真源的概念，一律不得作为机制依据。

## 三、工程复盘与错误归因戒律（真机交互经验）

1. **数据结构重构全量检索防悬空**：
   - **典型教训**：数据结构重构后，部分逻辑残留旧字段访问，在脚本顶层抛出未捕获 `TypeError`，直接阻断后续全部事件监听器注册，导致前端交互完全失效。
   - **执行防线**：修改任何配置、状态字段或全局常量规格后，必须在全局（含脚本与状态栏 HTML）全量检索旧字段名；修改前端脚本后必须运行执行测试，验证零报错方可交付。
2. **热更新清理机制禁设拦截死锁**：
   - **典型教训**：打包脚本中写死判断已存在节点即 return，导致真机测试中覆盖新代码时，检测到旧 DOM 存在直接退出，既有旧节点无法被替换，新修复代码无法生效。
   - **执行防线**：嵌入式状态栏挂载逻辑必须采用「先清理旧节点，再挂载新闭包」的热插拔模式，严禁使用直接 return 的拦截逻辑阻断更新。
3. **原生嵌入非核心 DOM 判空防护**：
   - **典型教训**：状态栏提取进入酒馆时仅打包主结构，若脚本直接访问仅在预览外部存在的元素，未判空即抛空指针异常，造成快照渲染中断。
   - **执行防线**：状态栏脚本内所有 DOM 获取与属性赋值，一律采用判空守卫（`const el = document.getElementById(...); if (el) ...`）或安全可选链，非核心辅助展示绝不可阻断核心数据流与交互闭环。
4. **动作与输入解耦铁律（胶囊代码单一真源）**：
   - **典型教训**：前端胶囊传下结构化动作对象后，若将其退化拼装为文本字符串并调用正则重新猜测，一旦名称不匹配即丢弃动作，导致“选了动作却结算 0 个”的严重偏差。
   - **执行防线**：前端传递的结构化动作对象必须直通中控执行引擎（`opts.actions -> _actionQueue -> settleAction`），严禁将结构化数据降级拼装为文本再走反向猜词；输入框自然语言纯作伴随文学描写，绝不参与动作判定。
5. **静态文本越权侵入动态中控管辖区（静态与动态状态机边界铁律）**：
   - **错误类型本质**：静态开场白或常驻系统提示词越俎代庖，硬编码本应由中控引擎负责动态抽样与管辖的数据槽位参数（如具体服饰细节、肢体行为、身心状态），导致静态文本抢跑中控职权，与后续动态回执产生数据竞争、语义冲突与状态穿帮。
   - **执行防线**：静态文本只负责客观宏观环境底色、时空物理定位与远景留白剪影；所有涉及个体的微观具象表征（着装、双手、身心），必须且只能由后台规则与实体台账真源通过回执流动态驱动，严禁静态层抢跑越权。
6. **外部依赖缺件先清点再动工**：
   - **典型教训**：外部依赖要求配套文件齐备，清点不严容易直到打包阶段才暴露缺失。
   - **执行防线**：任何第三方插件或配套组件接入前，先按清单逐项核对在位状态，登记在案，不得带缺件进入打包流程。
