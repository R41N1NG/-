# 第一步 · 在酒馆里验证

> 目的：确认这两个脚本在你的酒馆里能正常存东西、取东西。
> 花不了两分钟，但不做这一步，后面全白搭。

---

## 一、装

1. 打开酒馆，点侧边栏的 **酒馆助手**（Tavern Helper）
2. 找到 **脚本库**，点 **新建**
3. 建第一个，名字随便写，比如 `OKH-Boot`
   - 打开 `tavern_scripts/0_okh_boot.js`，**全选复制**，粘进去
4. 再建第二个，名字叫 `OKH-Core`
   - 打开 `tavern_scripts/1_okh_core.js`，**全选复制**，粘进去
5. **顺序很重要**：让 `OKH-Boot` 排在 `OKH-Core` 前面（脚本列表里可以拖）

> 顺序错了不会炸，但 core 会报一句「注册表不存在」，看到这句就说明顺序反了。

---

## 二、验

1. 按 `F12` 打开浏览器控制台
2. 如果已经在聊天里，**刷新一下页面**（脚本要重新加载）
3. 控制台里应该出现两行：

```
[OKH] 注册表已建立 · v0.1.0
[OKH] core 已就绪 · 存储模式：tavern
```

**看到这两行，就成了一半。**

注意第二行写的是 `tavern`（不是 `memory`）。写 `memory` 说明没连上酒馆的变量池，那存的东西刷新就没了。

---

## 三、再验一次真的能存

在控制台里粘这段，回车：

```js
const c = window.__OKH__.modules.core
c.write('test.hello', '你好')
console.log('读回来：', c.read('test.hello'))
```

应该打印：

```
读回来： 你好
```

再刷新一次页面，粘这段：

```js
console.log('刷新后还在吗：', window.__OKH__.modules.core.read('test.hello'))
```

还是 `你好` —— **说明真的存进存档里了**，不是存在内存里。

---

## 四、出问题怎么查

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 控制台一片空白，两行都没有 | 脚本没启用 | 检查脚本前面的开关是不是关的 |
| 只有 Boot 那行，没有 Core | Core 脚本没加载 | 检查顺序，或者脚本里有没有语法错误 |
| 显示 `存储模式：memory` | `getvar` 用不了 | 换个酒馆助手版本，或者看下 API 名字改了没 |
| 刷新后读不到 | 变量没存进存档 | 同上，多半是模式不对 |
| 报了红色错 | 复制时漏字符 | 重新全选复制一次 |

---

## 五、这一步做完了意味着什么

- 有了一个「盒子」，所有数据都能往里放
- 刷新页面数据不丢（因为你保存在存档里）
- 后面所有角色状态、时间、事件，都往这个盒子里塞
