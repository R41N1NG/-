# 实现方案 · 角色自主行动系统

> **对应要求**：后台脚本控制每个角色的自主行动，按预设行为自主发展
> **技术环境**：SillyTavern + Tavern Helper（酒馆助手）
> **架构准绳**：`角色卡通用架构搭建规范.md`、`设定_中控架构与状态栏规范.md`
> **设计依据**：`系统_角色自主行动设计.md`、`系统_出场与推演接入范例卡规范.md`

---

## 一、先划清技术边界

在动手之前必须知道：酒馆脚本**能做什么、不能做什么**。

| 能做 | 不能做 |
|---|---|
| 读写变量池（`getvar` / `setvar`） | 直接操作文件系统 |
| 挂钩消息事件（收到/发送/生成前后） | 后台常驻定时器（页面关了就停） |
| 修改 DOM（渲染 HUD） | 主动调用 LLM（只能靠触发对话） |
| 触发 slash 命令 | 读取世界书全文（只能通过变量间接） |
| 持久化到聊天元数据 | 跨聊天共享状态（除非用全局变量） |

**最关键的一条**：脚本**没有真正的后台**。只能在「用户发消息」或「AI 回复」这些事件上挂钩子。

所以「自主行动」的实现方式不是「一直在跑」，而是：

```
每轮对话结束 → 钩子触发 → 检查时间是否跨了时段 → 跨了就推演一次
```

**推演是离散的，不是连续的。** 这符合叙事节奏，也不吃性能。

---

## 二、落点：只碰三个 API

| API | 用途 | 调用时机 |
|---|---|---|
| `eventOn(tavern_events.MESSAGE_RECEIVED, fn)` | 解析 AI 申报 + 触发推演 | 每轮 AI 回复后 |
| `getvar(key)` / `setvar(key, val)` | 读写变量池 | 全程 |
| DOM 操作（`document.querySelector`） | 渲染 HUD | 推演后 |

> 不同版本的 Tavern Helper API 名称可能略有差异。若 `eventOn` 不存在，用 `eventOnButton` / `SillyTavern.getContext().eventSource.on(...)` 代替，逻辑不变。

## 三、文件结构

浏览器环境没有 `import` 的模块解析（除非把脚本托管到可访问地址）。酒馆生态的通行做法是**多脚本 + 全局注册表**。

```
Tavern Helper 脚本列表（按顺序加载）：
├─ 0. okh_boot.js        初始化全局注册表 window.__OKH__
├─ 1. okh_core.js        变量读写封装
├─ 2. okh_schema.js      角色/行动/状态的结构定义与校验
├─ 3. okh_rules.js       纯函数判定（可用行动、底线）
├─ 4. okh_agency.js      决策：效用打分
├─ 5. okh_presence.js    出场判定：四闸门（内部）
├─ 6. okh_translate.js   数值 → char_d1 文本
├─ 7. okh_turn.js        主入口：事件钩子 + 时序编排
└─ 8. okh_hud.js         HUD 渲染
```

**加载顺序即依赖顺序。** 后加载的可以调前面注册的模块，反之不行。

### 3.1 全局注册表长这样

```js
// okh_boot.js
window.__OKH__ = window.__OKH__ || { version: '0.1.0', modules: {} }
```

每个模块注册自己：

```js
// okh_rules.js
window.__OKH__.modules.rules = { available, lineHolds, activeLines }
```

调用时：

```js
const { rules, agency } = window.__OKH__.modules
```

### 3.2 和代码规范的关系

`角色卡制作规范.md` 里的 `src/state/*.js` 是 **Node 环境**的路径。酒馆脚本是**浏览器环境**，落地方式不同，但**模块划分、依赖方向、职责边界完全一致**。

`check-deps.js` 在浏览器里跑不了（没有 `fs`），改成**开发期静态检查**：

```
node scripts/check-deps.js --scan tavern_scripts/
```

扫描每个脚本里 `__OKH__.modules.xxx` 的引用，比对允许的依赖方向。

## 四、核心骨架

### 4.1 okh_core.js —— 变量读写

```js
(function () {
  const PREFIX = 'okh'

  /**
   * 读变量，带默认值
   * @param {string} path 点路径，如 'npc.aurora.corruption'
   * @param {any} fallback
   * @returns {any}
   */
  function read(path, fallback = null) {
    const v = getvar(`${PREFIX}.${path}`)
    return (v === undefined || v === null) ? fallback : v
  }

  /**
   * 写变量
   * @param {string} path
   * @param {any} value
   */
  function write(path, value) {
    setvar(`${PREFIX}.${path}`, value)
  }

  window.__OKH__.modules.core = { read, write }
})()
```

> `getvar` / `setvar` 是 Tavern Helper 提供的全局函数，直接可用。

### 4.2 okh_rules.js —— 纯函数判定

```js
(function () {
  const M = () => window.__OKH__.modules

  /**
   * 解析 "<30" / ">=2" 这类条件
   */
  function test(value, expr) {
    const m = /^([<>]=?)(-?\d+)$/.exec(String(expr).trim())
    if (!m) return false
    const [, op, n] = m
    const v = Number(value), t = Number(n)
    return op === '<'  ? v <  t
         : op === '<=' ? v <= t
         : op === '>'  ? v >  t
         :               v >= t
  }

  /**
   * 底线是否仍然有效
   */
  function lineHolds(line, char) {
    for (const [k, expr] of Object.entries(line.holdsWhile)) {
      const v = k === 'corruption' ? char.corruption : (char.drives[k] ?? 0)
      if (!test(v, expr)) return false
    }
    return true
  }

  /**
   * 当前生效的底线 id
   */
  function activeLines(char) {
    return char.lines.filter(l => lineHolds(l, char)).map(l => l.id)
  }

  /**
   * 筛选可用行动
   * @returns {{ok: Array, blocked: Array}}
   */
  function available(char, pool) {
    const lines = activeLines(char)
    const ok = [], blocked = []
    for (const a of pool) {
      let pass = true
      for (const [k, e] of Object.entries(a.requires?.drives || {})) {
        if (!test(char.drives[k] ?? 0, e)) { pass = false; break }
      }
      if (pass && a.requires?.corruption && !test(char.corruption, a.requires.corruption)) {
        pass = false
      }
      if (!pass) continue
      const hit = (a.blockedBy || []).filter(id => lines.includes(id))
      hit.length ? blocked.push({ action: a, by: hit }) : ok.push(a)
    }
    return { ok, blocked }
  }

  M().rules = { test, lineHolds, activeLines, available }
})()
```

### 4.3 okh_agency.js —— 决策

```js
(function () {
  const CFG = {
    inertiaPerRepeat: 0.25, inertiaCap: 4,
    idlePerTurn: 0.15,      idleCap: 6,
    noiseRange: 0.2
  }

  const countOf = (c, id) => c.history.filter(h => h === id).length
  const idleOf = (c, id) => {
    const i = c.history.lastIndexOf(id)
    return i < 0 ? CFG.idleCap : Math.min(c.history.length - 1 - i, CFG.idleCap)
  }

  /**
   * 单行动打分
   */
  function score(action, char, rnd) {
    const inertia = 1 + CFG.inertiaPerRepeat * Math.min(countOf(char, action.id), CFG.inertiaCap)
    const idleBoost = 1 + CFG.idlePerTurn * Math.min(idleOf(char, action.id), CFG.idleCap)

    let mod = 1
    if ((char.drives.need ?? 0) > 60 && /shift|dinner|gift|touch/.test(action.id)) mod *= 1.4
    if ((char.drives.shame ?? 0) > 60 && /gift|touch/.test(action.id)) mod *= 0.8
    if ((char.drives.curiosity ?? 0) > 60 && /casino/.test(action.id)) mod *= 1.3
    if (char.corruption >= 30 && /gift|touch/.test(action.id)) mod *= 1.4

    const noise = 1 - CFG.noiseRange + rnd * CFG.noiseRange * 2
    return { id: action.id, score: action.base * mod * inertia * idleBoost * noise }
  }

  /**
   * 加权随机选一个
   */
  function pickWeighted(scored, rnd) {
    const total = scored.reduce((s, c) => s + c.score, 0)
    if (total <= 0) return null
    let acc = 0
    const target = rnd * total
    for (const c of scored) { acc += c.score; if (target <= acc) return c }
    return scored[scored.length - 1]
  }

  /**
   * 完整决策：筛 → 打分 → 选
   * @returns {{action: object|null, scored: Array, blocked: Array}}
   */
  function decide(char, pool, rndFn) {
    const { rules } = window.__OKH__.modules
    const { ok, blocked } = rules.available(char, pool)
    if (!ok.length) return { action: null, scored: [], blocked }
    const scored = ok.map(a => {
      const s = score(a, char, rndFn())
      return { ...s, action: a }
    }).sort((x, y) => y.score - x.score)
    const chosen = pickWeighted(scored, rndFn())
    return { action: chosen?.action || null, scored, blocked }
  }

  window.__OKH__.modules.agency = { decide, score }
})()
```

### 4.4 okh_translate.js —— 数值转文本（关键）

```js
(function () {
  /**
   * corruption → char_d1 追加描述
   * 每档 ≤40 字，作为段落追加，不替换原文
   */
  const BANDS = [
    { max: 29,  text: '她最近总是很晚才回来，问起只说活多。' },
    { max: 54,  text: '她开始避开伯里的目光，说话时会突然停住。' },
    { max: 79,  text: '她已经不太解释了，只是把挣来的钱放下就走。' },
    { max: 100, text: '她不再提以前的事，仿佛那些从没发生过。' }
  ]

  /**
   * 取当前堕落档的描述
   * @param {number} corruption 0-100
   * @returns {string}
   */
  function band(corruption) {
    return (BANDS.find(b => corruption <= b.max) || BANDS[BANDS.length - 1]).text
  }

  /**
   * 覆盖 char_d1_{id}：保留原心智指南，末尾追加堕落描述
   * @param {string} id
   * @param {object} char
   */
  function writeCharD1(id, char) {
    const { core } = window.__OKH__.modules
    const base = core.read(`base_d1.${id}`, '')      // 原始心智指南（静态，不覆盖）
    const extra = band(char.corruption)
    core.write(`char_d1_${id}`, base ? `${base}\n【近期状态】${extra}` : `【近期状态】${extra}`)
  }

  window.__OKH__.modules.translate = { band, writeCharD1 }
})()
```

> **为什么用 `base_d1` 存原文**：`char_d1_{id}` 每次被覆盖，原文不能丢。所以初始化时把静态心智指南存一份到 `okh.base_d1.{id}`，每次渲染都从它拼出来。

### 4.5 okh_presence.js —— 出场判定（内部）

```js
(function () {
  const MAX_ON_STAGE = 3

  /**
   * 算在场名单
   * @param {object[]} npcs
   * @param {object} ctx { roomId, phase, flags }
   * @returns {object[]} 在场角色（≤MAX_ON_STAGE）
   */
  function resolve(npcs, ctx) {
    const cand = []
    for (const n of npcs) {
      if (!n.alive) continue
      if (n.room_id !== ctx.roomId) continue                    // 闸门1 空间
      const allow = n.schedule?.[ctx.phase]
      if (allow && !allow.includes(n.room_id)) continue         // 闸门2 日程
      if (n.absent?.flags && Object.entries(n.absent.flags)
            .every(([k, v]) => ctx.flags[k] === v)) continue    // 缺席优先
      cand.push(n)
    }
    cand.sort((a, b) => (b.priority ?? 0) - (a.priority ?? 0))  // 闸门4 戏剧
    return cand.slice(0, MAX_ON_STAGE)
  }

  window.__OKH__.modules.presence = { resolve }
})()
```

### 4.6 okh_turn.js —— 主入口（最重要的一个）

```js
(function () {
  const { core, agency, presence, translate } = window.__OKH__.modules

  const PHASES = [
    { name: 'deep_night', from: 0,    to: 360   },
    { name: 'morning',    from: 360,  to: 600   },
    { name: 'afternoon',  from: 600,  to: 1020  },
    { name: 'night',      from: 1020, to: 1380  },
    { name: 'deep_night', from: 1380, to: 1440  }
  ]

  /**
   * 由当日分钟数推时段
   * @param {number} totalMin
   * @returns {string}
   */
  function derivePhase(totalMin) {
    const m = ((totalMin % 1440) + 1440) % 1440
    return (PHASES.find(p => m >= p.from && m < p.to) || PHASES[0]).name
  }

  /**
   * 从 AI 消息里解析 <time elapsed="30" end="1日08:30" />
   * @param {string} text
   * @returns {number|null} 分钟数
   */
  function parseElapsed(text) {
    const m = /<time[^>]*\belapsed="(\d+)"/.exec(text)
    return m ? Number(m[1]) : null
  }

  /**
   * 跑一轮推演
   */
  function runTurn() {
    const npcs = core.read('npcs', {})
    const playerRoom = core.read('player.room_id', 'inn')
    const phase = core.read('sys.phase', 'morning')
    const flags = core.read('world.flags', {})
    const rnd = Math.random

    for (const [id, char] of Object.entries(npcs)) {
      if (!char.alive) continue
      const pool = core.read(`actions.${id}`, [])
      const { action } = agency.decide(char, pool, rnd)
      if (!action) continue

      // 结算
      for (const [k, v] of Object.entries(action.effects?.drives || {})) {
        char.drives[k] = Math.max(0, Math.min(100, (char.drives[k] ?? 0) + v))
      }
      if (action.effects?.corruption) {
        char.corruption = Math.min(100, char.corruption + action.effects.corruption)
      }
      if (action.effects?.location) char.room_id = action.effects.location

      char.history = (char.history || []).concat(action.id).slice(-30)
      npcs[id] = char

      translate.writeCharD1(id, char)
    }

    // 在场
    const present = presence.resolve(Object.values(npcs), {
      roomId: playerRoom, phase, flags
    })

    core.write('npcs', npcs)
    core.write('present', present.map(n => n.id))
    core.write('sys.lastTurnAt', core.read('sys.total_min', 0))

    renderHud(present)
  }

  /**
   * HUD 渲染（只填已有字段，不改布局）
   */
  function renderHud(present) {
    const el = document.querySelector('[data-okh-presence]')
    if (!el) return
    el.textContent = present.length
      ? present.map(n => `${n.name}（${n.cue || '在场'}）`).join('｜')
      : '无'
  }

  /**
   * 消息钩子：解析申报 → 累加时间 → 必要时推演
   */
  function onMessageReceived() {
    const { eventSource } = SillyTavern.getContext()
    // 取最后一条 AI 消息
    const ctx = SillyTavern.getContext()
    const last = ctx.chat?.[ctx.chat.length - 1]
    if (!last || last.is_user) return

    const elapsed = parseElapsed(last.mes || '')
    if (elapsed === null) return

    const before = core.read('sys.total_min', 0)
    const after = before + elapsed
    core.write('sys.total_min', after)

    const oldPhase = core.read('sys.phase', null)
    const newPhase = derivePhase(after)
    core.write('sys.phase', newPhase)

    if (oldPhase !== newPhase) runTurn()      // 跨时段才推演
  }

  // 挂载
  if (window.__OKH__?.ready) {
    eventOn(tavern_events.MESSAGE_RECEIVED, onMessageReceived)
  } else {
    console.warn('[OKH] 模块未就绪，推演系统未启用')
  }

  window.__OKH__.modules.turn = { runTurn, derivePhase, parseElapsed }
})()
```

## 五、时序总览

```
用户发消息
    ↓
LLM 生成 <content> + <status_bar>
    ↓
[MESSAGE_RECEIVED 钩子]
    ├─ 解析 <time elapsed>
    ├─ total_min += elapsed
    ├─ phase = derivePhase(total_min)
    └─ if (phase 变了) runTurn()
          ├─ 每个角色：decide → 结算 → 写 room_id / corruption
          ├─ 翻译 corruption → char_d1_{id}
          ├─ presence.resolve → present[]
          ├─ 写回变量池
          └─ renderHud(present)
    ↓
下一轮生成时，世界书读 {{getvar::char_d1_id}} 拿到新文本
```

## 八、风险与退路

| 风险 | 表现 | 退路 |
|---|---|---|
| **`<time>` 缺失** | AI 不申报时间，系统不推进 | 兜底：每 N 轮强制 +15 分钟 |
| **变量池写失败** | 报错或静默丢数据 | 每次写入后回读校验，失败则降级为内存态 |
| **API 版本差异** | `eventOn` 不存在 | 用 `SillyTavern.getContext().eventSource.on()` |
| **推演太频繁** | 每轮都跑，卡顿 | 只在跨时段跑（已实现），必要时加节流 |
| **角色行为全一样** | 因为行动库是同一套模板 | 每个角色的池子必须单独配置，不能共用 |
| **AI 擅自改状态** | LLM 在正文里写"她堕落度提升了" | 数值只认脚本，正文里的文字不作为输入 |

## 九、和范例卡的接口对照

| 我们的东西 | 范例卡对接点 | 方式 |
|---|---|---|
| `okh.sys.total_min` | `<time elapsed>` | 脚本累加，AI 只申报增量 |
| `okh.player.room_id` | 状态栏 `【坐标】` | 从 `<move to>` 解析 |
| `okh.npcs[id].room_id` | 状态栏 `【在场】` | 脚本判定，渲染进 HUD |
| `okh.char_d1_{id}` | 世界书条目 A 的 `{{getvar::char_d1_id}}` | 变量覆盖，条目自动生效 |
| `present[]` | HUD `【在场】` | 直接改 DOM |
| `corruption` | **不进契约** | 翻译成文本，只出现在 `char_d1` 里 |

**没有任何一处新增标签、条目或字段。全部落在已有容器。**
