## 一、冒险者公会五阶体系

### 1.1 核心设计原则
1. **代码侧极简职责**：小队公会等级**仅影响委托任务的接取门槛**（挂于 `world.tags`，累计功绩存于 `world.playerState.guild_merit`，状态栏 HUD 展示当前阶位与功绩进度）。
2. **同行名额脱钩等级**：每次委托的同行名额（`partyLimit`）由具体任务自身规定，不受小队等级限制。
3. **古兰随行边界**：古兰的随行**不占常规同行名额**；非特殊情况不出手；没有和龙族相关的遗迹不参与。
4. **爱德跑腿独立性**：爱德的后台跑腿与急件截取能力源自玩家日常训练与信任，与公会等级无关。
5. **功绩规则**：
   - 升级门槛（累计功绩）：`20 / 60 / 120 / 200`（每阶增量 $\Delta M(R) = 20 \times R$）。
   - 单项产出：普通正式委托 `+10`、进阶 / 浅层遗迹 `+20`、高危 / 大型深层遗迹 `+35`；爱德后台跑腿 `0` 功绩。失败不扣已有等级，当次得 `0` 功绩。

### 2.3 六阶细分条目（按关键词触发）

- **条目 02-B1【战力细分·I 阶凡俗阶】**（参考当量 1）
  - 物理近战：仅凭本能与粗浅蛮力挥砍，无步法与格挡章法，面对正规兵刃极易溃败。
  - 游侠斥候：仅具备基础野外辨向与粗浅躲藏能力，难以应对专业追踪与隐蔽陷阱。
  - 奥术施法：魔力微弱，仅能催动照明、生火等生活戏法，无法构成实质杀伤或防御。
  - 神术神官：仅能念诵基础安神祷言与调配常规草药，尚无法引动实质神圣疗愈或驱散术式。
  - 常见怪物锚定（最普通种类下限）：普通史莱姆、普通哥布林、普通骷髅兵、荒原野犬、巨鼠。

- **条目 02-B2【战力细分·II 阶正规阶】**（参考当量 3）
  - 物理近战：动作沉稳、懂基本攻防与阵型掩护，能稳压未受训的凡俗者，正面招架同阶对手；但要害受创同样致命。
  - 游侠斥候：精通潜行跟踪、常规机关拆解与弓弩匕首暗袭，能在复杂地形中周旋脱身。
  - 奥术施法：魔力回路稳固，能在安全距离吟唱成型攻击与防护术式（穿甲飞弹、基础力场护盾），并辨识常规魔纹与法术陷阱。
  - 神术神官：能引动实效神圣治愈（闭合中轻度创伤）、驱散轻度瘴气与精神动摇，是队伍续航与抗污染的中坚；正面格斗能力仍弱。
  - 常见怪物锚定（最普通种类下限）：普通兽人、普通石像鬼、普通食尸鬼、荒原座狼、狗头人战士。

- **条目 02-B3【战力细分·III 阶精锐阶】**（参考当量 12，大部分凡人训练极限）
  - 物理近战：力量、耐力或爆发速度明显高出常人，能破开常规铁甲或锁死低阶对手关节，正面拆解普通小队合围。
  - 游侠斥候：具备高速突刺、敏锐的危险直觉与复杂暗锁、毒物处理能力，擅长在混战中一击脱离或反制警戒。
  - 奥术施法：魔力密度厚实，可施展中阶范围打击、复合魔纹解离或短时快速施法，能正面击溃低魔抗的物理阵线。
  - 神术神官：可施展大范围神圣庇护、强效净化古代诅咒与剧毒，并能在战局中稳固全队心智抵抗精神侵蚀。
  - 常见怪物锚定（最普通种类下限）：普通亚龙（双足飞龙、地行亚龙）、格雷姆石像、兽人重步兵与战狼骑兵、普通巨魔、死灵骑士。

- **条目 02-B4【战力细分·IV 阶宗师阶】**（参考当量 100，少数天赋与机缘者可达）
  - 物理近战：剑风力道可裂石断木，能正面撕开大股正规披甲士卒的合围，寻常木铁盾牌难挡其重击。
  - 游侠斥候：身法隐蔽难测，可在复杂环境中无声穿透严密防线，精准猎杀高戒备目标。
  - 奥术施法：掌握高阶大型术式与精密魔网干涉，具备独自摧毁小型据点或压制常规军阵的火力，并能构筑强力结界。
  - 神术神官：神恩共鸣深厚，能抚平濒死重创、大规模净化区域污秽与上位异兆压迫。
  - 常见怪物锚定（最普通种类下限）：普通成年巨龙、普通巫妖、高阶恶魔将领、成年奇美拉、高阶魔导巨像。

- **条目 02-B5【战力细分·V 阶超凡阶】**（参考当量 300，世间罕有，精锐及以下数量难成威胁）
  - 物理近战：护体气血胜过精钢，常规刀剑箭矢难以破防，举手投足蕴含破城级破坏力。
  - 游侠斥候：遁形匿迹接近自然法则，能避开常规魔导侦测，千里奔袭与一击绝杀难被凡俗捕捉。
  - 奥术施法：魔力屏障与高阶术式规模超越常规防御极限，可改写局部战场地形与气候，压制百人军阵。
  - 神术神官：可降下覆盖整个战场的神圣结界与群体复苏恩典，直接抗衡上位魔力天灾或深渊侵蚀。
  - 常见怪物锚定（最普通种类下限）：上位古龙、大巫妖、深渊大领主、远古守护构装体。

- **条目 02-B6【战力细分·VI 阶神话阶】**（参考当量 2000，仅存于故事与传说）
  - 通用表现：生命阶位远超凡俗尺度，存在本身即带有上位法则与血脉威压（收敛隐匿时不触发），具备倾覆城邦与改易地貌的尺度，无法以现世常规战力与人数堆砌衡定。
  - 传说锚定：太古源初真龙、神话魔神、创世级泰坦。

### 3.2 第二类：职业 Tag（`category: 'class'`，含 1～5 阶进阶）

- **复合职业判定规则**：
  - 同一角色可同时拥有多个子职业 Tag（例如 `class_heavy_vanguard2` + `class_trap_breaker1`）；
  - **角色战力阶位**：取所有职业 Tag 中的**最高阶位**（上例为 II 阶正规阶）；
  - **四维加成聚合**：同一角色各职业 Tag 对**同一属性**的加成**取最大值（`max`）**，不同属性可分别取各自最高值（上例为 `力+2, 敏+1`），防止同系多职业刷爆属性。
- **阶位统一增量梯度（1～5 阶）**：主属性 `+1 / +2 / +4 / +8 / +15`；特定双修副属性 `+0 / +1 / +2 / +4 / +7`。

## 四、通用解法判定与角色组装规范（供 LLM 呈现）

1. **小队属性取样**：面对障碍的 `solutions`（如 `力 >= 5` 或 `智 >= 3` 或 `class_trap_breaker >= 3`）时，后台取**当前同行者中的单人最高值**比对，不搞多人累加。
2. **后台 → LLM 呈现原则**：
   - 世界书（通用法则 + 静态人设）与后台 `buildLedger` 分工合作：外貌、着装、口癖留在世界书；
   - 后台把角色当前有效的种族、**复合职业专长（含战力阶位）**、特质及后台判定出的事件结果，**全部翻译成自然人话**注入台账，**不向模型或玩家暴露英文 Tag ID 与四维数字**。
3. **古兰组装示例**：
   - 后台登记：`race_dragonkin` + `class_heavy_vanguard4` + `trait_dragon_awakening` + `trait_blood_resonance_weak`（常态聚合成 IV 阶宗师、力 12）。
   - 喂给 LLM 的台账人话：位置与动向、好感与血脉浓度、能力底牌（半龙人，IV 阶宗师重剑士，留有血脉激发底牌，受上位显性龙血压迫），以及本轮后台算出的障碍结果。
