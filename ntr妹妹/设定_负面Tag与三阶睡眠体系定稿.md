## 一、挂载口径与呈现原则（方案 B）

1. **统一挂载至 `world.tags`**：
   - 在 `okh_app_tags.js` 校验与 `okh_app_migrate.js` 迁移白名单中，将 `'player'` 设为合法保留主体；
   - 主角 {{user}}（`world.tags.player`）与所有已登记 NPC（`world.tags[npcId]`）统一收归 `world.tags` 管理，走同一套读取、结算与渲染链路。
2. **开放触发源与人话翻译**：
   - 通用状态 Tag **不锁死触发来源**，任何战斗、陷阱、法术、药物或日常/暗线事件均可按需调用 `applyTags` 挂载；
   - 所有条目设为 `visibility: 'public'`，通过 `buildLedger` 将当前状态效果与行动边界翻译为自然人话注入台账，不向模型或玩家暴露英文 Tag ID 与四维数值。

## 二、通用负面 Tag 字典（7 项）

| Tag ID | 名称 | 后台机制效果（四维与行为约束） | 解除条件 |
|---|---|---|---|
| `debuff_light_wound` | **轻伤** | **`力 -1, 敏 -1`**（四维保底 `1`）；在轻伤状态下再次受创时，直接升级为重伤 | ① `class_holy_heal >= 2` 治愈；<br>② 在旅店安稳休养过夜 `1` 晚 |
| `debuff_heavy_wound` | **重伤** | **全四维 `-2`**、**有效战斗阶位 `-1` 阶**（最低 I 阶）；禁止作为障碍硬解领头人 | 不可野外自愈，须回镇：<br>① 找 `class_holy_heal >= 3`（如塞西莉亚）救治并支付 **`10` 金** 药费；<br>② **或**在旅店连续休养 `3` 天（期间不可外出接战） |
| `debuff_bleeding` | **流血** | **`力 -1`**；持续失血，若连续 `2` 个时段未止血则附加/升级伤势（无伤→轻伤，轻伤→重伤） | 及时止血即清除（消耗 `1` 份 `supply` 包扎、`class_holy_heal >= 1` 或基础药剂） |
| `debuff_poisoned` | **中毒** | **`力 -1, 敏 -1, 智 -1`**；旅店普通睡觉**无法自愈**，每持续 `24` 小时未解毒则恶化伤势 | `class_purify_ward >= 2` 净化、`class_elixir_alchemist >= 2` 或城镇药铺购药解毒 |
| `debuff_paralyzed` | **麻痹** | **`敏 -2`**，肢体僵直；**禁止担任潜行、拆锁、远程点射、游斗或前排格挡手，且无法完成需手势的成型施法** | 脱离当前冲突并经过 `1` 个时段自然消退，或神官/药剂解除 |
| `debuff_exhausted` | **疲惫** | **`力 -1, 敏 -1`**（体力透支、动作迟滞） | 安全区或营地消耗 `1` 份 `supply` 休息 `1` 个时段清除 |
| `debuff_starving` | **断粮缺药** | **全四维 `-1`**，荒原/遗迹中禁止深入未知区域；持续超 `24` 小时附加 `轻伤` | 补足并消耗正常 `supply`（1 份/人）并经过一次休息清除 |

## 三、三阶睡眠状态字典（3 项）

睡眠体系贯通**日常作息（夜间进房互动、潜入、扎营）**与**战斗/药效控制**，按警觉度分为三阶：

| Tag ID | 名称 | 典型场景 | 后台行为与警觉边界 | 解除与唤醒条件 |
|---|---|---|---|---|
| `status_sleep_light` | **轻眠** | 野外扎营轮休、白天午休小憩 | **浅睡保持警觉**：无法主动观察周围；若睡眠中突遭袭击仅丧失先手（初动受限），不会任人摆布 | **极易惊醒**：稍大脚步声、门锁轻响、低声呼唤或微弱魔力波动即立刻惊醒并清除；休息时段结束自动清除 |
| `status_sleep_deep` | **深眠** | 安全区（旅店/修道院/山庄等）日常夜间入睡 | **意识沉入熟睡**：轻手轻脚的推门、靠近、低语或轻微触碰**不会立刻惊醒** | **中度刺激唤醒**：大声呼唤、剧烈摇晃、强光直射或痛感会惊醒并清除；清晨醒来时段自动清除 |
| `status_sleep_comatose` | **沉眠** | 睡眠药水、催眠卷轴、催眠术、致睡魔物攻击 | **强行深度昏睡（负面控制）**：行动力归零，完全失去对外界常规刺激的感知与反抗能力，处于无防备状态 | **常规刺激无法唤醒**（摇晃/呼喊/轻触均无效）；仅能：① 等待药效/术式时限结束；② 神官驱散或解药；③ 遭受足以造成实伤的强力痛击惊醒 |
