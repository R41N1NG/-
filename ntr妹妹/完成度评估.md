## 二、三个阻塞项（不做就没法玩）

### 阻塞 1 · 世界书读的变量，系统不写 ⛔

**世界书里**（`03_小队全员档案.md` 等）：

```
{{getvar::char_d1_gulan}}
{{getvar::char_d3_gulan}}
{{getvar::char_d1_isna}}
...
```

**系统实际写的**：

```
okh_gpt.state.v1:<chatId>   ← 完整世界状态（JSON）
okh_gpt.ledger              ← 台账
okh_gpt.pendingText         ← 待演绎
okh_gpt.watch               ← 监听
```

**`char_d1_*` / `char_d3_*` 一个都不存在。**

**后果**：世界书里所有角色条目加载时都是**空白**。AI 看到「<角色档案_古兰_心智>（空）</角色档案_古兰_心智>」。

**两个解决方向**：

| 方案 | 做法 | 代价 |
|---|---|---|
| A | 系统加一层导出，把角色状态写成 `char_d1_xxx` | 要改代码，但一次解决 |
| B | 改世界书，把变量引用换成直接写内容 | 要动主人写的 26 项条目 |

**肥鱼建议 A**——世界书是主人的劳动成果，不动它。

### 阻塞 2 · 没有「当前局势」台账条目 ⛔

世界书里有静态总纲、场景、角色双轨，但**没有一条读 `okh_gpt.ledger`**。

**后果**：AI 不知道现在第几天、什么时段、玩家在哪、谁在场。

**解决**：加一条常驻条目：

```xml
<当前局势>
{{getvar::okh_gpt.ledger}}
</当前局势>
```

### 阻塞 3 · 从没在真酒馆跑过 ⛔

所有测试都是 Node + vm 模拟宿主。三个 API 没验证过：

| API | 用途 | 不成立会怎样 |
|---|---|---|
| `getVariables` / `replaceVariables` 或 `getvar` / `setvar` | 存档 | 数据不落盘 |
| `eventOn` / `tavern_events` | 消息钩子 | 不会自动推进 |
| `setExtensionPrompt` | 事件注入 | AI 看不到待演绎事件 |
