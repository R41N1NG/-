## 一、核心宪章与设计原则

1. **单一整金账本（系统做减法）**：
   - 全卡后台仅维护单一整型资金字段 **`world.playerState.gold`**（单位：金币，下限 `0`，不设硬上限）。
   - 不做金 / 银 / 铜三进制换算；日常喝茶、小口吃食等低额碎银开销留在叙事层，不逐餐发标签扣钱。
2. **后台定果，严禁模型报数字**：
   - 严禁出现 `<gold add="..." />` 或允许 LLM 自填金额的属性。
   - 正文只通过全量注册的枚举事实标签 `<economy ... />` 与既有 `<bond ... />` 申报事实，由后台查表校验条件、冷却与余额并扣发固定数额。
3. **固定宿费跨夜打包**：
   - 宿费由跨午夜结算模块统一扣除，不依赖 LLM 每晚主动记账。

## 二、开局初值与固定支出（宿费规则）

### 1. 初值与迁移兜底
- **开局初值**：`world.playerState.gold = 30`（对应前传荒原途中囊中旅费紧张，每日 5 金食宿仅够维持全队极限生存 6 天）。
- **欠账状态旗标**：`world.flags.inn_arrears = false`（`boolean`）。
- **存档迁移**：旧存档未含 `playerState.gold` 时非破坏补齐为 `30`；若旧档已置 `player_barony_granted === true` 且未初始化金币，补齐为 `1000`。

### 2. 跨午夜 `00:00` 宿费扣减规则（按天唯一结算）
- **触发条件**：在 `k * 1440`（第 `k` 天转入第 `k + 1` 天）夜间结算节点，仅当以下条件**全部成立**时结算当晚整队旅店基础食宿费：
  - `world.flags.arrived_oakhaven === true`（前传野外不扣）；
  - `!world.flags.eileen_fugitive`（通缉逃亡风餐露宿期停收旅店宿费，但若此前已有 `inn_arrears` 保留至恢复付清）；
  - `!world.flags.player_barony_granted`（清算男爵受封奥克赫斯爵位后免收）。
- **扣费公式**：
  - 每日固定扣除 **`5` 金**。
  - 若扣除前 `gold >= 5`：`gold = gold - 5`，若 `!eileen_fugitive` 且此前挂有欠账，清除 `world.flags.inn_arrears = false`。
  - 若扣除前 `gold < 5`：`gold = 0`，写入 **`world.flags.inn_arrears = true`**。
- **欠账 `inn_arrears` 影响（硬惩罚边界）**：
  - 仅作用于旅店掌柜态度提示（`buildLedger` 注入欠账警示）及**禁止在未清账状态下执行旅店内带实物支出的赠礼/安抚**（详见第三节）；
  - **不阻断**主线剧情触发、休息睡过时间或逃亡突围（一旦通过赚钱恢复 `gold >= 5`，即可立即在下一结算或充值后转回正常）。

## 三、日常实物送礼与三大吞金口（支出侧真源）

### 1. 日常实物类 `<bond>` 轻消耗（`-2` 金/次）
下列 4 项明确涉及购买酒肉、甜点、茶包或耗材礼物的 `<bond>` 交互，在各自原有的地点、好感与冷却校验基础上，**额外校验资金余额与欠账状态**：

| 角色 | `kind` | 单次耗金 | 前置拦截条件（不满足则拒绝本次效果与消耗） |
|---|---|---|---|
| `isna` | `comfort`（旅店分肉饮酒安抚） | **`-2` 金** | `playerState.gold >= 2` 且 `!world.flags.inn_arrears`（旅店消费受欠账约束） |
| `isna` | `gift`（镇上赠酒肉或开锁小礼） | **`-2` 金** | `playerState.gold >= 2` 且处于 `inn` 时须 `!world.flags.inn_arrears` |
| `nise` | `treat`（镇上投喂甜点/法术耗材小礼） | **`-2` 金** | `playerState.gold >= 2` 且处于 `inn` 时须 `!world.flags.inn_arrears` |
| `aurora` | `gift`（实用小礼草药茶包披肩） | **`-2` 金** | `playerState.gold >= 2` 且处于 `inn` 时须 `!world.flags.inn_arrears` |

- 其余非实物情感 / 协同 / 对练 / 祷告类 `<bond>`（如 `spar` / `care` / `share_food` / `tease_back` / `magic_help` / `help_chores` / `heal_care` / `church_visit` / `wilds_assist` 等）保持 **`0` 金消耗**。

### 2. 三大角色吞金汇率与还债 / 捐助标签（`<economy>`）
全部以 **`10 金 / 点`** 为核心偿债汇率，孤儿院按 **`5 金 / 点`** 计注资：

1. **奥萝拉旧债 (`<economy op="repay" npc="aurora" tier="part|all" />`)**
   - **汇率**：`1 点 debt_pressure = 10 金`（满额 `100` 点 = `1000` 金）。
   - **前置条件**：`aurora.alive !== false && !aurora.flags?.aurora_purged_with_baron`、`aurora.flags?.aurora_debt_disclosed === true`（`affection >= 80` 坦白开关已打开）且 `(aurora.values.debt_pressure ?? 0) > 0`，玩家与奥萝拉同处 `inn / town / church` 之一。
   - **扣款与结算**：
     - `tier === 'part'`：固定扣 `Math.min(debt_pressure, 10) * 10` 金（常规分期为 `100 金` 减 `10 点`），余额不足时不生效；
     - `tier === 'all'`：扣 `debt_pressure * 10` 金直接将 `debt_pressure` 归 `0`；
     - 只要结算后 `debt_pressure <= 0`，自动写入 `aurora.flags.aurora_debt_cleared = true`；若当时仍在山庄任职（`manor_service_active`），同回合随即由 `aurora_debt_cleared_quit` 辞职归队回 `inn`。

2. **妮丝赌债 (`<economy op="repay" npc="nise" tier="part|all" />`)**
   - **汇率**：`1 点 gamble_debt = 10 金`（与奥萝拉统一，体现赌场高利贷代价；初借 `10` 点 = `100` 金，荷官期 `30` 点 = `300` 金，满额 `100` 点 = `1000` 金）。
   - **前置条件**：`nise.alive !== false && nise.stage < 3 && !nise.flags?.casino_debt_frozen && !nise.flags?.nise_fled_casino`、`(nise.values.gamble_debt ?? 0) > 0`，玩家位于 `town / casino / inn` 且**已获知赌债事实**（`nise.flags?.nise_debt_known === true` 或妮丝已在当场坦白/已触发赌场阶段）。
   - **扣款与结算**：
     - `tier === 'part'`：固定扣 `Math.min(gamble_debt, 10) * 10` 金（常规 `100 金` 减 `10 点`）；
     - `tier === 'all'`：扣 `gamble_debt * 10` 金清零 `gamble_debt`；
     - 若结算后 `gamble_debt <= 0`，置入 **`nise.flags.debt_repaid_once = true`**（供好感 `>= 90` 终生戒赌豁免判定）。

3. **塞西莉亚修道院经费 (`<economy op="donate" npc="cecilia" tier="small|large" />`)**
   - **汇率与前置**：玩家与塞西莉亚同处 `church`，塞西莉亚 `alive !== false && stage < 3 && !affection_locked && (cecilia.values.orphanage_funds ?? 0) < 100`。
   - **扣款与结算（日常捐款已下调对齐紧缩模型）**：
     - `tier === 'small'`：`playerState.gold - 5`，`orphanage_funds + 2`，`donated_gold + 5`；若当前 `cecilia.values.affection < 70`，同步 **`affection + 2`（增后封顶 `70`，豁免日上限）**；
     - `tier === 'large'`：`playerState.gold - 15`，`orphanage_funds + 5`（封顶 `100`），`donated_gold + 15`；若当前 `cecilia.values.affection < 70`，同步 **`affection + 5`（增后封顶 `70`，豁免日上限）**；
     - **70 好感截断规则**：一旦 `cecilia.values.affection >= 70`，捐赠善款仍可增加 `orphanage_funds` 与 `donated_gold`，但**不再提升好感度（`+0`）**。
   - *(注：`church_gift` `<bond>` 消耗 `-2 金` 同步记 `orphanage_funds + 1, affection + 2`；高好感孤儿院危机求助事件 `cecilia_manor_appeal_1/2/3` 平账门槛保持高压大关卡不变：分别需消耗 `50/100/150` 金同步计入 `donated_gold` 与 `orphanage_funds + 15/+25/+35`。)*

## 四、收入来源与委托门禁（收入侧真源）

### 1. 常规做工、公会分层委托与修道院委托（`<economy op="work" tier="odd|guild_normal|guild_high|church_paid|church_volunteer" />`）

| 档位 (`tier`) | 地点要求 | 冷却 / 频次门禁 | 同伴协同校验 | 收益 | 附带状态联动 |
|---|---|---|---|---|---|
| **`odd`**<br>小队协作紧急短差 | `town` 或 `wilds` | `arrived_oakhaven && !eileen_fugitive`，**每自然日限 1 次**（`world.flags.playerOddJobDay !== day`） | 无要求 | **`+6` 金** | 写入 `playerOddJobDay = day`；*(若当日以 `<bond npc="isna" kind="steady_work" />` 与伊丝娜同行正经出工且尚未领过当日零工报酬，亦同步结算 `+6` 金并记用掉当日额度)* |
| **`guild_normal`**<br>公会常规委托 | `town` 或 `wilds` | `arrived_oakhaven && !eileen_fugitive`，**每 3 天限 1 次**（与高危委托共享冷却：`day - (lastGuildCommissionDay ?? -99) >= 3`） | 无要求 | **`+28` 金** | 写入 `lastGuildCommissionDay = day`；若 `gulan.alive !== false && gulan.stage < 3` 写入 **`gulan.flags.player_guild_job_done = true`** |
| **`guild_high`**<br>公会高危悬赏 | `town` 或 `wilds` | 同上：**每 3 天限 1 次**（与 `guild_normal` 共享 `lastGuildCommissionDay`） | **须有活跃战斗同伴同地协同**：古兰（限在 `wilds` 荒原护持，城镇公会常规单不代打）或伊丝娜中至少一人 `alive !== false && stage < 3 && !captured_orc && !isna_captured_ed && npc.location === world.playerLocation` | **`+48` 金** | 写入 `lastGuildCommissionDay = day` 与 `gulan.flags.player_guild_job_done = true` |
| **`church_paid`**<br>修道院常规帮工 | `church` 或 `wilds` | `arrived_oakhaven && !eileen_fugitive && cecilia.alive !== false && cecilia.stage < 3`，**每 2 天限 1 次**（与 `church_volunteer` 共享冷却：`day - (lastChurchErrandDay ?? -99) >= 2`） | 无要求 | **`+3` 金** | 写入 `lastChurchErrandDay = day`；`orphanage_funds + 4`、`cecilia.affection + 2`（受日常 `+3` 上限约束） |
| **`church_volunteer`**<br>修道院无偿义工 | `church` 或 `wilds` | 同上：**每 2 天限 1 次**（共享 `lastChurchErrandDay`） | 无要求 | **`+0` 金** | 写入 `lastChurchErrandDay = day`；`orphanage_funds + 8`、`cecilia.affection` 常规上限部分 `+2` 叠加无偿热忱额外 **`+3`（豁免日上限，单日干净状态共 `+5`）** |

- **余额回暖解除欠账**：任何赚钱渠道使 `world.playerState.gold >= 5` 时，若 `world.flags.inn_arrears === true`，可在该次结算后同步解除 `inn_arrears = false`。

### 2. 剧情酬金与日常急件截单

## 五、周常生存收支基准律与 20 天验算结论

### 1. 【周常生存基准律（净结余 1 金币）】
- **周收入（40 金）**：通常每周完成 1 轮常规委托（`28 金`）并出工 2 次紧急短差（`12 金`），共计 `40 金`；
- **周支出（39 金）**：七日整队旅店通租食宿（`35 金`）加两次同伴赠礼请客（`4 金`），共计 `39 金`；
- **周生存净结余**：**`1 金币`**！日常做工仅能维持队伍勉强苟活，存不下大钱。

### 2. 20 天窗口验算结论
以抵镇后 20 天（前传余下 `30` 金开局，抵镇 20 夜旅店固定房费 `-100` 金）为窗口：
- **只靠短差做工**：扣除房费后所剩无几，无力清偿奥萝拉 `1000` 金与妮丝巨额赌债，债务高压逼迫玩家必须寻求破局；
- **正常跑单与爱德急件**：周结余紧缩，只能勉强支撑日常送礼或小额救济修道院；
- **开拓重磅支线破局**：唯有通过珠宝铺解救爱丽丝（`+40 金`）、深入荒原攻破兽人据点（`+300 金`）或主线清算男爵（`+1000 金`），方能获得翻盘重金完成全员救赎！
