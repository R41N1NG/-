## 一、设计边界与中控原则

1. **单向无副作用拼装**：
   遗迹组装器（`okh_app_ruins.js`）是一个**纯生成型装配管道**。它根据输入的「目标阶位」与随机种子，从已注册的组件库中筛选出符合生态与强度的组件，组装成结构化对象 `ruinInstance` 写入 `world.ruinState`。
2. **拒绝口头设定，组件全量注册入库**：
   所有生成的房间必须在已注册的组件库中存在实体 ID，包括入口（`entrance`）、机关（`obstacle`）、岔路（`branch`）、守卫（`combat`）与密室（`sanctum`）。
3. **时长只设下限，不封死上限**：
   单区块基础探索耗时下限 $\ge 8 \sim 12$ 小时，整座遗迹时长下限 $\ge 36 \sim 64$ 小时（跨越 2 至 4 个完整昼夜，必须消耗多日口粮）。若遇阻、绕路、硬闯或遭遇苦战，耗时自然上浮，严禁设死上限。
4. **效果全汇于中控真源**：
   组件自身只声明门槛要求（如 `reqAbility`、`enemyTier`、`damageType`），不写死金币发放、好感变动或状态增减。掉落结算归口 `okh_app_ruins.js` 与 `okh_effects.js`，难度比对归口 `okh_app_rules.js`。

## 三、组装流水线四步算法（Assembly Pipeline）

### 3.1 步骤一：位阶选择与生态准入池过滤
```javascript
// 1. 确定位阶 targetTier (2: 正规, 3: 精锐, 4: 宗师)
// 2. 根据位阶构建候选生态白名单
function getAvailableBiomes(tier) {
  const commonBiomes = [
    'biome_narrow_mine',
    'biome_toxic_mire',
    'biome_trap_vault',
    'biome_living_lair'
  ];
  if (tier >= 3) {
    return [...commonBiomes, 'biome_arcane_grid', 'biome_undead_crypt'];
  }
  return commonBiomes;
}
```

### 3.2 步骤二：多维生态氛围生成（Atmosphere Profile）
组装程序根据选出的 `biomeId`，提取对应的五维感官文本与战术禁忌，写入 `ruinInstance.atmosphere`，直接作为前端状态栏环境展示与 LLM 场景提示词挂载源。

### 3.3 步骤三：队伍规模准入、区块数量与总耗时下限生成
1. **队伍准入上限（partyLimit）**：
   - 随机外围探险点：按委托规模随机抽取准入上限为 `2 ~ 4` 人（含玩家 `{{user}}`）；
   - 核心遗迹：按特定关卡拓扑分别设定上限（第一核心遗迹上限 3 人，第二与第三核心遗迹上限 4 人）；
   - 实际出战队伍由玩家接取委托时自由指派，随行人员写入 `partyMembers`。
2. **区块数量抽取**：
   - II 阶：固定抽取 `4 ~ 5` 个区块；
   - III 阶：固定抽取 `5 ~ 6` 个区块；
   - IV 阶：固定抽取 `5 ~ 6` 个区块（或特定深层 6 区块）。
3. **时长下限模型（只写下限，不设上限）**：
   - 单区块耗时下限：`8 ~ 12` 小时；
   - 4 区块下限：$$\text{minDurationHours} \ge 36 \text{ 小时}$$；
   - 5 区块下限：$$\text{minDurationHours} \ge 48 \text{ 小时}$$；
   - 6 区块下限：$$\text{minDurationHours} \ge 64 \text{ 小时}$$；
   - 跨午夜口粮核销：每满 24 小时或跨过午夜，严格依据在场实际总人数（$N = 1 + |\text{accompanyingNPCs}| (+ 1 \text{若古兰随行})$）动态扣除 $N$ 份 `supply`，严禁定死人头数值。

### 3.4 步骤四：定点插槽拓扑装配（Slot Topology）
区块排列遵循以下有序拓扑结构：
```
Slot 1: entrance (入口)
   ↓
Slot 2: obstacle (机关 / 环境险阻)
   ↓
Slot 3: combat (守卫 / 游荡遭遇)
   ↓
Slot 4 [可选]: branch (策略岔路，分流高风险暗室或平缓绕道)
   ↓
Slot 5 [若总数=6]: obstacle 或 combat (根据前序平衡动态补齐)
   ↓
Slot N: sanctum (核心密室 / 首领战利品)
```

**组件筛选规则**：
- `component.supportedBiomes.includes(biomeId)` 为 `true`；
- 阶位匹配：`component.tier == targetTier`（岔路暗室允许出现 `targetTier + 1` 的高风险房）；
- 保证同一遗迹内组件 ID 不重复。

## 五、组装程序代码架构预留（`okh_app_ruins.js` 契约）

```javascript
/**
 * @module      okh_app_ruins
 * @updated     2026-11-26 13:25
 * @status      active
 * @reason      遗迹随机组装器与组件库总装，支持双轨遗迹与多维生态氛围渲染
 * @deps        ['core', 'data', 'rules', 'skills']
 * @provides    { assembleRuin, advanceRuinBlock, retreatFromRuin }
 */

export default {
  id: 'okh_app_ruins',
  deps: ['core', 'data', 'rules', 'skills'],
  
  init(ctx) {
    this._core = ctx.core;
    this._data = ctx.data;
    this._rules = ctx.rules;
    this._skills = ctx.skills;
  },

  api: {
    /**
     * 随机生成并组装一座遗迹实例
     * @param {Object} opts { tier: 2|3|4, partyLimit?: number, partyMembers?: Array, rng?: Function }
     * @returns {Object} ruinInstance 写入 world.ruinState
     */
    assembleRuin(opts) {
      // 1. 判定位阶与可用生态池
      const tier = opts.tier || 2;
      const biomes = this._getAvailableBiomes(tier);
      const biomeId = this._rollItem(biomes, opts.rng);
      
      // 2. 抽取生态氛围档案
      const atmosphere = this._data.RUIN_BIOMES[biomeId].atmosphere;
      
      // 3. 队伍准入上限与实际成员 (随机遗迹上限 2 ~ 4 人)
      const partyLimit = opts.partyLimit || (opts.rng ? Math.floor(opts.rng() * 3) + 2 : 3);
      const partyMembers = Array.isArray(opts.partyMembers) ? opts.partyMembers : [];
      
      // 4. 抽取区块数量 (4 ~ 6) 与时长下限
      const blockCount = tier === 2 ? 4 : (opts.rng ? Math.floor(opts.rng() * 2) + 5 : 5);
      const minDuration = blockCount === 4 ? 36 : (blockCount === 5 ? 48 : 64);
      
      // 5. 定点插槽组件装配
      const blocks = this._assembleBlocks(biomeId, tier, blockCount, opts.rng);
      
      return {
        instanceId: `ruin_${Date.now()}_${tier}`,
        tier,
        biome: biomeId,
        partyLimit,
        partyMembers,
        atmosphere,
        minDurationHours: minDuration,
        currentBlockIndex: 0,
        cleared: false,
        blocks
      };
    }
  }
};
```
