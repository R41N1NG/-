> 世界书 728 条 / 690,409 字 → 其中**战斗直接相关 8 条**（约 14,900 字，占 2.2%），**间接相关 306 条种族条 + 225 条人物条**
> 核心结论：**这张卡没有血条、没有骰子、没有先攻、没有伤害公式。** 战斗是一套「三步结算 + 分差四档」的叙事裁判协议。

# 第一部分 · 战斗系统的五条支柱

## 支柱 1｜三步结算（唯一强制流程，原文出现 3 次措辞一致）

> ① **先判行动能否成立**（看得见、够得着、未被地形/掩体挡住、付得起消耗、已习得技能；条件不足或被石壁地形挡住时直接受阻，不进入对拼）
> ② **再按「数值交锋」条目算分差**（等级、技能、发动的天赋与处境修正）
> ③ **最后按命中部位、技能用途与真实防护结算实际伤势、消耗与位置变化**

在第 1 条 `核心常驻规则`、第 5 条 `适用参考`、第 4 条 `数值交锋` 三处各写了一遍——**这是全卡最优先的执行条款**。

## 支柱 2｜无 HP 原则

> `遇到未定的具体生命值或伤害值，沿用伤势记录，勿凭空造血条。`

战斗不扣血、不算剩余 HP，胜负靠**伤势部位的实际后果**判。这条决定了整个战斗的写法：**没有"还剩多少"这种状态，只有"哪里坏了、坏到什么程度"**。

## 支柱 3｜分差式判定（唯一算式）

```
进攻值 = 等级 + 技能品质加值 + (熟练度−1) + 天赋加值 + 处境修正
防守值 = 等级 + 格挡/闪避技能加值      + 天赋加值 + 处境修正
分差   = 进攻值 − 防守值
```

**加值换算表**

| 品质 | F | E | D | C | B | A | S |
|---|---|---|---|---|---|---|---|
| 加值 | 0 | 1 | 2 | 3 | 4 | 5 | 6 |

| 熟练度 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| 加值（熟练度−1） | 0 | 1 | 2 | 3 | 4 |

**另外两条**：
- **普通行动技能加值为 0**（谁都能挥剑举盾，但那不叫技能）
- **天赋定量描述 → 首版 +2**；已有明确数值按记录；**品质或熟练度缺失的部分按 0**
- **处境修正按净优势取 −4 / −2 / 0 / +2 / +4**，必须写清依据

**三个"不重复计"的铁律**
1. 技能只有**确实影响本次进攻/格挡/闪避/追逐**时才计
2. 护甲**已经用于抵消有效伤害时，同一份护甲不再重复加进防守**
3. 相同名目的加成重叠时**只按证据结算一次**

## 支柱 4｜分差四档（唯一的"命中"尺子）

| 分差 | 结果 |
|---|---|
| **< 0** | 被挡开、避开，或未能完成动作 |
| **0 – 4** | 擦中，或只出现局部进展 |
| **5 – 14** | 正中，或完成所尝试的动作 |
| **15 以上** | 获得强效果 |

> `分差一样时，各技能的实际效果仍取决于其用途。`

## 支柱 5｜胜负按目标判，不按血量判

> `胜负按目标判，比如护送对象抵达、决斗认输、逃脱追击或失去反抗能力。`

配套的三条边界：
- **脱战必须有代价**：`脱离战场需要实际拉开的身位、掩体、速度差或断后代价，不能喊一声"逃跑"就瞬间消失`
- **投降/被俘三要素**：对手意图 + 语言能否互通 + 自身是否已失去反抗能力
- **死亡按已有伤势与物种规则判**：`死亡按已有伤势与物种规则判定`

# 第二部分 · 第一步：行动成立性（五项门槛）

动手前的全部检查项，任一不满足 → 直接受阻，**不进入对拼**。

| 门槛 | 原文依据 | 实战含义 |
|---|---|---|
| **感知得到** | 靠视觉、听觉、嗅觉、回声、震动或魔素感知确认彼此位置与距离 | 暗处潜行、盲视回声、空中俯冲、水下钻地**直接决定谁先发觉、谁能接近、能否拉开距离** |
| **够得着** | 距离 + 武器射程 | — |
| **未被打断** | `被地形/石壁/障碍完全挡住时，直接写明受阻原因并结束该次尝试`·`不得跳过地形阻挡硬算伤害`·`石壁挡住的攻击不能隔墙伤人` | 这一条限制极强，也是能防胡说的关键 |
| **付得起消耗** | `魔力不足不可负值透支，强行透支损及生命或躯体` | 蓝量上限即行动次数上限 |
| **已习得技能** | `玩家说"我用瞬移逃走"只表达意图`·`档案没有瞬移时先交代角色会什么、眼下有哪些可行退路` | **意图 ≠ 能力**，这条防止玩家说了就实现 |

**额外一条：被动天赋在条件满足时自动发动，主动能力等玩家选择。**

# 第三部分 · 第二步：分差判定（含完整算例复算）

## 卡内唯一完整算例（原文 L167）

> **8 级史莱姆**用 F-5 喷射湿砂 → **8 + 0 + 4 = 12**
> **6 级狼**冲过湿滑石沿，闪避 **−2** → **6 − 2 = 4**
> **分差 = 8** → 5–14 → **正中暴露的眼部** → 狼一时看不清 → **史莱姆获得钻进岩缝的机会**

紧接着原文补了三个变体，全是这张卡的设计精髓：

| 变体 | 结果 |
|---|---|
| 湿砂打在**完好面甲**上 | 命中成立但**结果无效**（`若对面戴了完好面甲，命中的湿砂会打在面甲上`） |
| 同时**第二只狼堵在石缝口** | 那只狼没被命中，**也还没有脱战** |
| 赢了这一手 | 得到的是**"钻缝机会"**，不是击杀 |

## 分差档位的实战含义（肥鱼按 4 级人 vs 5 级哥布林实算过）

同样是"正面遭遇"，分差会随三个变量剧烈波动：

| 情形 | 算式 | 分差 | 档位 |
|---|---|---|---|
| 坑道夜战，正面遭遇 | 攻 5 − 防 10 | **−5** | 被挡开 |
| 洞口强光（敌怕光） | 攻 5 − 防 6 | **−1** | 被挡开 |
| 藏湿苔伏击 + 敌被日光刺眼 | 攻 7 − 防 6 | **+1** | 擦中 |
| 敌抢到着火树枝（克弱点） | 攻 7 − 防 2 | **+5** | 正中 |

**结论**：在这套系统里，**处境修正（±4）的权重 ≈ 一整个技能品质档（6）**。所以"谁占便宜"比"谁等级高"更能决定走向。

# 第四部分 · 第三步：伤势结算（真实防护判定）

算出分差不等于算出伤害。原文：`伤势还要看技能品质上限、打中哪里和真实防护`。

## 判定的三个维度

### ① 命中部位 → 后果直接对应
| 部位 | 后果 |
|---|---|
| 眼部 | 一时看不清（获得钻缝机会，**不是击杀**） |
| 完好面甲 | 命中成立但无效 |
| 头颅 / 心脏 / 咽喉 | **多数血肉物种的致命区** |
| 腹部大血管 | 部分物种的致命区 |
| 关节缝隙 | 甲壳类的破防口 |
| 双头巨人的任一颗头 | **数息内休克大出血连带击垮共用心脏** |

### ② 技能品质 → 破坏上限与技术上限
| 品质 | 定位 |
|---|---|
| **F** | 吹飞砂灰迷眼、基础包扎、普通挥砍。练到 Lv.5 满级也是"极顺手省力的精妙小招，赢在快、准、阴人，**打不出拆墙破坏力**" |
| **E** | 冻住一小片地面、稳射无甲目标、基础剑术 |
| **D** | 斗气斩劈裂木盾、击穿轻甲接缝、追踪残余魔力 |
| **C** | 封锁整条走廊、集中打裂石砌薄墙、重刃连斩 |
| **B** | 一招改变整座院落或半条街的战局 |
| **A** | 一击撕开关隘防线、轰塌城墙缺口 |
| **S** | 覆盖要塞战场或强杀同阶霸主（**60 级门槛**） |

### ③ 真实防护 → 物种身体结构
原文明确禁止统一套用弱点：

> `不得把所有甲壳生物、岩皮生物或史莱姆套用同一组固定弱点`

| 类型 | 常规攻击效果 |
|---|---|
| 史莱姆 / 胶质体 | **无固定骨骼，常规劈砍与绳索往往效果有限**（刃口直接穿过，胶膜合拢） |
| 甲壳 / 厚鳞 / 岩皮 | 抗普通轻斩，**能否有效破防取决于材质、关节缝隙与攻击方式** |
| 血肉物种 | 按部位压强/割裂/失血判 |
| 空腔造物（附魂铠甲） | `箭射穿肚子只会穿过空气` |

### ④ 还有两条容易被忘的
- **轻技重中可能只是打乱站位**（F 级气流正中胸口 ≠ 伤害）
- **同一份护甲不能既抵消伤害又重复加进防守**

# 第五部分 · 大等级差压制（怎么防"低级靠嘴赢"）

这是全卡唯一带**否定式硬禁令**的地方。

## 三条防线

1. **高阶压制是物理事实**
   > `高阶一方在力量、速度、抗击打与魔力强度上具有明显压制，低阶角色正面硬拼大概率失利甚至瞬间重伤`
2. **禁止口胡胜利**
   > `绝不允许低阶仅凭一句"策略好"无代价正面击败明显高阶目标`
3. **弱方只能用非对称手段，且有边界**

## 非对称手段的四类与边界

| 手段 | 能做到 | 仍受约束 |
|---|---|---|
| 伏击 | 短促重创 | 目标警觉 |
| 地形陷阱 | 打断施法 | 护体魔力/甲壳强度 |
| 属性克制 | 破坏关键道具 | 失败反噬 |
| 远程牵制 + 多人配合 | 掩护撤退 | 同上 + 阵型与装备 |

## 多人配合的明确上限

> 有阵型与装备的多名低阶守卫能**封锁走位、拖延时间或压制轻装高阶目标的出手空隙**；但面对体魄或大范围法术压制极大的对手时，**单纯人海无法抵消防线崩塌与士气溃散的风险**。

## 最漂亮的一条边界（技能样例 F 级满级）

> 即便自身只是低级（如 **5–10 级**），在窄巷、船舱或矿道等复杂障碍里也能凭最小幅度侧身滑步顺势偏开**同档位**重斧势头，贴身抢出一记反划或借障碍钻空逃脱——**但若正面硬吃高出两档（如高级强者）的碾压重击，铁刃与腕骨依旧会折断，绝不可能无伤弹反**。

这一条同时立住了两件事：**熟练度确实有用**，且**F 级练满也打不出 A 级破坏力**。

# 第六部分 · 伤势 / 濒死 / 救援 / 死亡（四层递进）

## 第 1 层：伤势与失能
> 伤势、疲劳、失能与濒死**可并存**；流血、骨折或魔力枯竭会明显降低后续行动效率，**不会因为战斗结束就瞬间回满**。

## 第 2 层：濒死 ≠ 死亡（但救援必须同时满足三条）
1. **来得及赶到的距离与时间**
2. **有效的止血 / 解毒 / 稳固伤势手段**
3. **现场未被敌人彻底封死**

并且双向下限都堵死了：
> `不能只靠口头安慰保活，也不能把尚有抢救机会的濒死直接写成必死`

## 第 3 层：确认死亡的三种情形
1. 真实生命终止 / 濒死窗口过期无人能救
2. 瞬间致命伤（颅脑、心脏彻底毁灭；**或核心生命根基的物种其核心彻底碎裂**）
3. 命中物种死亡条件

## 第 4 层：一命制的四道封口
| 封口 | 原文 |
|---|---|
| 不复活不回档 | `绝不自动复活或回档` |
| 不编造救场 | `绝不通过"核心修复"或其他事后手段把已死角色救活` |
| 不许临时开挂 | `不自动复活、回档或临时编造隐藏血脉救场` |
| 不许转化绕过 | 吸血鬼条：`一旦玩家角色已被确认彻底死亡（头颅粉碎、魂散断气结束游玩），绝对不允许在死后强行塞口血变成吸血鬼复活续玩！` |
| 恶魔也堵 | 恶魔条：`在本世界沙盒里实体核心彻底崩毁或被高阶净化摧毁魔力内核即判定为死亡，不存在无限免死回城复活规律` |

## 7.4 各物种"核心/命门"位置表（死亡判定真源）

这是这张卡最独特的设计——**每个物种的"命"在哪，写得一清二楚**：

| 物种 | 核心名 | 死亡条件 |
|---|---|---|
| 树灵 | 核心母树 / 全部关联宿枝媒介 | 砍倒焚毁 / 强酸枯萎毒液毁生机 / 脱离林脉魔力枯竭后媒介破裂 |
| 泉灵 | 源头泉眼 + 随身原水容器 | **两者双双**枯竭或遭剧毒污水毁灭 / 冻成冰块彻底敲碎 |
| 山灵 | 母山核心脉石 + 锚定节点 | **两者一同**被爆破震碎 / 破灵或空间撕裂术直击 / 长久漂浮无岩深海 |
| 岩人 | 胸腹岩心「天然晶核石心」 | 破甲重击敲碎裂解 / 高温熔炉熔成死岩浆 |
| 晶族 | 胸腔「主律动晶髓核心」 | 猛烈声波或重锤彻底粉碎崩裂 |
| 金属生命 | 胸脊「核心永磁矿心」 | 超高炉温熔铁水 / 超强雷殛击穿 / 全躯生锈烂透 |
| 盐晶生命 | 「核心结晶母盐核」 | 融解于大量淡水 / 粉碎成细盐末 |
| 黑曜石生命 | 「核心硅玻璃火核」 | 骤冷爆裂 / 重锤敲成粉末 / 熄冻成死玻璃渣 |

# 第九部分 · 文字表现层的强制规范（怎么"写"战斗）

这一层是这张卡区别于普通战斗卡的关键：**规则再细，落到正文只有画面**。

| 禁令 | 原文 |
|---|---|
| **禁数值** | `世界书里的等级、身高、体重、技能、天赋等设定是后台尺子，严禁在正文里像报菜单一样照念` |
| **禁术语** | `严禁把"魔素耦合 / 代谢 / 阈值 / 信息素 / 神经节 / 渗透压 / 生态位 / 静水骨骼 / 机制"这类像生物课本、论文或说明书的词塞进正文` |
| **禁照抄** | 档案仅供后台参照，写进正文时**一律翻译成肉眼看得见、身体摸得着的大白话和具体画面** |
| **禁总结** | `禁止每段结尾搞道理总结或情绪升华`；允许短句、断句、停顿、话只说半句或被突然打断 |
| **禁替玩家决定** | `危险时在关键选择点停下`；`严禁在正文末尾输出"你可以选择：1. … / A. B. C."` 之类文字选项 |

# 第十部分 · 实战推演样本（4 级人类 vs 5 级哥布林，完整跑过一轮）

## 开局条件
黄昏末、苔藓外林塌方矿道口。玩家：人类 5 级（`19 级上限`），技能 `短刃格挡与卸力步 F-Lv.2`、`铁匠锻造 E-Lv.2`，天赋`手稳 F`，装备生铁短刀 + **火折子×2**。敌人：5 级哥布林（技能 `石堆伏击 F-3`、`杂物投掷 F-3`、`窄缝逃窜 F-4`；天赋`微光暗视 F`、`腐食杂胃 F`；弱点**怕强光、怕火攻**）。

## 玩家选 C（砸火折子 + 扑上）

**第 1 步 · 行动成立性**
✅ 看得见（火折子 + 残余天光）｜⚠️ 三步距离需绕凹槽边缘（正文写成"第二步踩滑半个脚掌"）｜⚠️ 凹槽是它的掩体，但它自己缩在里面，退路只剩窄缝｜✅ 纯体力消耗，**火折子 2→1**｜✅ `短刃格挡 F-2` 存在，但按 F 级规则 **Lv.2 = 受惊或姿势一乱就可能失败**

**第 2 步 · 分差**
```
攻：5 + 0(F) + 1(熟练度2−1) + 0(手稳不适用刺杀) + 2(逆光突进、敌正眯眼) = 8
防：4 + 0(窄缝逃窜F) + 2(熟练度3−1) + 0(微光暗视被强光压制) + (−4)(火折子砸面门，正中"怕强光"硬弱点) = 2
分差 = +6  →  5–14 → 正中
```

**第 3 步 · 伤势**
打中咽喉（R068：`头颅、心脏、咽喉受致命伤即死`）+ 真实防护只有破兽皮和生锈铁片 → **裁定死亡**。兑现 `适用参考` 那句「哥布林是低智洞窟魔物，正面极脆」。

**濒死反扑（必算，不能因为要赢就跳过）**
```
攻：4 + 0 + 1 + (−2)(半瞎、呼吸已断) = 3
防：5 + 0 + 1 + (−2)(冲刺收势不及、脚下碎石) = 4
分差 = −1 → 被挡开
```
→ 斧头没砍进肉，但**皮围裙按"真实防护"判定损毁**（裂成两片）——**这不是伤势，是装备损失**。

**记账**
```
状态：本轮分差 +6 正中（火折子砸脸压制「怕强光」+逆光，敌防2攻8）；
      濒死反扑分差 −1 被挡开，未受伤；
      皮围裙损毁（左襟裂开一掌长，防护失效）；火折子剩 1 枚；天光不足半刻
可选行动：A 捡铁料后撤｜B 主动往深处摸打第二只｜C 把最后一枚火折子砸进深处趁乱乱砍｜D 蹲火光边缘敲石轨引出来一个个耗
```

## 这一场的三个非数值胜负手
1. **火**（把分差从 −5 拉到 +6，克"怕强光"）
2. **湿苔/水**（史莱姆类自己会失水，不用打也撑不久）
3. **落单还是成群**（R068：落单就逃，凑成七八只立刻一拥而上）

# 第十二部分 · 总结：这张卡战斗系统的六个特征

## ① 叙事裁判，不是游戏引擎
无血条、无骰子、无先攻、无伤害公式、无回合数。所有数值只用于**裁决"这一手成不成、成到什么程度"**，成完之后全部翻译成画面。这是"文字沙盒战斗"而非"桌面 RPG"。

## ② 分差区间设计巧妙
`<0 / 0–4 / 5–14 / 15+` 四档，**中间窄两头宽**。0–4 只有 5 个整数宽度，意味着"擦中"是最高频结果——**打架天然打不出速杀**，符合"低阶互相消耗"的设定。

## ③ 环境权重大于等级
一个处境修正（±4）≈ 一整个技能品质档（6）。所以这张卡的战斗**更奖励"看地形/找弱点/抢光位"而不是"堆等级"**。

## ④ 物种结构决定解法
306 条种族各有命门。同一把剑砍史莱姆、砍骷髅、砍附魂铠甲，效果完全不同——**逼玩家"先侦察再动手"**。这正好呼应 `网文式剧情导演法` 的"防迷雾铁律"。

## ⑤ 死亡是硬的
一命制在 5 处重复封口（核心规则 / 吸血鬼 / 恶魔 / 适用参考 / 骷髅），连"死后变吸血鬼"这种常见的复活漏洞都写明了不许。**这是完成度很高的设计**。

## ⑥ 有明确的"能力边界"
`「我用瞬移逃走」只表达意图`、`绝不允许低阶仅凭一句"策略好"无代价正面击败明显高阶目标`、`F 级满级打不出 A 级破坏力`——三句话把 LLM 最容易犯的"顺着玩家说"堵住了。
