## 二、源码入口

源码采用分模块解耦架构，包含 **21 个独立单一职责模块**（行数取自实测）：

```
奥森德/src/
├─ core/                 9 个通用核心模块（不绑定具体角色与剧情标记）
│  ├─ okh_utils.js       378 行  通用校验、深拷贝与原型安全
│  ├─ okh_rules.js       128 行  纯规则条件匹配（纯函数）
│  ├─ okh_activity.js    249 行  占线活动调度与自动释放
│  ├─ okh_effects.js     183 行  原子效果执行与移动门禁
│  ├─ okh_events.js      309 行  事件流、选项分支与去重
│  ├─ okh_nodes.js       210 行  阶段推进节点与防越界
│  ├─ okh_turn.js        371 行  时间推进与时点回执结算
│  ├─ okh_api.js         274 行  状态归一化与核心总接口
│  └─ okh_adapter.js     221 行  串行持久化控制与检查点恢复
└─ app/                  12 个解耦应用模块（各自单一变更源）
   ├─ okh_app_data.js   2200 行  纯数据定义（ROSTER 7, ACTIONS 15, EVENTS 68, NODES 15）
   ├─ okh_app_rules.js   566 行  业务规则判定（好感档、前传门禁、救赎/堕落）
   ├─ okh_app_time.js    413 行  跨日午夜唯一键、拂晓轮替与经济周期
   ├─ okh_app_hook.js    336 行  SillyTavern 周期钩子、提示词注入与回滚回放
   ├─ okh_app_parse.js   325 行  <status_bar> 语义与 at 时点解析
   ├─ okh_app_hud.js     242 行  在场面板、监听面板与 HUD 渲染
   ├─ okh_app_migrate.js 197 行  存档版本增量迁移（SCHEMA_VERSION = 2）
   ├─ okh_app_world.js   194 行  分聊天持久化仓库与事务提交
   ├─ okh_app_adapter.js 183 行  控制器桥接与台账/监听快照生成
   ├─ okh_app_debug.js   136 行  调试控制台工具
   ├─ okh_app_config.js   83 行  运行时装配器与子模块导出
   └─ okh_app_entry.js    58 行  宿主生命周期统一入口
```

## 三、构建与测试命令

```powershell
# 1. 静态依赖与模块头检查
node scripts/check-deps.js

# 2. 重建两个脚本产物（同步输出到 奥森德/dist/ 与 dist/）
node 奥森德/scripts/build.cjs

# 3. 重建角色卡 JSON 与 Markdown 镜像
node scripts/build_card.js

# 4. 执行全量自动化测试（合计 44 项，必须全部通过）
node 奥森德/scripts/test_foundation.cjs
node 奥森德/scripts/test_card.cjs
node 奥森德/scripts/review-regressions.cjs
```

构建脚本会自动完成：
1. 按固定依赖顺序拼接 **21** 个模块（9 core + 12 app），附加自启包装代码；
2. 写入 `奥森德/dist/` 与 `dist/` 目录；
3. 执行模块计数与回读校验。

## 七、酒馆宿主环境操作

**主载脚本交互（推荐 `okh_complete_autostart.js`）：**

```javascript
await OKH_CARD_READY        // 等待自启动就绪标志
OKH_APP.info()              // 查看核心版本、结构版本与运行时状态
```

**常用手动调试指令：**

```javascript
OKH_APP.status()            // 查看 7 人当前位置、好感与专属数值
OKH_APP.ledger()            // 查看当前注入 LLM 的台账内容
OKH_APP.queue()             // 查看当前待处理的事件与节点队列
await OKH_APP.step(30)      // 手动推演 30 分钟
await OKH_APP.migrateSchema() // 手动执行 SCHEMA_VERSION = 2 增量迁移
```
