## 一、记录规则

### 1.1 三要素必填

| 要素 | 格式 | 不合格示例 |
|---|---|---|
| 修改时间 | `YYYY-MM-DD HH:mm` | 今天、刚才、11-8 |
| 修改理由 | 触发原因：用户反馈 / bug / 需求变更 / 重构 | 优化、调整、改了下 |
| 状态 | `active` / `deprecated` / `legacy` / `archived` | 空着 |

### 1.2 状态四态

| 状态 | 含义 | 代码位置 |
|---|---|---|
| `active` | 当前版本，正常维护 | `奥森德/src/` 与 `tavern_scripts/okh_complete*.js` |
| `deprecated` | 能跑，已被替代，不再加功能 | 原位置，头注释标注替代者 |
| `legacy` | 仅为兼容旧存档或历史对照保留 | `_archive/legacy_okh/`、`_archive/superseded_2026-11-10/` |
| `archived` | 完全废弃或已并入主线后冻结留存 | `_archive/` |

### 1.3 编号规则

每条记录一个稳定锚点，格式 `#okh_<模块名>`，供代码头注释 `@history` 引用。
