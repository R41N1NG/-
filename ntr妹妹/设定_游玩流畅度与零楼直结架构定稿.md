## 一、 核心设计原则

1. **有戏进场，无戏直结**：不涉及 NPC 对话博弈、重大剧情抉择或主观文学描写的机械操作，支持零楼数、零 Token 后台直结并实时刷新 HUD；同时保留玩家手动输入文本发楼进行自由 RP 的全部权利。
2. **默认不跳过，快进由玩家开启**：遗迹探险沿用 `autoSkipSafeRooms = false` 默认设置，玩家可手动开启跳过安全节点开关或点击「自动」。
3. **近期轨迹摘要（`localDigest`）防叙事断层**：
   - 后台直结且影响现实状态/时间/物资的操作，须将客观事实摘要暂存至 `world.bg.localDigest`；
   - 下一次玩家发楼触发 LLM 时，由 `beforeGeneration` 将 `localDigest` 作为 `【近期已完成的整备与行动】` 注入提示词，并在该楼 `finishReply` 确认后清空；
   - **空跑不记，实事连地点一并记**：仅切换地图地点而未在该地执行实质操作时，不写入 `localDigest`（当前所在地点本身由台账 `buildLedger` 实时提供）；一旦在某地执行了实质操作（如在圣辉大教堂募捐、疗伤），则将地点与实事一并记入 `localDigest`。

## 二、 全量玩家操作分类矩阵

### 1. 保留发楼进场（有戏 / 开局仪式）

| 操作项 | 来源 | 说明 |
|---|---|---|
| **开局选职** | `adventure` (`选职`) | 在 0 楼开局创建阶段完成 |
| **待决事件抉择** | `hud` (`dispatch`) | 所有主支线节点请托与危机抉择 |
| **同伴专属交互** | `hud` (`CHAR_META`) | 请教剑术、法术研讨、市井情报、常识教学、查问账目等 |
| **情感赠礼 / 请酒** | `parse` (`<bond>`) | 涉及 NPC 当场反应与台词 |
| **替妮丝 / 奥萝拉还债** | `parse` (`<economy op="repay">`) | 涉及债务心结反转与关键剧情演出 |
| **夜间同房过夜** | `parse` (`<room>`) | 涉及同房互动与次晨状态 |
| **水晶球回忆回放** | `echoes` | 需 LLM 结合插图标记输出正文故事 |
| **遗迹默认手动探索** | `adventure` | 默认 `autoSkipSafeRooms = false`，支持选动作或手写 RP 发楼 |

### 2. 零楼数后台直结 + 记入 `localDigest`

| 操作项 | 来源 | 结算与轨迹规则 |
|---|---|---|
| **研读 / 买药 / 用药 / 疗伤 / 休整** | `adventure` | 点击即过本地前置校验，不通过直接提示拦截；通过则直结状态与时间并记入实事 |
| **购买补给 (`buy_supply`)** | `parse` (`<economy>`) | 镇上/旅店按 1 金/份直接购入，扣金币加库存并记入实事 |
| **教堂募捐 (`donate`)** | `parse` (`<economy>`) | 小额/大额募捐直接扣金币、结算好感/进度，并连同教堂地点记入实事 |
| **例行打工 (`work`)** | `parse` (`<economy>`) | 含散工 `odd`、修道院杂务 `church_paid`/`church_volunteer`、公会跑腿单 `guild_normal`/`guild_high`；点击快进时后台推进耗时、结算报酬与冷却并记入简报（仍允许玩家打字发楼自演打工过程） |
| **旅店回房休息** | `map` (`room1` 等) | 无待决事件与夜间同房/夜袭冲突时，零楼数推进时段休息并记入 `localDigest`；若有事件或同房冲突则停下提示或转交发楼 |
| **遗迹「开启跳过」或「自动」安全节点** | `adventure` | 仅在开启 `autoSkipSafeRooms` 或主动点「自动」时触发，直结无分岔/无密室/非均势战节点并记入简报；遇分岔、密室、均势/劣势战、补给告罄或首次通关立即停下 |

### 3. 零楼数后台直结、不记入 `localDigest`

| 操作项 | 说明 |
|---|---|
| **技能 `装配 / 卸下`** | 后台栏位调整，不在叙事中表述，不污染提示词 |
| **单纯地图移动（空跑）** | 无阻断、无待决事件时直接切换 `playerLocation` 与路程时间并刷新 HUD；未在目标地办实事时不写入 `localDigest` |
| **旅店「整理行囊」** | 直接切换至手札「随身行囊」页，零楼数查看与操作（实际用药/研读时再按对应条目记入） |
| **设默认立绘 / 查看档案与手札** | 纯本地视图与展示偏好调整 |

## 三、 技术对齐规范（检查点与并发锁）

1. **串行锁与生成互斥**：
   - 在 `okh_app_hook.js` 新增统一本地直结入口（如 `applyLocal`），与 `beforeGeneration`、`onMessage` 共用 `serialSession` 串行队列，防止竞态修改 `revision`。
   - 若 `activeGeneration` 处于生成中状态，拒绝执行本地直结，避免提示词与权威存档状态撕裂。
2. **轻量无检查点提交（`checkpoint: null`）**：
   - 调用 `W.commit(s, { expectedRevision, state, checkpoint: null, reason: 'local-action' })` 提交，**不向 `envelope.history` 写入 `manual:` 记录**，避免挤占 24 层的聊天楼层回滚窗口。
   - 提交后立即调用 `publish(s)` 同步派生变量与聊天世界书，并触发 `OKH_APP_HUD.render(true)` 实时刷新界面。
3. **回滚边界约定**：
   - 正常向前发楼时，此前积累的本地直结结果自然沉淀进下一楼的 `before` 检查点；
   - 若玩家在未发新楼前撤回或重生成紧邻的上一楼，随上一楼 `before` 一并回滚，时间线自洽；
   - 跨多楼回溯修改早先历史楼层触发 `replay` 时，以楼层文本作为重放锚点，不单独重演早先楼层间夹杂的零楼点击。

## 四、 UI 入口接管与前置校验规范（2026-11-28 07:10 增补定稿）

1. **「当前地点」页（`buildLocationPage`）接管**：
   - **奥克赫斯城（`town`）**：`购买补给`（支持 ×1 / ×5）、`买药`、`普通委托` / `高难委托`、`镇上散工（odd · 6小时）` 均接管为零楼直结并记入 `localDigest`。
   - **圣辉大教堂（`church`）**：
     - 「治疗伤势（重伤 10 金 / 轻伤免费）」移出 `churchAudience` 限制，只要玩家位于 `church` 且非遗迹中即可办理；塞西莉亚在场时由她处理并记入 `localDigest`，不在场时由教堂驻守医护处理。
     - 「修道院募捐（小额 / 大额）」与「修道院差事（领酬帮工 / 无偿帮工）」保留塞西莉亚在场限制，点击走零楼直结并记入 `localDigest`。
     - 「询问 / 交付周常遗迹委托」保留填框发楼演绎。
   - **旅店 / 荒原（`inn` / `wilds`）**：「使用补给休整」走零楼直结并记入 `localDigest`。
2. **「职业与背包」页（`supply`）接管**：
   - 技能 `装配` / `卸下` 走零楼直结（不记 `localDigest`）；
   - 道具 `使用`（用药）与技能残卷 `研读` 走零楼直结并记入 `localDigest`。
3. **遗迹与地图接管**：
   - **遗迹（`buildRuinInteraction`）**：新增 `跳过安全节点（默认关）` 开关（`autoSkipSafeRooms`）；点击「进入」先过前置校验；开启跳过或点击「自动」时直结安全节点并汇总简报，遇分岔、密室、均势/劣势战、补给告罄或首次通关立即停下。
   - **地图（`okh_app_map.js`）**：`前往此处` 无阻断直接切换地点（空跑不记 `localDigest`）；旅店 `回房休息` 无事件/同房冲突时零楼推进时段并记入 `localDigest`；`整理行囊` 直接切至背包页。同伴房间交互保留填框发楼。
4. **前置校验原地拦截**：
   - 所有直结按钮点击时先执行本地只读校验；不通过时**不改状态、不填输入框**，直接在对应反馈条显示原因；通过则即时提交并刷新 HUD。

## 五、 异象唤醒、遗迹停靠提示与防流水账约束（2026-11-28 07:32 增补定稿）

1. **异象浮想轻量唤醒**：
   - 当存在待回应的异象浮想时，HUD 顶部「📖 旅途手札」页签显示数量角标（如 `📖 旅途手札 · 1`）。
   - 任何零楼直结操作（移动、打工、休息、遗迹跳过）若在后台推进中触发了新的待决交互事件，反馈条立即提示触发的事件标题，并附带一键跳转至「旅途手札」的按钮（不强行发楼、不抢焦点）。
2. **遗迹停靠卡点提示**：
   - 开启「跳过安全节点」后停在分岔（`branch`）、圣所密室（`sanctum`）、均势/劣势战或补给告罄时，反馈条明示停靠原因，提示玩家既可直接发消息让 AI 承接简报演绎，也可直接点选当前房间行动。
3. **`localDigest` 防流水账约束**：
   - 提示词注入结尾明确要求 AI 仅需在当前场景与人物状态上自然承接（一两句带过时间或余韵即可），不得逐条复述流水账、不得补写主角未说出的台词、不得重复扣费或重复推进时间。
