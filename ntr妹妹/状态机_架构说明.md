## 二、依赖方向与 600 行复核说明

1. **严格单向依赖**：由 [`scripts/check-deps.js`](scripts/check-deps.js) 自动扫描核验——`core` 不得反向引用任何 `OKH_APP*` 业务接口；`app` 从纯数据 `data` 逐层向 `entry` 收敛，杜绝环形或越级依赖。
2. **关键设计决策 — [`okh_app_data.js`](奥森德/src/app/okh_app_data.js) 与 [`okh_app_hud.js`](奥森德/src/app/okh_app_hud.js) 超出 600 行阈值说明**：
   - `okh_app_data.js` 当前约 3060 行，触发 [角色卡制作规范.md](角色卡制作规范.md) 第六节 600 行黄色复核阈值。**保留单文件理由**：该文件承担全部纯声明式角色花名册（`ROSTER`）、物品字典（`ITEM_CATALOG`）、日常行动（`ACTIONS`）、阶段节点（`NODES`）与条件事件（`EVENTS`）字典；不包含状态写入与循环调度逻辑。若按行数硬拆成多个数据碎片，会导致同一角色或跨角色联动（如奥萝拉—艾琳—伊丝娜—古兰跨线事件链）的 ID 互斥校验与检索上下文割裂。
   - `okh_app_hud.js` 当前约 1100 行，同样触发 600 行复核阈值。**保留单文件理由**：该文件集中承载四分页西幻手札模板、角色公开元数据/事件中文映射声明表及一体化羊皮纸 CSS（视觉底图由 `build.cjs` 在构建期以 Data URI 内联，不污染源码），全模块严格遵循“只读 `world`、不写业务状态”的单向展示职责；按行数拆分模板与样式会割裂 DOM 类名与渲染结构的一致性维护。

## 三、核心数据流

```
生成前 (GENERATION_STARTED):
  okh_app_hook.beforeGeneration()
    ├─ 对账历史 chat 变更 / 必要时回退检查点并重放
    ├─ okh_adapter.prepareGeneration() → 取出待发事件批次并置 prepared
    └─ inject(okh_app_adapter.buildLedger(world) + pendingText)

回复后 (MESSAGE_RECEIVED):
  okh_app_hook.onMessage()
    ├─ okh_app_parse.buildFront(text)         → 解析 <time>/<move>/<bond>/<room>/<injury>/<activity>/<event_resolve>/<prologue_step>
    ├─ okh_turn.advance(world, command, cfg)  → 按时间点穿插：释放到期普通活动 → 分段步进(跨时段调用 timeEffects & 自主调度) → applyBucket → refresh → syncWorld
    ├─ okh_adapter.finishReply()              → ack 确认批次 + 写入 checkpoint 历史 + 递增 revision 提交
    └─ publish() + okh_app_hud.render()       → 更新派生缓存与前端 [data-okh-hud] 面板
```

## 四、核心存档字段字典 (`okh_gpt.state.v1:<chatId>`)

| 字段路径 | 类型 | 含义 | 维护入口 |
|---|---|---|---|
| `world.schemaVersion` | `number` | 结构版本号（当前 `3`） | `okh_app_data` / `okh_app_migrate` |
| `world.timeMin` | `number` | 从第 1 天 `00:00` 起的累计分钟数（开局 `1080` = 1 日 18:00） | `okh_turn` |
| `world.playerLocation` | `string` | 玩家当前所在地点 key（`LOCATIONS` 8 选 1） | `okh_turn` / `okh_effects` |
| `world.playerState.gold` | `number` | 玩家当前持有流动资金（开局 `40` 金，非负整数） | `okh_effects` / `okh_app_rules` / `okh_app_time` |
| `world.playerState.inventory` | `Array` | 随身行囊数组：已注册物品存最小真源 `{ id, count }`（走 `ITEM_CATALOG` 查表，开局含 `supply: 10`）；向下兼容外部扩展（MUV）写入的 `custom: true` 条目（只读展示与防误删） | `okh_effects` / `okh_app_data` / `okh_app_migrate` |
| `world.focusNpcId` | `string \| null` | 当前叙事视角焦点角色 | `okh_turn` |
| `world.interactingIds` | `string[]` | 当前参与互动防打断的 NPC 列表 | `okh_turn` |
| `world.flags` | `object` | 全局里程碑（`arrived_oakhaven`, `arrivedDay`, `ed_joined`, `playerRoomTarget`, `inn_arrears`, `inn_free_pass_today`, `supply_shortage`, `eileen_arrived`, `eileen_fugitive`, `baron_purged`, `player_barony_granted`, `bloody_arena` 等） | `okh_effects` / `okh_app_rules` / `okh_app_time` |
| `world.npcs[id]` | `object` | 角色实体（`monitored`, `alive`, `hasStage`, `hasAffection`, `stage`, `location`, `homeLocation`, `values`, `plan`, `nodePlan`, `activity`, `nodeStates`, `flags`） | `okh_app_data` / `okh_effects` / `okh_nodes` / `okh_activity` |
| `world.bg` | `object` | 引擎内核控制区（`version: 2`, `revision`, `receipts`, `settled`, `fired`, `eventStates`, `queue`, `generations`［已完成保留最新 `32` 条］, `clockState`） | `okh_turn` / `okh_events` / `okh_adapter` |
| `envelope.history` | `Array` | 存档信封回滚检查点滑动窗口（默认保留最新 `24` 轮 `DEFAULT_MAX_HISTORY`，可通过 `configure({ maxHistory })` 调整；提交与迁移时自动裁剪防长对话膨胀） | `okh_app_world` |
