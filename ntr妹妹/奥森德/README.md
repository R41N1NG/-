## 在酒馆中使用

导入 `最新角色卡/奥克赫斯.json`，在酒馆助手中启用本角色卡脚本；无需另装独立运行脚本或下载地图。若此前单独安装过完整后台，请停用旧的那份，保持只启用一份完整运行脚本。

脚本沿用当前聊天存档，不强制初始化或重置。默认在最新一条助手回复下挂载状态栏，旧回复显示简版；支持酒馆助手同源 iframe 环境。导入器本身不会执行 JavaScript，需要已安装酒馆助手并开启本卡脚本库。

[原始上传件](原始上传/README.md) 单独保留；旧版独立部署仍可使用 [自动启动运行脚本](dist/okh_complete_autostart.js?raw=1)。如果已有自定义状态栏容器，可用 `OKH_APP.HUD.setAutoMount(false)` 关闭自动追加。

## 源码与验证

- `src/app/okh_app_album.js`：数值、剧情标记和事件条件收集，记录随聊天存档和回复回滚。
- `回忆相册/目录.json`：图片和解锁条件目录，当前为空；本地图片构建时内嵌。
- `src/app/okh_app_map.js`：地图、房间视图与行动意图。
- `src/app/okh_app_hud.js`：正式状态栏、挂载、事件与输入接入。
- `scripts/build.cjs`：构建运行脚本到 `dist/`，同时生成 `最新角色卡/奥克赫斯.json`、项目 `dist/` 导入包及交互预览。发布的两个 JSON 内容一致。
- `地图预览/接入验证/`：使用正式运行库与独立沙盒存档的可交互页面；其中的示例存档不会进入自动启动运行脚本。
