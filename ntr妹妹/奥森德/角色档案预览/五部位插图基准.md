# 角色档案五部位插图基准

> 2026-11-24 归档（UTC+8）

以确认后的古兰五部位插图为样张。后续角色沿用这套裁切、光向和上色方式，依各自的人设确定脸型、肤色、体型、姿态和服装。每次开画时同时备好该角色的人设参考与古兰样张。 [古兰基准原图](gulan-unified-light-source.png) · [古兰交互预览](gulan-dossier-unified-light-preview.html)

## 统一光影与质感

- 用同一盏从左上方打来的冷白柔光。受光面用较宽的亮区，沿曲面过渡到浅粉灰或低饱和玫瑰棕阴影。亮度以古兰样张为参照，肤色以各角色的设定为准。
- 边缘用柔和的厚涂过渡。通过转面和细微色差画体积，高光集中在少数受光处。肤质以柔和的微光和色阶为主，衣料、金属与肌肤各有各的反光。
- 衣料贴合处沿受力方向画浅压痕、接触阴影和少量褶皱。先画清楚自然站姿下的重量与承托，再处理高光。
- 背景统一用暖炭黑，四周留暗色余量。局部图里保留构图所需的人物特征和服装细节。

## 五个部位的构图

| 部位 | 档案键 | 构图与检查重点 |
| --- | --- | --- |
| 头部 | `head` | 正视，保留头顶与角色的角或耳尖，画面下缘裁到下巴。脸部比例、发型、瞳色和表情按角色确认。古兰样张是自然张嘴。 |
| 胸口 | `chest` | 正面，从肩颈到腰上缘，以胸部为画面中心。按人设画胸部体积、下缘的重量和衣料承托。古兰样张采用黑色无肩带半杯与细金边。 |
| 胯部 | `hips` | 后侧四分之三视角，取腰到大腿上段，以臀部为画面中心。画清腰线转向臀侧的弧度，臀宽、体积和服装按角色定。 |
| 腿部 | `legs` | 正面自然站姿，同时纳入大腿、膝部、小腿与双脚。大腿与小腿都留足画幅，按角色塑造丰润或紧实的线条。 |
| 手部 | `hands` | 从手腕到指尖，双手自然垂落，手背朝观察方向。手形、指长及可见的识别特征按人设定。 |

## 出图与接入

整套绘制时可沿用 `1536 × 1024 px` 的三列两行画幅，单格为 `512 × 512 px`。上排依次是头部、胸口、胯部，下排是腿部、手部和留空格。各格独立留边，方便单独裁切。档案展示图沿用约 `440 px` 宽的 WebP，保留原比例。头图单独裁到下巴。

按表里的五个档案键绑定到相应部位。新角色的全身剪影、点击区域和轮廓高亮按该角色的图重新对齐。验收时打开交互预览，检查五张图的光向和肤色是否一致，各部位是否按预期裁切，以及鼠标悬停和手机点选是否能打开对应画稿。
