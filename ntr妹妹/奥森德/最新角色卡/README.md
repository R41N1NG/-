## 导入使用

1. 下载 `奥克赫斯.json`，在 SillyTavern 中作为角色卡导入。
2. 安装并启用酒馆助手，在助手中启用本角色卡的脚本库。宿主的“本角色卡脚本”开关需要手动开启一次。
3. 如果此前单独安装过完整后台脚本，停用旧的那份，只保留卡内这一份。打开聊天后，状态栏自动出现在最新助手回复下。

导入一个 JSON，启用酒馆助手的本卡脚本即可；无需另装独立运行脚本或下载地图。普通角色卡导入器本身不执行 JavaScript。

新版基础世界书使用独立名称，避免与旧 R4 世界书混淆。导入后确认绑定的是“奥克赫斯·纯净标准世界书（34条）”。既有聊天仍使用当前聊天变量，不强制初始化或清空进度。

## 卡内内容

- 版本 `0.3.14-dossiers`，核心 `2.1.1`，存档 schema `3`。
- 34 条基础世界书、荒原开场，以及当前房间和工时报酬规则。古龙艾德的两条预注入资料在终局真正揭晓后才生效，按各聊天存档同步。
- 一份完整自动启动脚本、三条仅用于显示的正则（含对白气泡）；原始回执仍保留供后台解析。
- 六位角色内嵌 156 张气泡头像，涵盖 12 套造型。模型按句标记表情，脚本从该条回复的已结算状态读取造型。没有匹配表情时使用该造型的默认图，点击头像可放大。素材目录和 WebP 资源包位于 [对白头像](../对白头像/)。
- 古兰、妮丝、奥萝拉和艾琳在第三阶段结算后切换堕落形态；伊丝娜的营地形态仅在该路线确认堕落时启用。奥萝拉平日用牧师装，非休假日在庄园且已记录当天上工时用女仆装。塞西莉亚使用定稿近景。
- 新回复保存各角色当时的造型，回滚与重放会同步处理。旧存档可用仍保留的检查点还原近期造型；更早且没有状态记录的对白显示常态。
- 全域、镇内、旅店一层及二层四个视图；地图、手札纸面、标注字体均内嵌，职业图标为内联 SVG。原 HUD 的可选肖像及旧纹理沿用原路径和占位回退。
- 地图支持随时收起和展开，保留当前地图层级、房间选择与行动草稿。
- 同一排六门：伯里、古兰、伊丝娜、妮丝、奥萝拉、爱德。古兰为独立住客；爱德未加入时不提前作为住客展示。
- 同伴名册下方增加回忆相册，开局固定显示四位角色，后续女性角色取得立绘后新增；支持放大、翻页、设为默认立绘，收录条件支持数值、剧情标记和事件。当前正式图片目录留空，后续接图见 [相册说明](../回忆相册/README.md)。
- 点门先展开房间与角色，再选行动追加到输入框；不会自动发送、改变位置或推进时间。

地图标注已改为偏冷的深墨色，敌对地标采用暗红墨；文字加淡纸色衬光，全域与镇内底图稍降饱和度，保持无框标注。桌面与手机截图已同步。

在「同伴名册」展开古兰、伊丝娜、妮丝或奥萝拉，选择「查看完整档案」。四人均显示身份、简介、所在、近况、羁绊与专长。所在、近况、羁绊与古兰的血脉读数来自当前聊天。点击「记录」查看剪影和部位图，可切换着衣与内衣。奥萝拉的着衣支持圣职者装和女仆装。档案图册随卡提供，剧情解锁的回忆仍在名册下方的回忆相册中查看。 [下载独立档案预览 HTML](../角色档案预览/companions-dossier-preview.html?raw=1)

## 验证与构建

在 `奥森德/` 执行 `node scripts/build.cjs`，会同时生成完整运行脚本、本目录角色卡、项目 `dist/` 同版导入包及交互预览。基础字段来自 `scripts/inputs/card-fields.json`，该文件供构建脚本读取。卡内 `okh_build` 记录运行脚本、地图素材与原始来源的 SHA-256、字体授权，以及相册目录摘要和条目数。

`test_card.cjs` 的整卡测试检查原设定保留、原生助手脚本结构、资源字节一致性、显示正则、开场解析、卡内脚本直接启动、存档复用和聊天延迟就绪。

`test_card_browser.cjs` 直接执行 JSON 内的脚本，使用模拟酒馆助手接口进行浏览器验证：开场、四视图、六间房、草稿追加、浏览不改存档、320/390/640px、卸载重载和单次事件处理；阻断网络时地图仍可解码。截图来自这一整卡流程。

```sh
node scripts/build.cjs
node --test scripts/test_card.cjs scripts/test_work.cjs
node scripts/test_card_browser.cjs
```

`导入预览.html` 下载后在浏览器中打开即可交互。点击“演示：古兰表情”可比较三张气泡头像。演示“抵镇入住”只写预览沙盒，不会写入真实聊天。上述浏览器检查使用模拟宿主，尚未在用户的实际酒馆实例中导入验证。

相册排版预览使用独立的示意素材，不进入正式卡。相册新增 7 项回归与浏览器交互检查，确认已收集图片保留、回复回滚、跨聊天隔离及浏览不改档。

0.3.2-album：初始名册与相册均固定四位角色。塞西莉亚不属于初始队伍，未抵镇不能打开镇内或旅店地图。点击相册图片可放大并设为默认立绘，选择随聊天保存；选择的图片若被剧情回滚撤销，会回退到仍已收集的基础立绘。

0.3.4-fixes：重载后头像可继续打开和关闭；气泡随宿主正常卸载。差事需在同一回执里达到工时，工作报酬每个游戏日最多结算一项。伊丝娜协作与普通短差均为 6 金。
