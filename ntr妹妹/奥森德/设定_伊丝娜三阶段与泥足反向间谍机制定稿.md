## 一、正线与被俘入口

1. **正线求救条件**（当 `arrived_oakhaven` 且 `gold_desire >= 70` 时触发营地探财遇险）：
   - **吊坠 0 延迟求救**（`isna_camp_ambush_pendant`）：`affection >= 90 && token_exchanged`，消耗 `isna_pendant`，即刻发出真求救，救援窗口 `isnaDistressDays < 2`（T 至 T+1 完结前）。
   - **灰鼠延迟报讯**（`isna_camp_ambush_rat`）：`affection >= 80`（未达成吊坠线），次日 `isnaDistressDays >= 1` 灰鼠送达求救信，救援窗口 `isnaDistressDays < 3`（T+1 至 T+2 完结前）。
   - **直接被俘**（`isna_camp_ambush_direct`）：`affection < 80`，直接被押入黑兽人营地地牢（`captured_orc: true`）。
2. **救援成功**：触发 `isna_wilds_rescue_real` 或 `isna_wilds_rescue_gulan_solo`，伊丝娜返回 `inn`、`gold_desire -30`、解冻欲望，不进入异兆/堕落线。

## 二、堕落三阶段全流程

### 阶段 1：异兆期（`stage = 1`，黑兽人营地地牢）
- **触发**：`npc.stage === 0 && Boolean(npc.flags?.captured_orc)`。
- **内容**：被押入 `wilds_camp` 地牢当日即进入异兆期（`stage = 1`），遭受兽人拷问与轮流粗暴侵犯、丢失处女，被千夫长克罗格在小腹隐蔽处种下**黑兽人血契印记**。
- **印记规则**：必须每 3 天回营地接受兽人精液灌注压制，否则会剧痛发作并显露魔纹。
- **后台联动**：挂上标签 `orc_blood_seal`，写入首次 `dossierAdd`（丢失处女、粗暴体位与精液容量），注册水晶球残响 `echo_isna_camp_torture`。

### 阶段 2：泥足期（`stage = 2`，放回城镇做反向间谍，共 10 天）
- **触发**：`orcCaptiveDays >= 1` 时转入 `stage = 2`，克罗格放伊丝娜返回 `inn`（`captured_orc: false`），并以“外人强行碰触血契便会爆裂伤身、何况失身之躯只会遭同伴嫌弃”封住她的口；伊丝娜对外伪装成趁营地换防侥幸逃回，顺势接下“夜间潜行踩点盯梢黑兽人”的借口。
- **后台标签**：挂上 `orc_spy_conflict`（表面如常奔走探听消息，尚念旧情而内心纠结）。
- **第 3、6、9 天外出汇报与受赏**：
  - 泥足期第 **3、6、9** 天夜间，伊丝娜以“外出踩点盯梢”为由离开旅店（地图与 HUD 隐匿去向，不剧透营地位置），实则潜回 `wilds_camp` 向克罗格汇报城镇与古兰动向，并在营帐内以更粗暴的兽人轮换体位接受大量精液灌注压制印记（“接受赏赐”）。
  - 每次潜回触发暗线事件 `isna_mud_camp_report`（`covert: true`），累加 `isnaMudSpyCount`，写入 `dossierAdd`（粗暴轮换体位、内射次数与更高精液容量），并解锁阶段 2 水晶球残响 `echo_isna_mud_spy`。
- **泥足期主动拜访与双轨容错**：
  - 经历第 3 天再次归巢（`isnaMudSpyCount >= 1`）后，玩家前往 `inn` 拜访伊丝娜房间并与之互动（`world.playerLocation === 'inn' && npc.location === 'inn' && !isnaMudOutTonight && world.interactingIds.includes('isna')`）时，触发待决事件 **`探查·伊丝娜的异常`**（`isna_mud_probe`）：
    - **高好感（`affection >= 75`）**：经历再次归巢又撞见玩家的关切询问，伊丝娜抱着必死的决心痛哭吐露真相，请求原谅她的自大失足，央求玩家不要嫌弃被兽人玷污的她。
    - **低好感（`affection < 75`）**：首次探查时，伊丝娜遮遮掩掩推辞未说真相，糊弄将玩家半赶出房间（记录 `isnaMudFirstProbeDay`）。必须等她**再次潜回营地并返回之后**（即跨越下一个 3 天潜回日，如第 4/5 天首次探查，下一次有效探查至少在第 7 天），于夜间/深夜再度拜访互动，触发 **`深夜探查·伊丝娜的异常`**（`isna_mud_probe_second`）：直接推门发现床上小腹显露印记的伊丝娜——作为半兽人的身体经由调教后夜晚情潮难耐正在自慰，面对已显现的印记她百口莫辩，只得说出真相。
  - **次日白天拔除印记或绝望逃走**：
    - 揭露真相后的**次日白天**（`morning` / `afternoon`），若 **塞西莉亚**（存活且 `stage < 3`、未被囚）或 **古兰**（存活且 `stage < 3`、未被俘且未离队）至少一人可用，则出现待决事件，玩家可选择：
      - 请 **塞西莉亚** 拔除：需耗费仪式材料，加剧教堂/孤儿院资金耗尽（`orphanage_funds -15`）；
      - 请 **古兰** 拔除：需激活龙血灼烧压制，导致血脉浓度小幅上升（`blood_density +5`）。
      - 拔除后退回正线 `stage = 0`（清除 `orc_blood_seal` 与 `orc_spy_conflict`，保留档案记录，并挂上永久标签 **`isna_orc_phobia`（兽人恐惧）**，效果：① 会拒绝和兽人有关的行动，拒绝前往 `wilds_camp`；② 面对兽人时会处于恐惧状态，失去战斗力）。
    - 若两位同伴均已沦陷或无法相助，则次日白天失去希望的伊丝娜逃离旅店（`isna_mud_hopeless_fled: true`），等待泥足期满 10 天后转入阶段 3。

### 阶段 3：沉沦期（`stage = 3`，宠物与内鬼）
- **触发**：泥足期未被挽回且 `isnaMudDays >= 10`，自动转入 `stage = 3`（`isna_fallen_orc: true`）。
- **后台联动**：移至 `wilds_camp`，移除 `orc_spy_conflict`，挂上 `orc_fallen_pet`，写入 `dossierAdd`，解锁阶段 3 水晶球残响 `echo_isna_fallen_pet`（心甘情愿成为克罗格的宠物与间谍，泄露城镇与古兰情报）。
- **联动古兰线**：进入阶段 3 后，由伊丝娜发出单向假求救信号（`wilds_rescue_trap_low / mud_high / mud_low`）将古兰诱入 `wilds_camp` 陷阱。
