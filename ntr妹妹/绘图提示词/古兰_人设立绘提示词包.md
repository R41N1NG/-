## 零、锚点

### 0.1 外观锚点（每条必带）

```
1girl, solo, adult, mature female, tall female, voluptuous,
(black hair:1.2), long hair, straight hair, very long hair, blunt bangs,
amber eyes, (amber eyes:1.2), slit pupils, sharp eyes, pale skin,
horns, dragon horns, (black horns:1.25), curved horns, swept back horns, temple horns,
```

| tag | 对应真源 |
|---|---|
| `(black hair:1.2), long hair, straight hair, very long hair, blunt bangs` | 乌黑齐腰长直发 + 整齐齐刘海 |
| `amber eyes, (amber eyes:1.2), slit pupils, sharp eyes` | 深邃琥珀色**竖瞳**，目光如刃 |
| **`(black horns:1.25), curved horns, swept back horns, temple horns`** | **太阳穴两侧对称后弯的乌黑纯色龙角**，黑曜石光泽 |
| `adult, mature female, tall female, voluptuous` | 成熟女子、高挑修长、体态丰润 |
| `pale skin` | 肤色白皙，全无岁月细纹 |

> **角的位置是本角色最容易画错的地方**：单写 `horns` 会画成头顶牛角／羊角。必须 `temple horns`（拉到太阳穴两侧）+ `swept back`（后弯走向）+ `curved`。
> ⚠️ **常态角是纯黑的，角尖不带红**。红尖只在血脉激发时出现，见 0.4。

### 0.2 服装锚点（黑底金边高领高叉长裙 · 一字不改）

```
black dress, (long dress:1.15), (high collar:1.2), (covered chest:1.15), (modest neckline:1.1), long sleeves,
gold trim, gold embroidery, (side slit:1.2), (high slit:1.15), bare thighs,
classical dress, elegant, armoured dress, chainmail underlayer,
(corset:1.15), waist armor, leather belt, gold buckle,
pauldron, (single pauldron:1.15), spaulder, bracers, arm guards, gauntlets,
(thigh boots:1.25), (over-knee boots:1.2), black boots, leather boots, boot cuffs,
```

| 分组 | tag | 说明 |
|---|---|---|
| 主裙 | `black dress, (long dress:1.15), gold trim, gold embroidery` | 黑底金边古典长裙 |
| 领口 | **`(high collar:1.2), (covered chest:1.15), (modest neckline:1.1)`** | 立领高至颈根，**领口严实包裹** |
| 高叉 | **`(side slit:1.2), (high slit:1.15), bare thighs`** | 两侧开衩至腰际（为迈步出剑），大腿露出 |
| 甲 | `armoured dress, chainmail underlayer, (corset:1.15), waist armor, leather belt, gold buckle` | 内衬软锁甲 + 皮革束腰腰甲 + 金扣 |
| 肩腕 | `pauldron, (single pauldron:1.15), spaulder, bracers, arm guards` | **左肩单侧**护肩 + 黑色护腕 |
| 靴 | **`(thigh boots:1.25), (over-knee boots:1.2), boot cuffs`** | 黑色过膝皮长靴，靴口翻边 |

> `high collar` 单写常只到锁骨，必须配 `covered chest, modest neckline`，否则模型自作主张开低胸。负面压 `cleavage, exposed chest, low cut`。
> `boots` 单写会出短靴，`(thigh boots:1.25)` + `(over-knee boots:1.2)` 两个一起才到膝上。负面压 `knee boots, ankle boots`。

### 0.3 武器锚点（阔刃双手精钢重剑）

```
greatsword, two-handed sword, (broad blade:1.15), thick blade, straight sword, crossguard,
holding greatsword, (sword:1.1),
```

| tag | 说明 |
|---|---|
| `greatsword, two-handed sword, (broad blade:1.15)` | 阔刃双手重剑，宽度是辨识点 |
| `thick blade, crossguard` | 厚重、十字护手 |
| 状态词 | 背负 `on back, sword on back`；拄地 `sword resting on ground, point down`；擦拭 `wiping blade, polishing, whetstone` |

> **不要写 `katana` / `longsword` / `thin blade`**——会画成细长刀。她要的是"重若崩山"的宽刃大剑，负面必须压这几条。

### 0.4 三态开关（本包最容易翻车的地方）

| 状态 | 触发 | 加什么 | 必须删掉的负面 |
|---|---|---|---|
| **① 常态**（日常、练武、受迫） | 绝大多数场景 | **什么都不加**，角纯黑、无鳞、无尾 | `dragon tail, scales` 类压在负面里 |
| **② 血脉激发**（生死搏杀、被同源器物逼迫） | 演武场斩杀／兽人营地／真血破围 | `(dragon scales:1.15), black scales, scales on forearm, scales on thigh, (horns with red tips:1.15), (red glow on horn tips:1.1)` | 删掉 `dragon scales, black scales, full body scales, dragon girl` |
| **③ 终局龙化**（`stage 3 · 沦陷`） | 终局立绘 | ②的全套 + `(dragon tail:1.3), (black dragon tail:1.25), thick tail, (dragon claws:1.3), (clawed hands:1.25), (sharp claws:1.2), (black claws:1.2)` | 此外还要删 `dragon tail, tail`（否则与正面打架，尾巴出不来） |

> 轻/中/重三档鳞片的完整写法见旧包 `古兰_Animagine提示词包.md` 第 0.4 节。**默认走轻度**（小臂 + 大腿外露那两块 + 角尖）。
> ⚠️ 尾巴要进画必须 `full body`，`cowboy shot` 直接裁掉。

### 0.5 表情四档

| 档 | 用途 | tag |
|---|---|---|
| ① 肃穆 | 日常、督训、擦剑 | `serious, closed mouth, calm, cold expression, looking at viewer` |
| ② 怒 | 出手、护雏 | `(angry:1.15), cold fury, (glaring:1.15), frown, narrowed eyes, clenched teeth, (clenched jaw:1.1)` |
| ③ 硬撑 | 血脉压制、被俘 | `(sweatdrop:1.15), (clenched teeth:1.15), (furrowed brow:1.15), (trembling:1.05), strained, (flushed face:1.1)` |
| ④ 冰冷 | 终局 | `cold expression, (emotionless:1.2), (cold eyes:1.2), expressionless, deadpan, (looking down at viewer:1.1), (inhuman:1.1)` |

> 她是"**严格控制住的愤怒**"，不是咆哮：不写 `screaming, roaring, open mouth`。`clenched jaw` + `glaring` 才是宗师级的怒——嘴上不出声，手上已经把人劈了。
> 第③档是她的灵魂：**真血翻涌、额角黑角发烫、指节捏得发白，她依然归因于自己武道心境不稳**。这一档的脸不是"痛苦"，是"不服气"。

## 五、排错速查

| 症状 | 原因 | 修法 |
|---|---|---|
| 角画到头顶 | 缺位置词 | `temple horns, swept back horns, curved horns` 三条一起；负面压 `cow horns, curved horns on top` |
| 常态长出鳞片 | 负面太松 | 负面必压 `dragon scales, black scales, full body scales, dragon girl` |
| 龙血档鳞片不长 | 负面没删 | 删掉负面里的 `dragon scales, black scales` 两行 |
| 终局没有尾巴 | 负面压着 `dragon tail` | 删掉 `dragon tail, tail`；并确认 `full body` |
| 领口开成低胸 | 缺包裹词 | `(covered chest:1.15), (modest neckline:1.1)`；负面压 `cleavage, exposed chest, low cut` |
| 靴子变短靴 | 权重不足 | `(thigh boots:1.25), (over-knee boots:1.2)` 同时给；负面压 `knee boots, ankle boots` |
| 重剑变细刀 | `katana / longsword` 残留 | 删掉这些正面词；负面必压 `katana, rapier, thin blade, longsword` |
| 变成咆哮怪兽 | 混进 `screaming, roaring, open mouth` | 全删，只留 `clenched jaw, glaring, narrowed eyes` |
| 表情太凶像反派 | 缺"克制"层 | 加 `cold fury, calm anger, battle focus` |
| 场景 2 像被打败 | 缺"支撑"动作 | `one knee on ground` + `supporting self with sword` + `white knuckles` 三条一起 |
| 场景 3 太惨 | `crying` 泄漏 | 删 `crying, tears`，改 `glaring`；她是瞪人不是哭 |
| 场景 6 还在生气 | 沿用前面惯性 | 负面压 `angry, furious, glaring, clenched teeth` |
| 银甲／板甲全覆盖 | `armor` 泛化 | 负面压 `armor set, full armor, helmet, heavy armor`，正面只用 `single pauldron, bracers` |
