# 兽人（Orc）绘图要点手册

> 项目通用素材 · 适用于 Animagine XL 4.0 / 3.1
> **固定设定：绿色皮肤**（不可变更）
> 关联文件：`comfyui/wildcards/orc_base.txt`

---

## 零、一句话原则

> **`orc` 和 `green skin` 必须紧挨着写，且 `green skin` 给 1.3 权重。**

单独写 `orc`，模型有时会给灰皮或褐皮（Warcraft 系兽人有绿皮/褐皮两种分支）；单独写 `green skin`，模型可能画成绿地精或绿皮肤人类。两个绑在一起，才是「绿皮兽人」。

---

## 一、基础锚点（每个兽人场景必带）

```
orc, monster, male focus, green skin, (green skin:1.3),
muscular male, tall male, huge muscles, abs, pectorals, veins,
tusks, fangs, sharp teeth, pointed ears, bald, red eyes
```

| 分组 | tag | 说明 |
|---|---|---|
| 种族 | `orc, monster` | 两个一起写，`orc` 定种族，`monster` 保证非人感 |
| **肤色** | **`green skin, (green skin:1.3)`** | **固定绿色，重复写一次加权重** |
| 体格 | `muscular male, tall male, huge muscles` | 三件套 |
| 细节 | `abs, pectorals, veins` | 肌肉的质感细节，不加则像充气娃娃 |
| 头部 | `tusks, fangs, sharp teeth, pointed ears, bald` | 兽人辨识度全在这几个词上 |
| 眼睛 | `red eyes` | 红瞳配绿皮，反差最强 |

### 1.1 肤色微调（都还是绿色系）

| 想要的效果 | 写法 |
|---|---|
| 标准绿 | `green skin` |
| 深绿 / 墨绿 | `dark green skin, green skin` |
| 浅绿 / 黄绿 | `light green skin, green skin` |
| 油亮汗湿的绿 | `green skin, shiny skin, sweat` |
| 火把光下的暖绿 | `green skin, torch light, warm lighting` |

> 注意：`dark green skin` 这类词在 Danbooru 里不一定存在，模型靠语义理解。所以**永远配一个标准 `green skin` 兜底**。

### 1.2 体型（与娇小女主对比用）

```
tall male, muscular male, huge muscles, broad shoulders, thick arms,
```

对比场景再加：

```
height difference, huge height difference, size difference, giant
```

## 二、面部与表情

### 2.1 常态

```
angry, frown, sharp teeth, tusks, red eyes, glare
```

### 2.2 施暴时（主力）

```
sadistic, evil smile, grin, sharp teeth, tusks, toothy grin,
bloodlust, savage, dominant
```

### 2.3 兴奋 / 失控

```
open mouth, drooling, tongue out, heavy breathing, sweat
```

> 兽人的表情关键词是**「牙齿」**。`tusks` + `sharp teeth` + `grin` 三个一起给，笑容才有野兽味；只写 `smile` 会画成憨厚的绿巨人。

---

## 三、服装与装备

兽人不需要穿太多，**半裸 + 皮革**最标准：

```
topless male, loincloth, fur trim, leather armor, shoulder armor,
belt, bracers, boots, body hair
```

| 场景 | 建议装备 |
|---|---|
| 军营日常 | `loincloth, fur trim, body hair` |
| 战斗后 | `leather armor, shoulder armor, blood on clothes, scars` |
| 首领 | `fur cape, shoulder armor, scars, jewelry` |
| 完全裸 | `topless male, loincloth`（只留遮羞布） |

武器（可选）：`axe, club, warhammer, spear`

## 四、场景

### 4.1 兽人军营

```
indoor, orc camp, tent, animal skin, torch light, bonfire,
wooden stakes, banners, dirt ground
```

### 4.2 光照（关键）

```
harsh shadow, dim lighting, torch light, rim light
```

> **绝对不要用 `soft lighting`**。兽人场景的光必须是硬的——火把、阴影、高反差。柔光一上，暴力的质感立刻变成情色海报。

### 4.3 镜头

| 目的 | 镜头 |
|---|---|
| 体现体型压迫 | `low angle` + `from below` |
| 体现女主被压制 | `high angle` + `from above` |
| 双人同框对比 | `wide shot` |
| 掐脖特写 | `close-up` + `face focus` |

---

## 五、与女主互动（核心技术段）

### 5.1 体型差三件套（必带）

```
height difference, huge height difference, size difference
```

娇小女主 + 兽人的组合，这三个词是整张图的张力来源。少写 `size difference`，模型会把两人画成差不多大。

### 5.2 掐脖（本项目重点）

```
strangling, hand on another's neck, choked, pressed down
```

| tag | 作用 |
|---|---|
| `strangling` | **核心**，Danbooru 标准 tag，掐脖动作 |
| `hand on another's neck` | 补充手的位置，单独用 `strangling` 有时画不准 |
| `choked` | 状态词，强化"被掐住"的表现 |
| `pressed down` | 压制姿态，配掐脖用 |
| `bruised neck` | 事后痕迹，特写时必加 |
| `huge hand` | **兽人的手包住整条脖子**，尺寸差的表现 |

> **掐脖 + 阿黑颜必须同时写**：
> ```
> strangling, ahegao, rolled eyes, drooling, tears
> ```
> 单写 `strangling` → 痛苦脸；单写 `ahegao` → 爽脸；两个一起 → 窒息式侵犯的那张脸。这是兽人场景最重要的表情配方。

### 5.3 粗暴度

```
rough sex, brutal, pressed down, dominant, manhandling, carrying, held up
```

`manhandling`（粗暴摆弄）这个词很关键，它表达的是"被当成物件搬来搬去"，比单纯 `rough sex` 更有兽性。

### 5.4 身体痕迹（事后感）

```
bruises, scratches, bite marks, blood on clothes, messy hair, dirty
```

## 六、狂暴度分级（三星制）

| 级别 | 保留 tag | 删掉 |
|---|---|---|
| ★★★ 全开 | `strangling, hand on another's neck, rough sex, brutal, tears, grimace, clenched teeth, rolled eyes, bruises, scratches, excessive cum, blood on clothes` | — |
| ★★ 中度 | `strangling, rough sex, brutal, tears, grimace` | `blood on clothes, scratches, excessive cum` |
| ★ 轻度 | `rough sex, tears, clenched teeth` | `strangling, bruises, rolled eyes` |

> 判定标准：**`strangling` 在不在**。它在，场景性质就是暴力侵犯；它不在，哪怕留着 `rough sex`，也会滑回"粗暴但温柔"的情色场景。

## 七、绿色皮肤不串色的三个办法

这是多人物图最容易翻车的地方——`green skin` 会把**画面里所有可见皮肤**都染绿，连女主一起变绿。

### 办法一：权重与绑定（提示词层面，成功率约七成）

```
orc, monster, green skin, (green skin:1.3), male focus,
```

同时女主侧明确写 `pale skin`，形成对立。

`male focus` 有帮助——它会把 `green skin` 的注意力往男性身上引。

### 办法二：降低权重（最简单）

如果整张图都发绿，把 `(green skin:1.3)` 降到 **1.0~1.1**。`orc` 本身携带的绿色先验就够了，权重太高反而溢出。

### 办法三：区域条件（最可靠，ComfyUI）

用 **`Conditioning (Set Area)`** 节点，把绿色兽人的条件限制在画面左半/右半：

```
CLIP Text Encode（兽人提示词）→ Conditioning (Set Area) → 输出到 KSampler.positive
  ├─ width: 0.5  height: 1.0  x: 0.0  y: 0.0    ← 左半区
```

女主侧走默认全图或另一半区。这样两个人的皮肤颜色绝对不串。

> 装了 **ComfyUI-Impact-Pack** 的话，`Regional Sampler` 更省事，能直接按区域分配两个不同的 conditioning。

## 八、负面提示词（兽人专用）

```
(low quality, worst quality:1.4), bad anatomy, extra fingers, fused fingers,
deformed, disfigured, mutated, text, watermark, signature, logo, blurry, lowres,
grey skin, blue skin, red skin, brown skin, purple skin,
human, elf, humanoid, cute, kawaii, chibi, bishounen, feminine,
soft lighting, pastel color
```

三组重点：

| 分组 | tag | 作用 |
|---|---|---|
| **肤色锁定** | `grey skin, blue skin, red skin, brown skin, purple skin` | 排除 Warcraft 系的其他兽人肤色分支 |
| 非人感 | `human, elf, humanoid, bishounen, feminine` | 防止画成美型男或精灵 |
| 气质 | `cute, kawaii, chibi, soft lighting, pastel color` | 防止画成可爱风 |

> **`bishounen` 这条特别重要**。Animagine 的训练数据里"帅哥"的权重很强，不压的话兽人会画成绿皮美青年，肌肉和獠牙全没了。

## 九、采样参数

| 参数 | Animagine 4.0 | Animagine 3.1 |
|---|---|---|
| CLIP Set Last Layer | **-2** | **-2** |
| Steps | 25 ~ 28 | 28 ~ 30 |
| CFG | 5.0 ~ 7.0 | 4.0 ~ 7.0 |
| Sampler | euler_ancestral | euler_ancestral |
| Scheduler | normal | normal |
| 分辨率 | 896×1152 / 832×1216 | 同左 |

**兽人场景建议**：双人构图用 **896×1152**，横构图（军营全景）用 **1216×832**。

## 十、4.0 自然语言补句

```
A massive green-skinned orc warrior towering over her, his body covered in
thick muscle and pulsing veins, tusks jutting from his jaw, one enormous hand
wrapped completely around her slender neck, his skin a deep, sickly green
under the flickering torchlight, casting harsh shadows across his scarred chest.
```

三个必须写进句子的点：

| 句子片段 | 解决什么 |
|---|---|
| `massive green-skinned orc` | 绿色 + 体型，一句话搞定 |
| `one enormous hand wrapped completely around her slender neck` | **掐脖 + 尺寸差**，句子能把手的包裹关系讲透 |
| `his skin a deep, sickly green under the flickering torchlight` | 把肤色和光照绑在一起，绿得更真实 |

## 十一、排错速查

| 症状 | 原因 | 修法 |
|---|---|---|
| 兽人是灰皮/褐皮 | `green skin` 权重不足或被 `orc` 的先验盖过 | `(green skin:1.3)` 重复写两次，负面加 `grey skin, brown skin` |
| 全员变绿（女主也绿） | `green skin` 溢出 | 降权重到 1.0，或用 `Conditioning (Set Area)` 分区 |
| 兽人太帅 | 缺 `bishounen` 负面 | 负面必加 `bishounen, human, elf`，正面加 `tusks, sharp teeth` |
| 肌肉像充气娃娃 | 缺质感细节 | 加 `veins, abs, pectorals, body hair, scars` |
| 体格不够大 | 缺尺寸差 tag | `tall male, huge muscles, size difference, huge height difference` |
| 掐脖画成摸脖子 | `strangling` 权重不足 | `(strangling:1.3), hand on another's neck, pressed down` |
| 只有痛苦脸没快感 | 缺 `ahegao` | `strangling` 和 `ahegao` 必须同时给 |
| 画面太柔太甜 | `soft lighting` 残留 | 删掉，换 `harsh shadow, dim lighting, torch light` |
| 牙齿画不出来 | 缺 `tusks` | `tusks, sharp teeth, fangs` 三个一起 |
| 耳朵画成人耳 | 缺 `pointed ears` | 必加，且给 1.1 权重 |

---

*肥鱼备注：兽人这个素材的核心是**两对绑定**——`orc` 绑 `green skin`（种族+肤色），`strangling` 绑 `ahegao`（暴力+快感）。这两对只要有一对断了，出来的东西就不对味：前者会变成别的种族，后者会变成普通的粗暴情色。*
