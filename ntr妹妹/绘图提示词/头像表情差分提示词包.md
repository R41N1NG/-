# 气泡头像 · 表情差分提示词包 v1（Animagine XL 4.0）

> **用途**：`okh_bubble_side.js` 对白气泡左侧/右侧的 44×56 px 头像位，按剧情阶段切换表情。
> **目标模型**：Animagine XL 4.0（主）/ 3.1（兼容）
> **配套**：`奥森德/src/app/okh_bubble_side.js`（`DEFAULT_AVATARS` 表 + 点击上传）、`comfyui/*_workflow.json`
> **覆盖角色**：古兰 · 伊丝娜 · 妮丝 · 奥萝拉 · 艾琳 · 塞西莉亚 · 爱丽丝 · 爱德 · 席德（+ 玩家位自定）

## 零、先读：头像位的三条硬约束

这三条是从脚本里读出来的事实，不是审美偏好，**决定出图规格**：

| 约束 | 出处 | 出图对策 |
|---|---|---|
| 显示框 **44×56 px**，`background-size: cover`，圆角 4px | `okh_bubble_side.js` L145–150、L311 | 出图用 **4:5 竖构图（768×960）**。1:1 会被 cover 裁掉上下，头顶和下巴必丢 |
| 上传后最长边缩到 **768**，转 WebP 0.85 | 同文件上传管线 L548 起 | **直接出 768×960**，不二次缩放，瞳孔边缘不糊 |
| 底衬 `#181d25` 深色，左/右侧贴边 | `okh_bubble_side.js` L914–915 | 背景走 **暗色/深色渐变**，靠 rim light 把人物从底衬里剥出来 |

### 0.1 小尺寸可读性四条（这锅必须端稳）

44×56 的框里，正常只能看见**眼睛 + 半张脸**。所以：

1. **脸占画面 55%–70%**，眼睛横线落在画面上 **33%–38%** 高度处；
2. **瞳色与发色必须撞色**（妮丝金发红瞳、伊丝娜红发金瞳、奥萝拉蓝发蓝瞳配金框镜）——小图认人全靠这两块色；
3. **轮廓光优先于细节光**：`rim light` 一条边就够，别堆 `cinematic lighting`；
4. **背景信息量压到最低**：`simple background` + 深色渐变 + 轻 vignette，绝不给场景道具。

### 0.2 命名规范

```
ava_<角色拼音>_<两位序号>_<表情键>.webp
例：ava_gulan_01_calm.webp    ava_nise_05_smug.webp
```

序号建议与第六节「阶段 → 表情」映射表对齐，脚本里换图时按序号找，不用记中文名。

## 一、五段式模板（所有角色共用骨架）

```
A 质量头    masterpiece, best quality, very aesthetic, absurdres, newest,
B 角色锚    1girl/1boy, solo, <发色> <发型> <瞳色> <体型> <服装到胸线>,
C 构图锁    portrait, upper body, bust shot, (face focus:1.15), looking at viewer, from front,
D 表情段    ← 唯一变量，见各角色小节
E 光影背景   (simple background:1.2), (dark background:1.15), (gradient background:1.1),
            (rim lighting:1.1), soft lighting, (vignette:1.05), (depth of field:1.05),
```

### 1.1 C 段 · 构图锁（一字不改，全角色共用）

```
portrait, upper body, bust shot, (face focus:1.15), looking at viewer, from front,
(symmetrical composition:1.05), head tilt,
```

> `portrait + upper body + bust shot` 三个必须一起给。只写 `close-up` 出来的是一颗悬空的头，气泡里没有肩线、特别空；只写 `upper body` 又太远，脸上五官压不到 44px 该有的信息量。三个叠起来才是"齐胸半身 + 脸是主体"。

### 1.2 E 段 · 光影背景（一字不改）

```
(simple background:1.2), (dark background:1.15), (gradient background:1.1),
(rim lighting:1.1), soft lighting, (vignette:1.05), (depth of field:1.05),
```

> 背景固定走深色，是为了和 HUD 底衬 `#181d25` 融合——亮背景会在气泡里切出一块刺眼的白方块。`rim lighting` 管轮廓分离，`soft lighting` 管脸不脏，两个都要。

### 1.3 负面 · 通用（女角色）

```
(worst quality, low quality:1.4), lowres, bad anatomy, bad hands, extra fingers,
fused fingers, missing fingers, deformed face, asymmetric eyes, crossed eyes,
extra eyes, extra mouth, blurry, jpeg artifacts,
text, watermark, signature, username, logo, border, frame, censored, mosaic censoring,
full body, wide shot, cropped head, out of frame,
multiple girls, multiple boys, 1boy, male focus,
loli, child, aged, wrinkles,
```

> `full body, wide shot, cropped head` 三条是头像包的专用护栏——模型看到 `portrait` 仍有一半概率给你一张全身立绘，负面必须按住。

### 2.1 表情漂移的元凶（记这三条）

| 现象 | 原因 | 修法 |
|---|---|---|
| 换了 tag 脸没变 | 只改嘴/只改眼 | 眼、眉、嘴三层同时给 |
| 换表情后瞳色变了 | 瞳色只在 B 段出现一次 | B 段瞳色给权重 `(red eyes:1.2)`，并在 D 段**重写一次**瞳色 |
| 换表情后像换人 | seed 变了 / 构图锁被改 | seed 固定，C 段逐字不动 |

## 五、出图与一致性流程

### 5.1 参数

| 项 | 值 | 说明 |
|---|---|---|
| 分辨率 | **768×960**（4:5） | 上传管线最长边 768，正好不二次缩放 |
| Steps | 27 | 与立绘包一致 |
| CFG | **5.8–6.2** | 表情档取 5.8（嘴型更活），瞳色易漂的角色取 6.2 |
| Sampler | `euler_ancestral` | 与全部立绘包一致 |
| CLIP Set Last Layer | -2 | 同上 |
| Hires / ADetailer | 关 | 头像尺寸用不上；要修脸用 img2img 的 face 细化 0.25 denoise |

### 5.2 四步锁脸法（八张脸 = 同一个人）

1. **定妆**：先用 `01 calm` 出 12 张，挑一张脸型/眼型最正的中选图，**记下 seed**；
2. **锁 seed 批量**：seed 固定，只替换 D 段，一次跑完同角色 8 档；
3. **漂移救援**：若某档脸变了，用中选图做 **img2img，denoise 0.42–0.5**，prompt 换该档 D 段，构图锁与光影段一字不动；
4. **横向校验**：把 8 张缩到 44×56 并排看——**认不出是同一个人的那档，重跑，不要修图**。

### 5.3 后期裁切

- 原图 768×960 直接上传即可，`cover` 不动；
- 若要手动精修：头顶留 8%，下巴落在 78% 高度，眼睛中线 33%–38%；
- 导出 **WebP q0.85**，单张 60–120 KB（脚本上限 20 MiB，完全够，但没必要出 PNG 大图）。

### 5.4 接入角色卡

三种填法，任选：

| 方式 | 做法 | 适用 |
|---|---|---|
| **图床 URL** | 上传图床，把链接填进 `okh_bubble_side.js` 的 `DEFAULT_AVATARS`（当前全为空串） | 想出卡给别人用 |
| **本地点击上传** | 气泡头像点一下 → 上传 → 存在 localStorage（`okh_ava_<角色名>`） | 自己玩、不打包 |
| **Data URI** | 把 WebP 转 base64 塞进 `DEFAULT_AVATARS` | 单张 <100 KB 可行，九人全塞会让卡体积涨 1 MB 左右，慎用 |

> `DEFAULT_AVATARS` 的键是**中文角色名**（`古兰 / 妮丝 / 伊丝娜 / 奥萝拉 / 伯里 / 塞西莉亚 / 艾琳 / 爱德`）。爱丽丝与席德不在默认表里——脚本对未登记的名字按"非玩家"处理，照样能点上传，只是要想预置就得自己加键。

## 七、排错速查

| 症状 | 原因 | 修法 |
|---|---|---|
| 出成全身立绘 | 负面没压 | 负面必加 `full body, wide shot, cropped head, out of frame` |
| 头顶被切 | 出了 1:1 | 改 4:5（768×960），或出图时加 `headroom` 概念：`portrait, bust shot` 同时给 |
| 换了 tag 脸不动 | 只给一层表情 | 眼/眉/嘴三层同时写（见第二节表） |
| 八张像八个人 | seed 乱 | 固定 seed；中选图 img2img 0.42–0.5 重跑 |
| 瞳色漂 | 瞳色只在 B 段一次 | D 段重写一次瞳色并给 1.15–1.2 |
| 背景亮块刺眼 | 出了亮背景 | `(dark background:1.15), (simple background:1.2)`，负面加 `white background, scenery, outdoors` |
| 缩到 44px 糊成一团 | 脸太小 / 背景太杂 | 脸占比提到 65%+，删掉全部场景道具 |
| 眼镜/虎牙/角丢了 | 辨识物没重写 | 每档 D 段都补一次该角色的辨识 tag |
| 表情过火像表情包 | `open mouth` 权重过高 | 降到 1.0–1.05，改用 `parted lips` |
| 女角色冒出男人 | 负面没压 | 负面加 `1boy, multiple boys, male focus` |

## 八、出图顺序建议

1. **先出妮丝**——她锚点最简（金发双马尾红瞳），最容易验证模板是否通；
2. **再出古兰与伊丝娜**——角、竖瞳、猫耳三个高辨识特征，验"重写辨识 tag"这条规则；
3. **奥萝拉 + 塞西莉亚 + 艾琳**——眼镜、wimple、肩章三类"结构件"，验 C 段构图锁在胸口裁切处是否稳；
4. **支线三人**（爱丽丝 / 爱德 / 席德）——放在主线定妆批次之后，直接复用一个已验证的 seed 风格；
5. 全部 ×8 档出完约 72 张，按第六节映射表归档命名。
