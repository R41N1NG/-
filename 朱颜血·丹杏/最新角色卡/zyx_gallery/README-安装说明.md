# 朱颜血·丹杏 · 本地图包安装指引

## 一键安装路径
请将本压缩包内的 `zyx_gallery` 文件夹直接解压到酒馆的图片目录：
`SillyTavern/data/default-user/user/images/`

完整解压结构如下：
SillyTavern/
└── data/
    └── default-user/
        └── user/
            └── images/
                └── zyx_gallery/
                    ├── 角色立绘/
                    │   ├── 白雪莲.png
                    │   ├── 薛霜灵.png
                    │   ├── 丹娘.png (包含 裴丹杏.png 别名)
                    │   └── ...
                    ├── 地图/
                    │   ├── danxing-border-map.png
                    │   └── danxing-overview-map.png
                    └── 关押中立绘/
                        ├── 白雪莲-关押中.png
                        ├── 薛霜灵-关押中.png
                        └── ...

解压完成后，在浏览器中刷新酒馆（Ctrl+F5），即可直接显示立绘！

## gpt：地图打开方式

使用已修复maps-v2的角色卡，点击状态栏地点栏。默认长宁周边小地图，可切换罗霄山大地图。图包路径为user/images/zyx_gallery/地图/；本地缺图时尝试联网备用图片。旧空地址配置的卡必须替换，单独复制图包不能修复。
