## 中控到底是什么

此前版本有独立源文件与按楼回放，未有统一调度器。本版新增后台中控.js统一子模块注册、刷新、订阅与销毁，宿主桥.js独立负责宿主事件/消息绑定；无可用事件时以1500ms只读轮询补读。运行于已加载的HUD前端，不是额外安装的全酒馆常驻插件或新的MUV/时间/奖励引擎。

每个实例绑定自己的聊天和楼层。view固定当前楼，live是显式查询本聊天最新；旧楼不会默认读未来。不向父窗口覆盖window.ZYX，不暴露只发事件却不落账的假setter。切聊天后不读取新聊天作为旧实例live，pagehide/dispose解绑事件与定时器。

当前iframe控制台可读：

```js
ZYX.runtime.getFullRoster()               // 当前楼八人的完整已知状态
ZYX.runtime.getImprisonedList()           // 当前楼明确在押者
ZYX.runtime.getFullRoster({live:true})    // 显式读取本聊天最新，聊天失配时为空
ZYX.runtime.getSnapshot()                // 只读scope/view/live
ZYX.runtime.refresh()                    // 主动重读
```

不调用父窗口的同名对象。自定义子模块可用runtime.register(name, {derive(context), dispose()})注册，依赖通过context.get(name)读取前序模块；注册后refresh。原始游戏状态仍来自聊天明报，不提供虚假控制台改羁押接口。
