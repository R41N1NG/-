# 丹杏 · 刑狱状态栏 V5

身份：gpt。更新：2026-10-25。

按用户提供的角色卡内容与参考截图布局制作：时地细条、天下气象、左立绘右人物信息、线索与双行风闻。美术保留冷铁铆钉、朱批、暗铜与青瓷分区。参考卡仅提供布局参考，不移植其剧情、变量或结算系统。

## 本版功能

- 点击地点条展开地图，含大地图与黑狱平面、当前位置标记、节点资料。地图只查看，不移动、不发消息、不推进时间。原卡地理矛盾及隐藏区域处理见地图只读说明.md。
- 左图位接人物立绘：按当前主焦点人物精确匹配配置，支持加载、缺图占位、点击大图。已移除“刑狱志”装饰画占充立绘的做法。实际图包地址与文件对应由后续 AI 处理，当前不包含人物图包。
- 武学栏记录**主角的当前境界与已掌握武学**。从本次开局及截至该楼的明确状态回报重建；无成长不清空旧记录，练习不自动算掌握。单独保留本轮练习/契机/成长分量。
- 案簿、在场他人仍可展开收起。地图和大图弹窗可关闭，支持 Esc 与返回焦点。

## 数据与边界

原24字段保留，V5在副人物与成长字段之间增加player_realm、player_skills，共26字段；兼容旧24字段。原人物五阶、气象、线索、近远风闻等含义不变。不添加参考卡的心跳、体力或金钱。

玩家武学回放.js只读聊天：定位当前消息，忽略未来楼与旧候选，从本次开局重建档案。境界只接受原卡十阶及其巅峰描述；武学只按明确登记/回报合并。缺报、无、未明不清空已有记录；不从growth_skill猜习得或升级。删楼或重生成后按当前聊天重新计算。无法可靠绑定宿主楼时只显示本楼快照，并提示开局未关联，不冒读最新聊天。

本轮不写聊天变量、MUV或localStorage，不新增奖励、经验、日历、移动或后台结算；只读回放不是新的成长引擎。当前画像只对应主焦点人物，主角武学另有明确标题。

## 可维护源与接入

- 模板.html、样式.css、交互样式.css：布局与样式。
- 地图组件.js、地图样式.css：只读地图。
- 玩家武学回放.js、交互控制器.js：档案回放、宿主楼定位、弹窗与高度。
- 本地图包.js、立绘配置.json：画像端口，详见本地图包接入说明.md。
- 核心输出协议.txt：V5输出要求，同时由角色原生depth_prompt（system/depth0）发送、description备援；标识ZYX_STATUS_PROTOCOL_V5。
- build.cjs：重建状态栏正则.json和预览.html。离线预览使用明确标注的虚构快照。

HUD和零楼均为HTML代码块前端，需要酒馆助手执行。HUD脚本采用静态内嵌data脚本，不用eval或外部库；其余正则必须保留显示/提示词阶段划分。普通状态字段拒绝HTML与原始反引号，避免穿出代码块。03只隐藏未闭合尾段；04仅清理depth3及以上AI历史状态；缺报只提示，不造假数据。

完整卡用上级试用卡/pack-card.cjs生成，局部apply.cjs只安装HUD，不安装零楼与每轮输出契约。不要手改成品中编码的脚本。打包与后续立绘步骤见上级试用卡/试用说明.md。
