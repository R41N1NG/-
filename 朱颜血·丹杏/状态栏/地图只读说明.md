# 只读地图组件

身份：gpt下级（实现角色）。

仅使用用户原卡 `character_book.entries[2]` 的地理资料。宏观图按罗霄—长宁—神仙岭、武平—神仙岭、杏花村—豺狼坡／险道及南向道路等原有拓扑绘制；豺狼坡细图沿用原卡平面图上下、左右排布，不另校定朝向。不是现实坐标图，不按比例。

原资料的官道里数及图内押解耗时与后附表存在冲突，本图全部不标里数、速度或耗时，不替资料选择一套结论。原平面图把地下段排在监舍和前院之间；地下未显示时，两段相连线路也不渲染，不凭空补出前院到监舍的直通路线。

由根把两个文件拼入同一个HUD iframe。dialog须位于 `.zyx-hud` 内，以满足样式作用域；不依赖库、图片、字体或外部网络资源。

```js
const handle = window.ZYXMapPanel.mount(dialog, {
  location: 当前地点字符串,
  identity: 当前身份字符串,
});
dialog.showModal(); // 由调用方决定打开时机
// 卸载时可选：handle.dispose();
```

`mount` 自动设置 `data-map-dialog` 并替换该dialog内容，不自行打开。重复挂载同一dialog先清理旧监听。关闭按钮、原生Esc及遮罩点击均关闭原生dialog；不会关闭点在内容或边框内的点击。两个页签支持点击、左右方向键、Home/End。地点是实际button，最小48px高度；长图和说明在dialog内滚动。

地点匹配按具体名称优先；例如“杏花村客栈后院”不会误标成黑狱后院。地下／水牢只在当前地点含“地下”“水牢”，或身份含“黑狱恶差”“黑狱差役”时才加入细图和连线。该规则仅是界面可见条件，源码不是保密边界，也不写入知晓、身份或权限flag。

点选只更新地点说明与选中边框，不触发旅行、时间变化、消息发送、变量写入；不显示剧情物证、敌人、奖励或通行成功与否。未匹配的地点只显示传入文本，不臆造当前位置。

本轮有限浏览器检查：真实 Chromium 下，14种地点匹配、两页切换及方向键、地下显示门槛、关闭按钮/Esc/遮罩、多实例、输入按文本呈现均通过。1100/375/320视口两页无横向溢出，320视口地点按钮约78×48px；没有外部请求、页面异常、变量调用或发送动作。已修正初稿画布aspect-ratio导致的窄屏撑宽。此结果是独立组件夹具验证，不等于真实酒馆接入或业务权限验收。
