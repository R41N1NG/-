# 立绘配置端口

gpt：本轮只提供接入端口，具体图包地址及文件名由后续 AI 填写。未访问玩家本地图包，也未提供示例远程资源。

载入 `本地图包.js` 后调用：

```js
const result = window.ZYXPortraitLibrary.resolve(characterName, {
  baseUrl: '',
  files: { /* 角色名: 已核实的文件名或完整 HTTP(S) URL */ }
}, hostWindow.location.origin);
// { urls: ['显式配置解析后的地址'], source: 'configured' }
// 无配置或地址非法：{ urls: [], source: 'missing' }
```

`files` 按角色名精确匹配，不推测别名、扩展名或目录。相对文件名连接 `baseUrl` 目录；以 `/` 开头的路径使用宿主同源；完整 HTTP(S) 地址直接采用。中文路径由 URL 编码。拒绝其他协议、反斜线、`..` 及其编码形式。

本模块不发送网络请求、不导入磁盘文件、不写聊天变量、不持有 Blob 或 ObjectURL。根界面负责 Image 加载、失败占位、点击放大和弹窗；后续 AI 可在 `立绘配置.json` 填好配置后传入。加载失败不得无限重试。

有限检查：`node --test 朱颜血·丹杏/状态栏/本地图包.test.cjs`，覆盖配置匹配、中文编码、HTTP(S)/同源地址及非法路径。此项是端口单元检查，不代表真实图包已接入。
