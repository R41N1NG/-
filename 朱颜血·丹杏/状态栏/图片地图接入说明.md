# 图片地图接入

身份：gpt下级（实现角色）。

本版完全移除旧拓扑节点、连线和建筑示意，只显示明确配置的地图图片。默认“大地图”“黑狱图”的file均为空，显示“地图图包尚未接入”；不请求图片，不生成替代图，不推测路径、文件名或解锁条件。旧《地图只读说明》的拓扑描述仅对应旧版，不适用当前组件。

保持原API：`window.ZYXMapPanel.mount(dialog, { location, identity })`返回`{ dispose }`，调用方自行`dialog.showModal()`。dialog应位于`.zyx-hud`内。location只作当前地点文本展示；identity为兼容保留，不据此猜测图片权限。

由根把《地图配置.json》作为`window.ZYX_HUD_CONFIG.maps`注入。同源宿主也可显式提供`window.ZYX_DANXING_MAPS`覆盖。schema为`{ baseUrl, images: [{ id, label, file }] }`；每个id应唯一，空file保留占位。baseUrl与file只能由知道实际资源地址的负责人填写，禁止根据标签猜图地址。

组件复用同iframe的`ZYXPortraitLibrary.resolve`做精确id到file的URL校验，需要该端口先加载。相对文件路径以显式baseUrl及宿主HTTP(S)源解析；绝对HTTP(S)文件地址可直接配置。非HTTP协议、目录穿越等非法配置不会发请求。配置不合法或组件不可用时显示提示，不回退到任何拓扑图。

切换标签只加载选中的明确文件，不预取其它图。切换及dispose递增请求代次，晚到图片不能覆盖当前选择；未配、载入失败都显示文本占位。所有标签、当前位置使用textContent，关闭按钮/Esc/遮罩关闭，页签支持左右键及Home/End，长内容在dialog内部滚动。

此组件不读写聊天变量、知晓flag或剧情状态，不发送消息、不旅行、不推进时间。图片可能包含的地理/剧情内容由图包提供者审定，本组件不额外叠加敌人、物证、奖励或热点节点。未生成或搜寻任何地图资产。
