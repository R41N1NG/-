# 尾行 · 申报协议与词表（v0.1 草案）

> 定位：整套数值系统接入酒馆的实现桥。架构平移仙姝堕数值事件申报的成熟模式（模型只有举证权），按尾行的多类型申报扩展。
> 铁律：**宁可不结算，不可错结算**——解析不了、校验不过、词表对不上的，一律降级为无机械效果的叙事，绝不让 LLM 的口述直接动数值。

## 一、协议总览：四类标签

LLM 在正文之外输出结构化标签，中控解析路由到对应处理器：

```
<动作>跟缀｜身后</动作>          ← 玩家机械动作（判定入口）
<事实>她的表现｜提速</事实>      ← 世界/她的客观事件（触发事件处理器）
<谎言>自称快递员｜她｜楼下｜高</谎言>  ← 已定稿格式（见数值策划·口才）
<模式>接触</模式>                ← 阶段/模式切换（潜行/接触）
```

- 分隔符全角竖线，格式解析失败整笔丢弃＋诊断计数，不锁流程不重试；
- 四类标签在给玩家的可见正文里全部剥离（同仙姝堕 `<Promotion_result>` 处理），不产原生楼；
- **一楼一队（主人定稿）**：每楼动作申报组成队列（上限 3 个），交掷骰插件的**结算台**顺序结算——复合输入（「跟上去顺便拍张照」）不拆楼、不浑账，队列内**状态实时传递**（跟缀的心跳余波当场影响后续拍照的手抖判定）。防刷靠队列上限；事实/谎言/模式类按各自规则限次。
- **模式状态机**：`<模式>` 推动日段 × 模式组合态转移。转移边全集：准备→开窗→潜行或接触（出门选择）；潜行↔接触（现视 / 隐匿，一楼至多一次）；任何→终局（下手申报，不可逆）；任何→收摊（她到家 / 放弃 / 过窗）；强制转移 = 被察觉（潜行破裂进她的反应轮）、终局失败（进结局）。
- **距离双栖语义**：潜行四档（目视远端 / 同街 / 身后 / 贴身）是「贼的位」；接触四档（隔街招呼 / 店内对话 / 并肩同行 / 私密距离）是「朋友的位」。词条 `args` 跟模式走；切换模式时距离档换轨不继承；机会等级读两套最近值。

## 二、防错四锁

1. **依据锁**：申报内容必须是可见正文的逐字子串（校验前剥离 think/状态栏/标签自身）——防凭空申报，更防叙事与数值分裂：数值层结算的动作正文必须真写了，正文写了的动作数值层必须有账；
2. **限次锁**：动作队列一楼 ≤3、模式切换一楼一次、过档事实一晚按档位数封顶、谎言按账本规则；
3. **词表锁**：词条外走归一→降级→诊断，无机械效果——宁可不结算，不可错结算；
4. **回执锁（演出纪律）**：LLM 正文结局必须与回执一致——骰子成功正文不能写失手，她警觉涨了正文不能写浑然不觉。软校验（result 字段对正文结局段核对）＋诊断＋下一楼修正引导，不删楼不锁流程。数是脚本的，笔是模型的，笔不能翻供。

GM 覆盖期间自动申报整笔拒绝（同仙姝堕语义）。

## 四、词表外处理：归一 → 降级 → 诊断

LLM 叙事天然会写词表外的表达，三步走：

1. **同义词归一**：先查 `aliases` 映射表（「跟上去，保持二十步」→ 跟缀｜身后）；
2. **氛围降级**：归一不了的，当纯叙事处理——**无机械效果**，正文照写。判定为「这一段没有可结算动作」，零伤害；
3. **诊断计数**：降级事件计数，超阈值提示词表要扩——词表是活的，跟着实际游玩的长尾长大。

## 五、玩家输入翻译链与流水对账

```
玩家自由文本（"我跟上去，别太近"）
   ↓ LLM 翻译（按常驻条目里的词表规则）
<动作>跟缀｜身后</动作>
   ↓ 中控结算（掷骰/修正/DC 全在脚本）
回执：流水（人读）+ JSON（机读）
   ↓ LLM 按回执写正文
玩家看流水对账 —— 翻译错了（说拉远却结算成跟缀）可下一楼纠正或 GM 手改
```

流水是**对账单**：玩家侧全透明，每笔结算的骰值、修正来源、DC、结果一行见底。她的暗账只给数字不给原因（数值策划明暗规则）。

## 六、注入策略（细则，暂定——预留修改空间）

**核心原则：LLM 眼里词表是菜单，不是手册**——词条的 DC / 修正 / 消耗一律不注入（数值住 `rules.json` 给中控），LLM 只需认词、用词、申报。词表注入极简到一行一词。

**六块注入内容**：协议卡（标签语法 + 四锁 + 回执遵循，常驻 ~300 tok）｜模式词表切片（随模式换装）｜票据条目（本轮事件票 + 演出指引，**每楼脚本改写**）｜状态简报（日段×模式、距离档、玩家明态、可用道具）｜上楼摘要（上楼结算一行——LLM 演手抖的依据）｜谎账简报（仅接触模式）。她的暗态永远不注入数值，只随票据下发票据级演出指引——信号歧义在注入层焊死。

**模式切片**：准备期（准备 5 + 数字 5 + 套话 2 + 载具 2 ≈ 14 条）；潜行（潜行跟踪 28 + 观察 5 + 载具 2 ≈ 35 条）；接触（互动 4 + 应对 3 + 观察 3 + 车厢 6 ≈ 16 条）；终局（无词表，走插件连掷）。managedEnabled 换装，防递归照搬仙姝堕。

```json

  "dc":{"base":13,"hidden_mod":2}, "result":"成功", "ledger":{"警觉":+2,"心跳":+8} }
```

```
[跟速检定] 1d20(11) + 敏捷(5) + [耳机伪装](+2) = 18
           vs DC15 ← 基础13 +2(她的状态，原因不明) → 成功
```
