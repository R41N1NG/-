A 2d spritesheet of d20 rolling animations  (one strip for each of the 20 results, with 12 frames of 512x512px). Restarted from scratch after ruining it all on my previous set (http://opengameart.org/content/d20-rolling-animations).

Click on the gif to get an animated preview of all the animations.
Available to download below is the tiled image of each roll in a separate larger image.
In the 7z file are included the blender file used to generate it all, the script used to generate the random roll animations, a .json dictionary of previously generated rolls for each of the 20 results.
