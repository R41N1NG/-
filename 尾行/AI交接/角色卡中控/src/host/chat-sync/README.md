# 重点维护模块：聊天与存档同步

玩家反馈“对话与存档不匹配、串档、重复扣账、删楼后进度错误”时先查本目录。

| 文件 | 职责 |
| --- | --- |
| `controller.js` | 串行操作、完整状态恢复、提交、备份恢复、诊断入口 |
| `session.js` | 聊天身份和任务代际校验，切聊天后取消旧任务 |
| `timeline.js` | 消息指纹、回合分支、最后共同检查点、保留窗口 |
| `repository.js` | 宿主聊天变量读写出口 |
| `keys.js` | 聊天变量名契约 |
| `diagnostics.js` | 只含阶段、楼号和错误码的有界诊断 |

`glue.js` 负责事件接线。完整引擎档格式与迁移位于 `src/runtime/game/save.js` 和 `src/runtime/persistence/migrations.js`。

专项文档：[聊天与存档同步专项](../../../docs/聊天与存档同步专项.md)。运行 `npm run test:sync`，代码检索标记为 `CHAT_SYNC:`。

新档版本为 v2，时间线协议为 schema 1。旧 v1 档迁移时保留原随机流。聊天身份或完整历史缺失时，诊断会注明能力降级，不能保证删楼、分支和消息去重。实际宿主事件与异步变量 API 行为仍需 TT 实机验收。
