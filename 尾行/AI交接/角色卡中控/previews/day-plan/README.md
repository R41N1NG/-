# 每日行动与时段：可操作预览 v0.8.8

下载 `index.html` 后直接用浏览器打开，无需安装依赖。使用正式 UI、引擎及聊天同步模块；试玩数据与酒馆相互独立。

- 可查看固定地图、市内移动、选择工作、线上补给、黑市采购、休息、度过本时段；日终后进入下一天并收取到货。
- 线上仅售食品，黑市器材须先通过地图前往 C 区临江黑市；浏览／取消不收费。交流和尾行入场仍待接具体内容。
- 上方五个按钮用于重置试玩状态。尾行中为显示样例，不执行原尾行判定。
- 浏览器允许本地存储时保存试玩进度；禁用存储时仅保留本页内存。
- `map-city.png` / `map-district.png` 为全城与手机街区图。
- `black_market.png` 为临江黑市现场采购；`shop.png` 为线上食品；`work.png` 为工作选择。
- `desktop.png` / `mobile.png` 为 1100px / 390px 实际浏览器截图，另检查 320px 无横向溢出。

重新生成：`npm run preview:daily`。截图与交互验收：`npm run test:browser`。

维护见 [日程行动框架](../../docs/日程行动框架.md)。正式卡默认保留原流程，可从明确入口试用日程；目标全天日程与尾行入场尚待接通。
