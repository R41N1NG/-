# 每日行动与时段：状态栏预览

下载 `index.html` 后直接用浏览器打开，无需安装依赖。

- `desktop.png`：1100px 浏览器实际截图。
- `mobile.png`：390px 浏览器实际截图。
- 页面按钮可以查看早间 4 点、午后 3 点、尾行中 2 点、本日结束 0 点，以及当前正式流程。

这是显示预览，不是完整日程试玩。演示状态经过实际引擎存档、恢复后生成快照；切换按钮不执行活动，也不消耗游戏进度。

v0.8.5 已移除误导的探头标签，路线进度改为“剩余 N 段”，不代表行动点或剩余回合。

v0.8.4 已接正式日程条与共用存档字段。目标全天日程、身份排班、活动入场扣点和完成后时段推进尚未启用；当前正式卡的夜间流程在页面第五个状态中展示。

重新生成：`npm run preview:daily`。截图与窄屏检查：`npm run test:browser`。生成真源：`tools/build/day-preview.js`，日程视图：`src/ui/renderers/day-plan.js`。
