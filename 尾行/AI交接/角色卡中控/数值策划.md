> 三条总纲：
> 1. **效果只认标签**：凡加减益，后台标签栈说了算，叙事口说无效（防 LLM 口胡）。
> 2. **故事描写，后台定果**：LLM 只申报事实，骰子、修正、结算全在中控（借仙姝堕 dispatcher 架构）。

> 4. **一切结算汇于状态栏**：所有插件与子系统共用中控单一真源，结算结果最终统一体现在状态栏上，不允许第二本账。
> 5. **LLM 出场判据是「有戏没戏」**（主人定纲）：例行走插件（打工、购物等纯数字结算零楼数零 token），有戏才请 LLM（搭话对话、节点事件、剧情时刻）。判据一句话：这件事值不值得写成一段让人读的话。白天是棋盘，晚上是小说，但棋盘上值得入戏的时刻 LLM 随时进场。

### 开局身份制（v0.8 定稿，主人拍板；原「出身模板」泛化重生）

**结构**：开局三步——**选身份 → 分 20 点（五维自选）→ 进游戏**。身份是开局配置层的东西：属性小修正＋通行特权＋本职工种＋负面，全部在开局落账；**不碰运行时规则层**（运行时的数值是属性与优势的领地，身份永不染指）。原五出身模板变为身份池中五个的「快捷预设」（自动填身份＋推荐点数），模板玩家体验不变。

**设计纪律（主人定稿）**：①效果必须写明公式和数字，严禁「听得到风声」式模糊话；②负面与正面对应，正面不强的身份不带负面；③优势可以是通行权但不必都是；④身份不是词条不是动作，LLM 零申报，效果全部由中控在开局/结算点自动执行；⑤每格效果必须注册进后台配置与引擎（见本节末注册清单），嘴上说说不算数。

## 二、核心检定

```
检定 = 1d20 + 属性值 + 状态修正 + 环境修正（全走标签栈） vs 动作DC
```

**动作 DC 表（基础值，实际 DC 叠她的暗标签）：**

| 动作 | DC |
|---|---|
| 远远缀着不跟丢 | 10 |
| 拍一张能看清的照片 | 13 |
| 同街尾随不被注意 | 13 |
| 身后十步内尾随 | 16 |
| 贴身（扶梯、排队） | 19 |
| 捡她掉的东西不被看见 | 16 |

**动作双轨制**：
- **主干动作全开放**：所有动作人人可试，属性只出现在修正栏，检定筛胜率（阿宅也能撬门，只是 35% 对壮汉 65%）；
- **门槛选项是额外线路的钥匙**：属性达标才亮的玩法分支——体格 ≥7 解锁「破门突入」「扛人就走」重暴力分支；口才 ≥7 解锁「伪装身份长期渗透」明线；情报 ≥8 直接开她的读人档案页。门槛管资格，解锁的是线路不是基本动作。

**对抗检定**（她主动出手）：`1d20 + 她的敏锐` vs `1d20 + 玩家敏捷或情报 + 隐蔽修正`，高者赢；平局 = 她起疑未锁定，警觉 +5。

## 三、五道闸（d20 方差驯服，暂定方案）

2. **优势双骰（主人定稿 2026-10-16：阈值标签制）**：效果只认标签——**优势五标签**，达线由中控自动挂、掉线自动摘（`game.js syncThresholdTags`，每楼对表）：

   | [优势：情报] | 累计 PI ≥ 60（＝八节「深层线索」解锁线） | 情报属性全部 1d20 检定单骰变双骰 |

4. **天然 1 选择权**：咽下（中事级警觉 +8~20，事故演出）或付代价抵消（体力 -20 / 现金 -50 / PI -2 任选）。

## 四、状态量公式

**她的警觉（暗值 0~100，五档）：**
```
警觉 += 事件威胁值 × 距离系数 × 环境系数 × 她的敏锐系数
威胁值：小事 3 / 中事 8 / 大事 20
距离系数：远端 0.5 / 同街 0.8 / 身后 1.2 / 贴身 1.8
环境系数：雨夜 0.7 / 夜 0.9 / 白昼 1.0 / 空旷 1.4
敏锐系数：0.8 + 敏锐 × 0.04
```
档位：0-20 毫无察觉 / 21-40 不安 / 41-60 起疑 / 61-80 确认 / 81+ 反应（2026-10-19 主人定：先留一段完全无感的余量，行为从 21 起才启动）。
**当晚开局警觉 = 时段基础（18~21点：0 / 21~23：10 / 23~01：20 / 01后：30）+ 长期戒心 ÷ 5**——深夜独行的她天然处于「不安」档起步，防着所有人。
**她的路线智能**：不安档以上的她主动绕开她自己害怕的路段（安全路线在事实池里）——堵无人巷堵不到她，猎物对危险的直觉先于猎手的计划。
近似事件拆开算，同晚重复小事边际递减（第三次要么质变要么习惯化，按情境，不机械累加）。

**玩家心跳（阶段条，操作线，已定稿）：**
- 公式：`心跳 += 刺激值 × (1.4 - 胆量 × 0.08)`（系数即胆量减免，不叠第二层）。
- **激活规则（猎手状态）**：心跳只在尾行、潜伏、伪装身份的接触、终局行动中激活；准备期与熟络后的正常社交不进账。紧张来自非法感，不来自距离感。
- **刺激值按暴露风险定级**（非物理距离）：无风险（合法状态：熟络社交、准备期）0 不进账；低风险（远缀、伪装寒暄）+5~10；中风险（贴身、被扫过、环境突发）+10~20；高风险（对视、验证雷前兆、终局行动）+25~35。刺激值表保留，后续可做随机事件池。
- **刺激接线（v0.8 补档，已落码，数值暂定待真机调参）**：`rules.heart.stim.pump`——**持续暴露按段一泵**（跟缀族 follow/ride_along/transfer/follow_work/ride_follow/car_follow，按当段距离档：远缀 5／同街 8／身后 12／贴身 16；楼内排队多个动作只泵一次）；**事件类照单泵**（天然 1 爆露照面 28、环境突发猫 10 狗 18）；跟丢 5；勉强维持结果带 +5 原判不叠档；天然 20 白给不泵；接触明线伪装寒暄 5（接近度 ≥60 的熟络常规社交不进账）；熟区环境类减半（×0.5，指向类永不减）。泵计入当段峰值（段税按峰值定档）；环境突发由 processFloor 结算挂账、快照读缓存（演出与账同源）。**节奏锚（暂定）**：标准晚＝9~10 段（5 节点动线 × 每跳路段段＋到点停留段，段＝10~30 分钟切片，非节点数）；此锚下十段曲线——同街第 2 段入甜区第十段顶格 65、贴身 3~4 段变形 6~7 段崩、胆 2 同街第 7 段变形（被逼远缀长焦流）。夜长由内容层调度，引擎不持有。
- **开局基线 = 30 统一**（v0.8 主人定稿：原 `30+(5−胆量)×3` 作废——胆高起点低等于进甜区反而慢，双重罚；胆量的心跳优势＝刺激折扣＋缓息效率，不在起点；段末回落与过夜回基线的锚同步统一 30）。
- **甜区**：40~65 全检定 +1；甜区顶与操作线只留 5 点缓冲（刀尖设计，主人定稿保留）。
- **操作线**：>70 [操作变形]（精细 -2），>90 [操作崩溃]（再 -2）。**全员统一线（v0.8 清账：[老手]/[新手] 双轨废弃——胆量的心跳系奖励只走优势：胆量，同轴不开第二条轨）**。
- **回落**：段末 −5 至基线为止；[缓息] 每段 −(10 + (胆量−5)×2)、单段最低 6，可降至 20。
- **封顶（v0.6）**：心跳上限 100——条打满即「濒临失控」的视觉语义，数值不飞。
- **体力联动（v0.6 定稿）**：段体力消耗按当段心跳峰值定档（税表见「玩家体力」）——心跳条即体力税表，紧张就是消耗。
- **区域熟悉度**：单区域累计 10 个场景段算熟；熟区内环境类刺激值减半，指向类（她回头、对视、差点暴露）永不减——路熟救环境，不救心虚。

**玩家体力（v0.6 重写：段税挂心跳）：** 上限 = 100 + 体格 × 5。
- **段税＝心跳档位税**（仅猎手状态激活时段收取）：按当段心跳**峰值**定档——<40 → −1/段（维持税）；40~65（甜区）→ −2/段；66~89（变形区）→ −4/段；90+（崩溃区）→ −6/段。缓息段无进账、峰值即段初值。同一动作随心跳涨价，越浪越累。
- **连掷不叠**：追逐 / 冲突走每轮账（追逐 −6/轮），不收段税。
- **移动账**：走 −1/公里、快走 −3/公里、奔跑 −12/公里；静止段（蹲守 / 潜伏 / 入座）零段税，静蹲回 +4/10 分钟——平静段（税 −1 + 静蹲 +6）净回 +5，蹲守流回血特性保留。
- **节奏验算锚**（胆 5、上限 120）：远缀夜 −15、标准尾行夜 −21、贴身浪 −20~24、高压夜+追逐 −78（压回满线）；多日循环——每晚 −68 以内永不欠债（醒满血），−84 以上锁死 96/72 醒点（过夜「恢复至」语义的债务循环），饭是赎身券、停拼是洗白键（详见第二十四节）。

**过夜结算：**
```
长期戒心 += max(0, 当晚警觉峰值 - 50) ÷ 4 （四舍五入）
次日开局警觉 = 长期戒心 ÷ 5
```

## 十二、冲突检定（强行下手，2d10）

**两条入口（v0.6 重构：偷袭与强攻是真分支，不是修正差）**：

- **偷袭（贴身限定）**：只有摸到贴身档（潜行线的终点）才有资格——**必压制一轮、必进挣扎轮**（能无声摸到这个距离，潜行检定早已付过代价，偷袭本身不再掷）。此后挣扎轮（进度制）：她攒满 3 格挣开，按住＝小声浪；**挣脱→按胆量分流**：胆大反击（进强攻轮）／胆小尖叫逃走（声浪判定＋追逐轮）。偷袭是「安静地开始，持续地漏气」。
- **强攻（身后即可）**：门槛低——身后距离就能发动。代价：**无法压制声浪**（她的嘴自由，声浪判定全程照走）；**掷战力定成败，面对高体格目标非常容易失败**（不吃先手；女警的迎战倾向天然克强攻）。**成功＝挂 [压制] 标签**——一拳打到肚子式的剧痛失能：她的体格大量减值（视同 1）、被搬运时几乎无反抗、**无法再进行声浪判定**。强攻是「吵着开始，安静地结束」——它的胜率窗口只在私密场所。

**挣脱进度制（定稿）**：挣扎轮她胜出 +1、大幅胜出（差 ≥5）+2，攒满 3 格挣开；你的体格每高她 2 点，进度增速降一档；转移（拖拽）＝压制态持续动作，每轮结算挣扎进度＋声浪。

**战力公式（两入口共用强攻轮）**：
```
战力 = 体格×3 + 敏捷×2 + 2d10 + 修正
修正：偷袭先手 +5（仅挣脱后的强攻轮）/ 她警觉每过一档她方 +2 / 玩家心跳>80 玩家方 -3
```

| 差值 | 结果 |
|---|---|
| ≥ +20 | 完全压制 |
| +5 ~ +19 | 得手但有挣打，留痕 + 声浪检定 |
| -4 ~ +4 | 纠缠，二轮再掷 + 声浪检定 |
| ≤ -5 | 被反制 |

**捂嘴与挣扎（v0.6 替换声浪机制为主机制）**：
- **捂嘴只判第一轮**：偷袭先手赢下首轮＝捂嘴成立，她的喊叫通道关闭——此后声响全部来自挣扎；
- **挣扎轮**（此后每轮）：`1d20 + 她的体格(与敏捷取高)` vs `1d20 + 你的体格`——**体格差越大她越容易挣脱**；你按住＝**小声浪**（挣扎的闷响，进她的警觉账但不惊动街区）；
- **挣脱后分流走胆量**：胆大的（胆量高）**直接反击**——转身肘击、踩脚、抠抓（对玩家反制）；胆小的（胆量低）**尖叫逃走**——挣开即尖叫（走下方声浪判定）＋拉开追逐；
- 你天然 1＝捂嘴失手，她喊出声＝声浪直接过；她大失败＝踹翻垃圾桶／打碎玻璃＝大声浪进「有人听见」；
- **未贴身的冲突（她的嘴自由）**：原声浪检定照走——`1d20 + 她的胆量 ± [胆小 −5 / 胆大 +2]` vs 地段 DC（闹市 5 / 普通街 10 / 无人巷 15），过＝有人听见；[胆小]（胆量 ≤3）/[胆大]（≥6）阈值自动挂（档位表见二十五节·她的属性档案）；
- 转移（拖拽带走）每轮＝挣扎轮＋声浪照算；
- **停挣扎道具（蒙汗药类）挂起**：商城系统专项讨论。

声浪响后进**目击者介入轮**：路人介入检定，公开场合几乎必成 → 冲突中断，玩家只剩逃跑（带目击，追缉 2 级素材）或落网。多层漏斗：战力层筛弱的，捂嘴挣扎层筛莽的，只有私密 + 低防备的真时机穿透全链。

验算锚点：阿宅（体2敏4，基础14）对女警（体6敏7，基础32）差 −18 稳定被反制；普通男（4/4，基础20）对普通女（3/4，基础17）期望差 +3 落纠缠档——撕扯、声浪、留痕的系统戏。

**两轴咬合**：接近度涨最快的通道全在近处，而近处每步都给心跳进账——胆量是门槛，口才是工具，心跳是摩擦力。接近度越高，心跳激活越少（融入而松弛），终局行动时以最凶火力回归。

**设计原则（主人定调）**：明面上越熟悉，反差感与背德刺激越强——中间那段松弛正是温床。明面上的熟人，背地里的猎物和猎人。

**备忘（主人构想，暂缓）**：双结局线——终局放手的好结局（其实她也喜欢你，只是你误会了）；接近着成情侣的可能。复杂度高，挂后。

### 刷脸编舞（暗线通路，定稿）

- **定义**：非尾行状态、低威胁地出现在她视野（便利店排队、同电梯、街角迎面、同班公交）。不掷骰，靠姿态条件：同街距离以上、不重合行进轨迹、停留一个场景段内。姿态不合格即尾行，进警觉账。**刷脸管「出现」，尾行管「跟随」，两本账不串——领地豁免只覆盖出现。**
- **涨幅**：合格刷脸 +2~4（按场景自然度）；眼熟段全额，有交集段减半，可搭话段无效——刷脸刷不出熟络，暗线天花板卡在明线地板上交棒。
- **界限三线**（硬规则，不靠 LLM 拿捏）：频率线——同一场景 48 小时内重复出现 → 疑虑检定（定点 DC12 / 轮换 DC15）；总量线——单周出现超 4 次 → 每超一次疑虑自动 +1；姿态线——不合格直接走警觉账。状态修正：她处「不安」档以上疑虑检定 +2，[结伴] 再 +2。
- **疑虑**（暗值，只给行为信号：换店、咬耳朵、表情微妙）：可消解——合格场景里一次成功自然搭话双收（疑虑 −1、接近度 +3~5）；日常话不是谎、不进谎言账本、无法被查证。敏锐 ≥7 的她同场景重复搭话 DC +2；疑虑触发过「变味事件」（换店换路线）后小戒心不退——疑虑可消，历史留痕。归因检定通用于刷脸场景。

### 认脸两层制（v0.6 重写：照面统一）

- **照面（统一触发词）**：她的眼睛落到你脸上。照面 → 面容记忆进账（遮挡照面不涨）；照面＋扳机已扣 → 身份关联判定。LLM 票据只报「照面」一类事实，脚本按等级定后果，不设两套申报。
- **面容记忆**（累积条，暗，满 20，不衰减）：进账唯一因 = 她看到你的脸；**潜行中绝不固定涨**：

| 照面等级 | 记忆 | 掷关联判定？ |
|---|---|---|
| 潜行全绿 / 失败但未照面（跟丢、声响暴露） | 0 | 否 |
| 勉强档瞥见（DC−1~−2） | +1 | 否（惊鸿一瞥对不上号） |
| 对抗被锁定 / 天然 1 爆露 / 冲突 / 数秒对视 | +2 | 是（扳机已扣才掷） |
| 接触模式正常社交 | 每段 +2 | 否（她在社交不在戒备） |

- **身份关联三件套**：①**扳机**——警觉进确认档，她坐实「有人一直在跟踪我」；②**契机**——一次看清你的时刻（正面对视 / 冲突 / 行动失手爆露 / 事件撞见）；③**判定**——`1d20 + 她的敏锐 + 每 5 格记忆 +1` vs `10 + 遮挡`。扳机不扣，脸见再多只是张熟脸；扳机扣了没契机，她知道「有人」不知道「是谁」。
- **遮挡来源与封顶**：夜色 +2（环境自动）、口罩 +3、墨镜白天 +1、帽子 +2（未出卡）；**遮挡合计封顶 +5**——夜行标配（口罩＋夜色）全额，帽子起吃封顶，防伪装器材未来堆料把浅养期认脸堆成半免疫。
- **蒙面被目击**：遮挡照面记忆不涨，但「街上有蒙面男」威胁值升一档（小事→中事）——挡清算，不挡警觉。
- **库存弹药（滞后引爆）**：扳机未扣时的照面照常涨记忆；确认后一次契机把存量全算上——她先见脸、后对号（「原来电梯里那个就是你」）。
- **判定后果**：过 = 对上号：接近度 <40 插认脸旗；≥40 触发**重叠事件**——戒心暴涨而接近度不清零，她对「你」的全部认知一夜重结算，涌现反杀与情感爆点的入口。刷脸攒的每分接近度都在给重叠加当量。
- **体系闭环**：面容记忆是关联加成——明面上越熟悉，暗地里越藏不住（反差总纲的机制表达）。
- **验算锚**：记忆满 20＋敏锐 8（女警）vs 遮挡 5 → 认出率 90%，深养裸脸必认；高中生记忆 5：口罩＋夜色把认出率 80% 压到 55%——遮挡救浅养不救深养，养与杀的「杀」住在这条曲线里。

| 同学 | 35 | 15/20 | 校园、通勤段 |

- 身份单选不重合（主人定稿）。尾行动机天然错开：陌生人全知皆盲，同学知其人不知其家，邻居知其家不知其日程与其他半径。
- **领地制**：领地内出现不进刷脸计数、自动缓涨接近度（每场景段 +1）；领地外出现照常计数且疑虑系数 ×1.5（越界更刺眼）。领地弹性：偶尔越界是机会（+3~5），频繁越界进敏锐检定；她的戒心会收窄领地宽度（出过事后她等你先走）。
- **双刃**：天然身份买接近度（开局有交集档、搭话解锁、明线电梯直达）卖隐蔽性（面容记忆开局高、关联判定吃加成、暗线高难高刺激、重叠当量最大）。
- 开局两层选择：**属性 build 决定怎么玩，关系身份决定从哪开始**。
- 数值均暂定，内测调参。

### 终局结算（接近度轴收官件，暂定）

**设计铁律（主人定调）**：终局行动常开，扳机一直在玩家手里；**条件不成熟的动手，失败必须是机制的必然**，不靠 AI 劝、不靠玩家自觉、不靠运气放过。目标：过程即游戏（博弈、紧张、刺激、背德全在接近的路上），终局只是过程的收割。

**机会等级（0~5，实时合成，对玩家暗）**：三因子——她的防备（接近度档 + 当前警觉档 + 疲惫/醉酒）、场所成色（独处、封闭、深夜、目击可能、逃跑路线）、先手条件（偷袭位、背身、熟睡、醉倒）。直接进战力硬修正：

| 机会等级 | 战力修正 | 状态 |
|---|---|---|
| 0 | −15 | 全防备、本能全开 |
| 1 | −10 | 高警觉 |
| 2 | −5 | 常态防备 |
| 3 | 0 | 放松 |
| 4 | +5 | 迟疑轮插入 |
| 5 | +10 | 僵住 / 熟睡 / 醉倒 |

验算：阿宅开局硬来稳定被反制；体格 8 壮汉 0 级也只剩挣打得手，随后落入声浪层。

**多层漏斗（条件不成熟层层必死）**：战力层筛弱的 → 声浪层（0 级她的反抗毫无保留，声浪 +5）→ 目击者介入轮（公开场合几乎必成 → 冲突中断：逃跑带目击进追缉 2 级，或当场落网）。只有私密 + 低防备的真时机穿透全链——而那本身已是高机会等级。

**防第一晚硬来的六道墙（世界自身的逻辑，非规则禁止）**：①知识墙——场所成色靠情报，她的安全路线在事实池里，且不安档的她主动绕开危险路段；②距离墙——冲过去先赢追逐战（追逐用敏捷、按制用体格，属性错位天然平衡），且**追逐轮声浪持续结算**；③身心墙——当晚开局警觉的时段基础让深夜的她防着所有人（机会等级 −1）；④转移墙——拖拽转移每轮挣扎＋声浪照算不豁免；⑤结算墙——穿透全墙的下场是 3% 白卷 + 陌生档事后链 + [身形醒目] 追缉识别加成速落网；⑥教育墙——白卷结局的完整度对比，玩家看一次就懂。哲学：她不是靶子，是有生存本能的活人。

**渐进墙（v0.6：六道墙的进度化具象——进攻阶段＝PI 与器材的函数）**：
| 墙 | 内容 | 钥匙 |
|---|---|---|
| ①环境 | 前几晚路灯火通明、人流大（她的安全路线亮街优先） | 时间＋蹲点找暗段 |
| ②同伴 | 不落单：结伴（学生）、有人接送、开车通勤 | 落单窗口情报（事实池） |
| ③跟丢 | 不知道她下一步往哪拐 | PI 路线解锁 |
| ④小区门禁 | 进得了小区 | 伪装（外卖箱／物业制服） |
| ⑤楼栋门禁 | 进得了单元 | 道具（数据开锁器／马甲） |
| ⑥户门锁 | 进得了她家 | 工具／科技门票 |
结构：**墙①②③的钥匙是时间与情报，墙④⑤⑥的钥匙是钱与器材**——PI 解锁「知道」，器材解决「做到」。前几晚不漏破绽是世界的默认状态，不是规则禁止。

**心理层**：0 级她的反抗是本能全开；高等级她的心理冲击先于身体反抗——迟疑轮（「不能相信是你」）与僵住概率随等级浮动。养的不是许可，是**她反抗意志的瓦解**——对她的每一点好都在拆她此刻的甲。

**养与杀（核心张力）**：越养得手越易，越养离暴露越近（面容记忆、谎言账本、重叠事件、追缉素材同步累积）。**硬来死于当场，久养死于暴露**，中间活路 =「她最不设防而你还没暴露」的交点，每局不同，由玩家水平决定。明线重估：搭话、节点事件、递伞全是凶器的打磨——接近度即终局的难度货币；她的邀约（「上来坐坐」）降格为顶配时机（五级机会的一种），不再是门槛。

**读时机检定**：`1d20 + 情报` vs DC15，过 = 回报模糊档位（「此刻天时地利」/「还不是时候」）。终极判断交给情报系练眼力。

**结局完整度**：任何结局出结算时展示本局完整度（档案揭开率、节点事件数、心事线深度、接近度终点）。开局硬来的罪成是一张 3% 的白卷——得到了她的人，从没得到过她；走完过程是 80%+ 全揭。同一画面，分量天差地别。

**事后链双轨（结算文案层——主人定稿：得手即终局拍拍屁股走人，事后只做结局画面的余韵，不构成得手后玩法；活的事后压力在失败侧）**：陌生硬来 = 她毫不犹豫报案，立案快、追缉猛，数日内落网（罪成但极短）；养后得手 = 她的心理混乱期——报案判定 DC 随接近度上浮（羞于启齿、不敢让人知道），社会面追问被「她不想说」拦截，开出私了 / 沉默的心事线分支（人妻的沉默悖论住在这，作文案风味）。失败侧威慑：0 级硬来被反制即她进敌对、立案、搬走——绝版赌注当场兑现，硬来的失败成本是整张卡。

**结局谱系**：罪成（暴力 / 养成两档质感）、落网、反杀（涌现：胆量 ≥9 的她在确认档反制且条件合适时打出，女警是天然载体）、放手好结局与情侣线（备忘暂缓）。**得手或败亡即本局终**，全屏结算遮罩 + 她的档案全揭（四维、事实池、心事线）——这页档案就是复玩性的发动机：下一局换出身、换身份、换一个她。

## 十四、中控架构（借仙姝堕 dispatcher）


**管辖场景（主干动作全开放，体格只是修正来源）：**

| 冲突战力 | 体格×3 计入 | 主场 |

| 设障改道 | DC14 | 挪围挡、放倒单车逼她绕行制造埋伏位；白天人流中有目击风险 |

### 敏捷（`agi`）——已定稿

**定位**：暗线主战属性，追逐战的发动机。

**动作属性归属**：尾随系（跟速 / 同街 / 身后 / 贴身 / 捡物 / 进楼）归敏捷；情报系（拍照 / 听通话 / 认路线 / 打量 / 归因）归情报。一张表两色，买点时看得明白。

**管辖场景：**

| 场景 | 判定 | 备注 |
|---|---|---|
| 冲突战力 | 敏捷×2 计入 | 速度是战力的一部分 |
| 跟速 | 每段 DC13 + 她的暗标签 | 尾行的心跳动作，[提速] 挂着时 DC15 |
| 尾随阶梯 | DC13 / 16 / 19 | 同街、身后、贴身，越近越难 |
| 躲藏 | DC12 + 情境 | 提前脱离视线，成功挂 [脱离视线] 一段 |
| 翻近道落地 | DC12 | 体格翻墙后的落地身法 |
| 开锁 | DC14，[开锁工具在手] +4（前置：开锁工具） | 手艺活归敏捷；留痕轻、失败可原地重试吃倒计时；她换锁后 DC+3——攻防对咬 |

**追逐战（距离刻度制，已定稿）：**

- **格数量程**：她在你前方 3 格开局（约三十步 = 现实的反应差），追到 **0** = 追上，拉开到 **5** = 甩脱（拐角加人流才算消失）。3/5 不对称是她的主场优势：熟地形、逃命肾上腺素；玩家的完整日程 +3、电动车 +5 专门用来填这个坑。
- **静态差快进**：开局先算速度盘（敏捷差 + 载具/情报/地形标签），静态差 ≥ +6 直接判 2 轮追上叙事带过，≤ -6 自动甩脱；只有中间态进逐轮。
- **差值带格移**（每轮双方掷 `1d20 + 敏捷 + 标签`）：

| 每轮差值 | 格移 |
|---|---|
| ≥ +5 | 追近 2 格 |
| +1 ~ +4 | 追近 1 格 |
| 0 | 僵持 |
| -1 ~ -4 | 拉开 1 格 |
| ≤ -5 | 拉开 2 格 |

- **暗体力**：她的体力 = 她的体格 ×10（暗值），跑空挂 [脱力]，玩家白捡 2 格。追逐拖久拼体格，瘦高敏的快刀要速胜，壮汉能耗死她。
- **玩家体力**：追逐每轮 -6，见底强制 [脱力]，眼看她跑远。
- **环境事件骰**：每轮 1d20，≤5 平安；6~15 小事件（路人、红灯、台阶，输方丢格）；16+ 大事件（车流、狗、她撞翻摊子，直接改格数）。均势追逐三到五轮内必被事件或体力破局。
- **复杂地形**：她敏捷 ≥7 会钻台阶窄巷，自己 +2、给玩家设障，玩家敏捷不够要绕，白丢一格。
- **节奏预算**：优势追逐 3~4 轮、均势 5~8 轮、劣势靠大事件赌翻盘。
- **终局三分支（v0.6）**：**追上（0 格）**＝接抓握——她最后一搏挣扎轮（进度制），抓稳＝偷袭压制链开局、抓脱＝再拉开 1 格垂死跑；**甩脱（5 格）**＝拐角＋人流消失——转跟丢找回线（情报 DC15）或她进店求援（反应轮后续）；**中途事件终局**＝大事件改写（车流隔开、她撞翻摊子被围、路人拦你）。心跳不加新罚——追逐时早已出甜区，变形/崩溃的既有罚在她追技术动作时自动生效。
- **公开性成本（v0.6：追逐＝撕破脸）**：当街追一个女人，无论输赢——面容记忆大幅进账（近距离＋她必回头看你）、目击者一堆、当晚她的防备顶格。**赢了对局，输了整局的隐蔽**，暗线基本报废。「追逐值得吗」是每次发动前该问的问题——「硬来死于当场」哲学的动作戏版。

**[脚步轻]（定稿）**：敏捷 ≥8 自动挂：脚步声响类判定 +2。与 [身形醒目] 不冲突——一个管她看见你（视觉），一个管她听见你（听觉），阈值标签跟现实逻辑走。
**[笨拙]（定稿）**：敏捷 ≤3 自动挂：脚步声响类判定 -2。

### 胆量（`nrv`）——已定稿

**定位**：刺激的汇率。不掷日常骰，改的是心跳账单的单价。心跳是阶段条（操作线），管「行为别太超现实」；胆量压低它的影响。

**管辖场景：**

| 场景 | 判定 | 备注 |
|---|---|---|
| 心跳系数 | `刺激值 × (1.4 - 胆量×0.08)` | 胆2=1.24 / 胆5=1.0 / 胆8=0.76 / 胆10=0.6 |
| 缓息效率 | 每段降 `10 + (胆量-5)×2` | 胆8 回 16，胆2 回 4（斜率暂定） |
| 稳住检定 | `1d20 + 胆量` vs DC12 | 凡突发惊吓，先稳住再行动 |

**稳住检定通则**：凡突发惊吓（她骤停回头 / 巡警手电扫来 / 路人迎面撞见 / 狗扑出 / 对视第一连 / 冲突下手前），先掷稳住。过 = 动作不变形，后续正常；败 = 挂 [僵直]（本段首个动作 -2，暂定）。

### 情报（`int`，原「观察」）——已定稿

**定位**：情报的产能，从事实池里捞出世界的过滤器。

**事实池预算制（铁律）**：她的世界（日程、习惯、物品、痕迹、心事）全部预写为结构化事实池，脚本持有。玩家可见度按情报值配给：我们写 10 的内容，平均情报看 6、低情报 4-、高情报 8+。LLM 不发明事实，只把配给到的内容写好看。

**素材分层（深层必连收益）**：每个事实素材写三层——表层（所有人可见）/ 中层（情报 4~7）/ 深层（情报 8+）。保底层数由情报值定，被动检定成功额外多开一层（骰子管惊喜）。
示例：她丢的饮料瓶——表层「她喝了瓶饮料」；中层「XX 牌抹茶奶绿，城东那家连锁」；深层「瓶身九点折扣标签 → 她回家路上掐点去那家店」→ 新情报条目 + 埋伏位。

**管辖场景：**

| 场景 | 判定 | 备注 |
|---|---|---|
| PI 系数 | `基础PI × (0.6 + 情报×0.06)` | 情报 1 是 0.66 倍，10 是 1.2 倍 |
| 被动情报流 | 每段自动 `1d20 + 情报` vs DC15 | 成功多开一层；情报 ≥8 一次剥两条 |
| 拍照 | DC13 | 情报系主战 |
| 贴身听通话 | 距离贴身 + 检定 | 高风险高情报 |
| 找回跟丢 | DC15 | |
| 打量 | DC12 | 读她的属性标签（三档制） |
| 归因检定 | DC12 / 15 / 18 | 信号歧义的机制化，见下 |
| 读人档案页 | 情报 ≥8 门槛 | 免检定直接开 |

**归因检定（她反常时主动掷）**：环境原因（施工、封路）DC12 / 她自己的心事 DC15 / 冲你的警觉反应 DC18（敏锐 ≥9 的她若装没事再 +3）。失败 = 继续猜。真起疑的人最难被读出。

**变现链（造优制）**：
- **粗情报**：解锁行动（没情报就没有该选项）+ 相关检定 +1；
- **精情报**：相关检定**造优**（双骰取高，走优势通道不占封顶）。
- 精化提速：粗转精的验证晚数 = 3 − 情报÷4（取整）——情报 8+ 一晚即精，4~7 两晚，低情报三晚。

**[预警]（已废弃，v0.8 清账）**：原草案「情报 ≥8 时过档信号提前一段」经主人核验从未拍板，且与「属性高给优势」的奖励制撞车——高属性奖励统一走优势五标签（双骰/甜区），不再设第二套时序奖励。信号时序类效果如将来重启，只可能以开局身份形式出现，不挂属性阈值。

**[粗心]（定稿）**：情报 ≤2：打量 DC +2，天然 20 不加彩。低情报不另设显性惩罚——税已弥散在每个过滤器里（PI 折、被动低、层数浅、精化慢、归因盲）。设计义务：低情报是**盲玩流派**（硬跟走敏捷、贴脸听走心跳、蹲守走体力），不是困难模式。

### 位置信息系统（v0.6 定稿）

- **数据模型**：她的位置 = `{区域, 场所, 状态(移动中/静止), 去向}`，与环境四维同构。真源 = 事实池日程骨架＋当日 seed 扰动（临时加班/绕路/被同事约）＋中控逐场景段解析，**全脚本持有**——位置也是一种事实，按玩家条件配给可见度（事实池预算制同款铁律），LLM 只拿过滤后的视图写正文。
- **可见度四级**：
  - **L0 未知**：陌生开局，先蹲点；
  - **L1 区域级**：活动半径粗探（区域熟悉度）——「她在城东一带」，只能蹲大区；
  - **L2 场所级**：日程已探（PI 解锁阈值）——「18 点她该在公司」，**是推断**，今天准不准要验证，掐点蹲点赌准头；
  - **L3 实时级**：正在尾随（距离档在场）或定位器常驻——真值：此刻在哪、动没动、去哪。
- **位置决定什么**：模式层开关（移动中→尾行线、在店→潜伏接触、在家→入室线或收摊）；收摊触发；机会评估与读时机的输入；蹲点精度（L1 蹲区 / L2 掐点 / L3 免蹲）；**偏航＝情报事件**——L2 日程预期对上 L3 真值，差异即信号（她绕开了常走的街＝有事发生）；无定位器的玩家只见跟丢、不见偏航。
- **输出**：状态栏「她的位置」条按级显示＋变化推事件（她动了 / 到了 / 偏航了，进信号流）。
- **两条边界**：①定位器的 L3 是**位置级不是观察级**——红点告诉你在哪家店，她在店里做什么照旧按距离档配给，细节靠肉身贴近（数据全知、肉身照走）；②**远程观猎不激活心跳**——看屏幕非猎手状态：不心跳不段税，但也不产出素材，真要什么还得出门把距离档叠上去。

**对偶**：玩家的情报对她的敏锐，同一枚硬币——你读她用情报，她察你用敏锐；打量对回头扫描，归因对识谎。

**情报四闸（v0.6 纪律：防情报无脑选）**：①**解锁≠突破**——情报告诉你「哪个小区哪栋楼」，进得去靠马甲、器材、体格，后段墙的钥匙在别的属性和钱包；②**事实池预算制**——池子总量不变，情报只决定看几层，不决定世界上有什么；③**行动层不吃情报加值**——检定 DC 对谁都一样，情报只走精化／造优通道（限预判型）；④**解锁一次性、条件每晚掷**——「知道她住哪」永远有效，「今晚她结伴吗、灯亮吗、加班吗」每晚重新生成。情报是参谋，不是外挂。

**天赋池备忘（已清算，v0.8）**：原三候选（预警 / 料敌于心＋1 / 情报复利＋0.5）全数废案——数值型种子与属性加值重叠、信息型种子无决策出口（读得到动不了等于没读）。天赋方向整体转向**开局身份制**（见第一节七身份表），主人为之。

### 口才（`cha`）——已定稿

**定位**：明线的引擎，五维里唯一的「写世界」属性——其他四维从事实池里读，口才往事实池里写，自由度最高，缰绳也最紧。

**管辖场景：**

| 场景 | 判定 | 备注 |
|---|---|---|
| 质问阶梯 | 第一轮 DC10+她的胆量，追问轮 DC+3 | 对视两连的第二连（先胆量稳住） |
| 搭话不引疑 | DC13 | 搭话三问：开场 → 她的回应（社会面+当晚心情）→ 收尾（留印象或留痕）；连续好印象喂接近度，砸了是双轨账（接近度掉、戒心进账） |
| 身份维持 | 被她朋友、店员盘问 | 她的社会面越高越常发生 |
| 伪装渗透 | 口才 ≥7 门槛 | 长期明线 |

**谎言账本（核心机制，已定稿）**：
- **入库走申报制**（平移仙姝堕数值事件申报架构）：LLM 输出附 `<谎言>claim｜对谁｜场景｜可验证度</谎言>`，中控解析入事实池。字段：`claim / to / verifiability(high职业可查·mid可对质·low无法验证) / stated_floor / times_used / status(active·busted·retired)`。校验全套同款：内容须为可见正文的逐字子串、格式错整笔丢弃＋诊断、快照同笔回退、GM 可改。玩家自己说的谎由 LLM 下轮补申报。
- **验证轮**：每数个游戏日按「她的社会面 × 活跃谎言可验证度」掷验证，命中后是大考：口才 DC = 基础 + 活跃谎言数×2 + 她的敏锐修正（≥7 再 +2）。过 = 圆过去（雷还在，可验证度升级）；败 = 穿帮事件链（戒心暴涨、接近度跳水、报警理由 +1）。
- **矛盾谎**第一版不自动检测，靠大考总账叠加；穿帮一起塌。
- **呈现**：谎言页对玩家可见（「我说过的话」），她的验证进度暗——看得见自己埋的雷，看不见她离雷多近。

**[人设入戏]**：同一伪装身份 times_used ≥3，该身份下口才 +2——演久了连自己都信。与谎言账本风险收益同源：身份越用越稳，穿帮塌得越狠。

**她的三层话防**：当场顶回去（她的胆量，质问 DC 底）→ 听出缝（她的敏锐 ≥7：谎言检定 DC+2）→ 事后查你（她的社会面，验证网络）。

**[结巴]（定稿）**：口才 ≤2：心跳 >70 时口才类再 -2。低口才 = 明线关门，活法是沉默尾行流（一个字不说纯暗线）或暴力线；要不要「走到她面前」的资格，开局买点时就定了。

## 十七、掷骰插件骨架（M4-1 脊梁已落码，2026-10-17 主人定稿四处）

**M4-1 拦截-结算-注入-放行管线（主人定稿 2026-10-17，mock 全链已绿待主人真机终验）**：①**方案 A·stop-resume 双段式**——玩家聊天框照常打字，MESSAGE_SENT 瞬间中控同步结算（打字→中控转化→**得到结果后发送放行**），结果包经 injectPrompts 注入（position:in_chat, depth:1, system；**不设 once**——swipe 重生成仍受同一回执约束），判定演出**与 LLM 生成同时进行**减少等待感；GENERATION_STARTED 看门狗兜底竞速（生成抢跑则 stopAll→注入→generate 续跑）；②**默认硬停**——结算面板定格等人点「认」，认只管面板收起不挡生成，插件设置可切「自动掷」（wx_conf.autoSettle，退回旧 generation_ended 全流程）；③**swipe 不重掷**——种子纪律（同楼同输入同结果），LLM 只重写文字；④**验证顺序**——小狐狸 mock 全链测绿后交主人真机终验（清单：发送后 AI 等不等回执／回复与回执一致／swipe 同数／开关切换）。**引擎拆相**：`settleInput`（动作相：玩家自然语言→translateInput 分句归一上限 3→全数值结算含刺激泵与段末账→结果包）＋`processReply`（回执相：只处理事实票据/谎言/模式，**零账目写入**——swipe 重跑天然安全；LLM 回复中的动作标签一律忽略防重复结算）。**回执注入文本**＝唯一数值真源（骰面/修正/DC/结果带/账目/段末/纪律头——「不要再输出动作标签」）。词表拟合生长实例：photo 补别名「拍张照／拍个照」。

- **定位**：专管掷骰的通用插件，是中控的「亲手模式」前端，也是**通用结算台**。骰子引擎、标签修正、规则、账本全在中控，插件只驱动过程、回传结果包入账，禁止自建第二本账。
- **三种形态（主人定稿）**：**单发**（一个动作一颗骰，默认也走插件手掷，后台自动掷降为可选设置）；**队列**（复合动作排队顺序结算，状态实时传递——前一动作的心跳余波当场影响后续动作判定）；**连掷**（追逐 / 冲突 / 声浪的小游戏模式，含锚点）。
- **三种驱动**：逐轮手掷（仪式感）、自动快进（一键到底，日志保留）、**锚点模式**（每 N 轮暂停注入一段过程叙事，玩家在此决策：继续 / 换策略 / 放弃；锚点间隔由玩家自选，自由度优先）。
- **队列语义**：一楼动作队列上限 3；顺序结算；种子 = 楼号 + 动作序号，重开同结果。
- **结果包**：结局 + 逐项流水 + 状态变化 + 后果钩子（如「翻倒的摊子：围观与目击风险」），注入后 LLM 只照包写戏，一个数不算。
- **种子纪律**：点击「开始」瞬间锁种子，注入即入账，重开同结果。
- **通用三模式**：追逐、冲突战、声浪对抗同款连掷结构。
- LLM 的复合输入翻译成动作队列（不再拆楼）。
- **打工结算皮肤（v0.6）**：点钞机式进账动画（现金计数滚动+加成档小字+暴击金闪），与判定演出的跳字悬念式刻意区分——白天不紧张，白天是挣钱。

## 十八、阶段结构（流程图纸，暂定）

**两层工作结构**：日程层（时间轴，管「现在能做什么」）× 模式层（在场方式，管「你以什么身份存在于她的世界」）。两层交叉，白昼局、凌晨局、夜路局全装得下，无需特判。

**日程层一天三段 + 过夜：**

| 阶段 | 时钟 | 玩法 | 心跳 |
|---|---|---|---|
| 准备 | 白天/开窗前 | 3 行动点（打工 / 购物 / 蹲点 / 休息）；**刷脸编舞主场**；情报日间积累 | 不激活 |
| 行动窗口 | 她的活跃时段（**她的日程开窗**） | 尾行、潜伏、接触、机会评估 | 按模式 |
| 收摊 | 她到家 / 放弃 / 过窗 | 过夜结算：警觉衰减、戒心沉淀、PI 入库、体力恢复、日期 +1；收摊遮罩 | 清零 |

开窗由她的日程决定（OL 18 点、夜店 22 点、人妻 09 点、女警随值班表）——蹲点就是在预习开窗时间，情报越足日程越透明。

**模式层三态：**

| 模式 | 进入 | 运转系统 | 退出 |
|---|---|---|---|
| 潜行 | 隐匿动作申报 | 距离档、尾随检定、警觉、心跳（激活）、体力、追逐、被动情报 | 她到家 / 跟丢 / 被察觉（强制进她的反应轮）/ 主动切换 |
| 接触 | 现身互动申报 | 搭话三问、话题、谎言账本、疑虑、接近度；心跳风险制 | 互动结束回潜行或离场 |
| 终局 | 下手申报（**任何时刻可入**） | 机会等级、冲突检定、反应轮、声浪介入链 | 结算 |

## 十九、目标角色库（首版骨架）

模板权衡两维（主人定稿，收场不参与）：**得手难度 × 窗口结构**——好按的窗口少，窗口好的按不动。

**胆量的信号感知（做减法：无主动试探动作，环境自然涌现）**：
- **主动试探已砍除（主人定稿）**：原设计「玩家主动弄出动静试探」违背犯罪心理与猎手隐蔽本能，造成性价比倒挂与终局悬念削弱，系统做减法予以清除。词表不设主动探测器。
- **信号流与偶发事件涌现**：她的胆量完全通过路上自然发生的突发事件（野猫翻垃圾桶、巷口急刹车、楼道灯灭、迎面醉汉）流露于信号流事实：
  - 胆小（≤3）：猛一缩肩、抱包快步小跑、惊弓避让；
  - 常人（4~5）：停步皱眉、观望后绕开；
  - 胆大（6~8）：低声斥骂、踢开阻碍、眼神直视。
- **未知张力保留至终局**：玩家仅能凭借信号流片段主观评估，系统绝不给现成数值结论，将最核心的生死与反抗悬念彻底保留至下手那一刻。

### 她的敏锐——感官雷达与身份识别（竖磨定稿）

**档位与管辖范围**：
- **基准秤**：普通人 3~4（学生/常人）；细心职场人 5~6（OL、护士、记者）；专业警觉 7~8（夜店小姐经验眼、刑警）；顶级感知 9~10。
- **管辖四大管道**：
  1. **警觉进账倍率**：`0.8 + 敏锐 × 0.04`（敏锐 4 ＝ 0.96，敏锐 8 ＝ 1.12）；
  2. **日常失窃与隐蔽装置发现**：翻找失窃周检定（`1d20 + 敏锐 vs DC14 + 复利`）、针孔摄像头每周巡检；
  3. **照面打量**：对视与照面时对玩家外貌、动作破绽的洞察；
  4. **身份识别（原认脸）**：核心三件套之③，将身形步态与生活印象对号。

**身份识别判定（公式制，方案 A 平滑缓释乘算）**：

$$\text{识别值} = \left\lfloor (1\mathrm{d}20 + \text{她的敏锐} + \text{体态醒目修正}) \times \min(1.0, \text{记忆} \times 0.05) \right\rfloor \text{ vs } 10 + \text{遮挡（封顶+5）}$$

- **核心铁律（记忆是识别的前提）**：
  若在非尾行生活场景中从未产生交集（记忆 $= 0$ 格），则乘算系数恒为 $0$，识别值 $= 0$。哪怕天然 20 掷面配顶尖敏锐，也无法凭空把眼前身形与玩家对上号。
- **参数规格**：
  - 记忆转化率：$0.05$（每 1 格记忆折算 $5\%$ 识别效率，满 20 格达到 $1.0$ 全额识别）；
  - 遮挡封顶：夜色、口罩、帽檐等面容遮挡合计上限 $+5$（基准 $\text{DC} = 10 \sim 15$）。
- **概率分布验算（常人敏锐 4、体态修正 0 vs 基准 DC 12）**：

| 记忆格数 | 识别系数 $k$ | 最高可能判决值 | 识别成功率（约） | 表现与体验 |
|---|---|---|---|---|
| **0 格** | $0$ | $0$ | **0%** | 完全不认得，只能觉得有路人走过 |
| **4 格** | $0.20$ | $4$ | **0%** | 仅一面之缘，脑海仅有模糊残影，对不上号 |
| **8 格** | $0.40$ | $9$ | **0%** | 见过两次，若无刻意遮挡仍难联想到具体人 |
| **12 格** | $0.60$ | $14$ | **15%** | 开始出现眼熟感，偶尔闪过怀疑的念头 |
| **16 格** | $0.80$ | $19$ | **40%** | 熟客/频繁接触，容易根据体态对号 |
| **20 格** | $1.0$ | $24$ | **65%** | 深度熟悉，身形步态无处遁形 |

- **体态醒目与身形伪装修正（`bodyMod`）**：
  - **醒目项**：体格过高/壮硕魁梧（体格 $\ge 8$）$+2$；携带显眼大件（大登山包、反光外挂）$+1$；
  - **伪装项**：穿着宽松风衣/大号雨衣（破坏身形轮廓）$-2$；刻意变换步态（`gait` 词条，如改变步幅重心，需过敏捷检定）$-2$。

**生活包状态动态修正**：
1. **OL 周末节律**：
   - 工作日晚（周一至周五）：高强度加班后注意力枯竭，精力聚焦于手机与通勤（敏锐保持常态 6，但防备不产生额外溢出）；
   - 周末（周六至周日）：白天休息充足，感官敏锐度完全释放，打量与识别更难蒙混；但在夜间聚会或娱乐场所，心防容易受社交气氛软化。
2. **夜店小姐醉态修正**：
   - 处于饮酒醉态时，敏锐下挫至 **$2 \sim 3$ 迟钝档**，感官迟钝、警觉大幅降低，打量与识别能力甚至弱于普通人；但在非醉酒的白昼与清醒时段，凭借阅人经验恢复 $7$ 点专业敏锐。

### 她的社会面——人际密集度与被关注度（1~5★，竖磨暂定）

**核心定位（物理安保彻底解绑）**：
- **物理安保归场所卡**（老破小、城中村、普通单元、高档公寓由住处生成，不与社会面死绑；夜店小姐可住旧小区，穷学生可住严管宿舍）；
- **社会面（★）纯管人脉密集度**：代表她周围活人人际网络的紧密程度与被关注程度。

**五档标尺**：
- **1★ 边缘孤岛**：外地独居、人际疏离。无亲友同住、少社交。失联数日无人问津；
- **2★ 普通社群**：学生、初级职场人。有舍友/同事，作息规律，夜晚偶有同行；
- **3★ 复杂江湖**：夜店小姐、资深公关。熟客、领班、姐妹、三教九流熟脸，人际触角广；
- **4★ 紧密契约**：人妻、家族同住者。配偶/同住家人、密集查岗、固定报备，身边常有视线覆盖；
- **5★ 体制联防**：女警、司法公职。周围全员治安同行，具备极高的互保敏锐度。

**管辖双管道（做减法，零冗余时钟）**：

1. **同行/结伴发生率（动手封印 × 尾行红利）**：

   - *双刃剑机制*：

2. **周日统一结算 · 谎账人际交叉核验（温和暗雷）**：
   - 仅在**周日统一结算**对活跃在账的未结谎言（Mid/High 类，Low 生活闲聊不挂雷）进行一次低频核查；
   - **触发判定**：$\text{核查触发率} = \text{社会面★} \times 4\% + (\text{High 类 } +5\%)$；

### 目标角色统一行为模板（Universal Behavior Template）

**设计总纲**：
- **不为特定角色 hardcode 专属分支，全部由统一模板生成**；
- **底层行为概率由属性数值通过严格公式推导计算，表层具体表现由四风味插槽（Flavor Slots）额外填写**。

**四大通用防御本能（警觉过档 20/40/60 时触发）**：
1. **【核实·直面】**（Face / Scan）：触发回头扫描对视对抗，直面威胁；
2. **【避险·脱离】**（Evade / Speed）：加快步伐小跑拉开距离，使玩家下轮跟速 DC $+2$；
3. **【借势·掩护】**（Shield / Cover）：佯装进店、看橱窗、借物遮挡，转入室内或逼玩家选择蹲守；
4. **【联络·求援】**（Signal / Call）：拿出手机通话、向熟人/门岗挥手搭话，引入身边人或挂求援倒计时。

**通用权重生成公式**：

$$\begin{cases}
W_{\text{核实}} = \text{胆量} \times 2 \\
W_{\text{脱离}} = \text{敏捷} + \max(1, 10 - \text{胆量}) \times 1.5 \\
W_{\text{掩护}} = \text{敏锐} \times 2 \\
W_{\text{联络}} = \text{社会面★} \times 3
\end{cases}$$

- **掷骰判定**：将四项权重归一后映射到 1d20 区间，投掷决定当段反应；
- **极端数值验算（敏2 胆5 锐4 设5★）**：
  - 核实 $10$（$23.5\%$）｜ 脱离 $9.5$（$22.4\%$）｜ 掩护 $8$（$18.8\%$）｜ 联络 $15$（**$35.3\%$ 跃居第一大项**，完美契合跑不动但依仗人脉的心理）。

**额外填写：四风味插槽（Flavor Slots）规范**：
具体角色仅填写表现文本覆盖，用于驱动 LLM 申报的事实描述：
- `flavor_face`：核实具体动作（如“借撩发斜睨”、“直接驻足冷眼回望”）；
- `flavor_evade`：脱离具体动作（如“抱紧包小跑”、“踩着高跟鞋急促快走”）；
- `flavor_shield`：掩护具体动作（如“拐进街角便利店”、“停在橱窗前假装看项链”）；
- `flavor_signal`：联络具体动作（如“免提大声喊老公”、“快步走向小区岗亭跟保安打招呼”）。

### 终局心理层——僵住与迟疑轮（竖磨定稿）

**双轨心理模型**：
- **僵住（Freeze）＝ 生理恐惧超载**：突发近距离偷袭或高机会等级（5级）突施按制时，大脑应激瘫痪；由**胆量**驱动抗性；
- **迟疑（Hesitation）＝ 认知信任崩塌**：熟人动手瞬间的认知混乱（“怎么会是你？！”）；由**接近度**驱动轮数。

#### 1. 僵住（Freeze）机制
- **触发门槛**：突发近距离偷袭（背身/暗处扑倒）或机会等级 5 级（熟睡/醉倒/完全不备）。若目标警觉 $\ge 60$ 已进入应激戒备，不触发；
- **检定公式**：
  $$\text{心理抗性} = 1\mathrm{d}20 + \text{她的胆量} \pm \text{阈值标签 vs DC 13}$$
  - 胆小（胆量 $\le 3$）：自动挂载 **$[$胆小 $-3]$** 标签（$60\%$ 概率僵住）；
  - 常人（胆量 4~5）：无标签修正（$40\%$ 概率僵住）；
  - 胆大（胆量 6~8）：自动挂载 **$[$胆大 $+3]$** 标签（$15\%$ 概率僵住）；
  - 顶尖（胆量 $\ge 9$，女警）：自带 $+5$ 训练修正（仅出天然 1 时僵死，撑住率 $95\%$）；
- **机械效果**：
  - 首轮反抗完全瘫痪：当轮挣扎对抗跳过，反抗战力视同 0；
  - 声浪封死：首轮无法尖叫呼救（声浪检定判定为 0）；
  - 玩家首轮按制自动建立，挂上初级压制优势。第二轮起恢复正常挣扎。

#### 2. 迟疑轮（Hesitation Rounds）机制
- **触发门槛**：认出玩家身份的瞬间（面容或声音对上号）触发；
- **轮数公式**：
  $$\text{迟疑轮数} = \begin{cases}
  0 \text{ 轮} & \text{接近度 } < 40 \text{（陌生 / 仅点头眼熟）} \\
  1 \text{ 轮} & \text{接近度 } 40 \sim 69 \text{（熟人 / 朋友 / 产生好感）} \\
  2 \text{ 轮} & \text{接近度 } \ge 70 \text{（信任 / 依赖 / 暧昧亲密）}
  \end{cases}$$
- **机械效果**：
  - **第 1 轮**：错愕质问，冲突战力惩罚 $-10$ 点，无法反击，首拍喊不出呼救；
  - **第 2 轮（仅接近度 $\ge 70$）**：心理防线半解体，战力惩罚 $-5$ 点；
- **对赌代价（双刃剑铁律）**：
  触发迟疑轮的同时，**面容记忆当场打满（100% 身份对号）**。若未能压制成功导致脱手逃跑，玩家现实身份当场彻底暴露，暗线彻底报废。

### 长线防备进退闭环（进退平衡机制，主人定稿）

防备是压制玩家长线操作的紧箍咒，若只升不降或增幅过大，游戏极易进入死局。必须严格恪守**现实心理学与进退平衡**：

#### 1. 谎言穿帮降格（社交信任流失 vs 防备温和）
- **现实逻辑（主人定稿）**：熟人吹牛或谎言穿帮，正常人的反应是“这人不老实/爱显摆/嘴碎”，绝不会直接得出“他是变态跟踪狂”的结论；
- **惩罚结构倒置**：
  - **社交惩罚为主**：接近度大额扣除 $-10 \sim -15$ 点，好感与信任退行；
  - **暗账防备温和**：防备仅微幅增加 $+3 \sim +5$ 点，不直接触发换锁搬家等硬核防御。

#### 2. 防备自然消减两大管道（养与杀的真髓）
白天对她做好事**绝不能直接抵消夜晚惊吓**（逻辑硬伤）；消除防备必须遵循客观归因：

- **管道 ① · 时间自然淡忘（平稳流）**：
  - 若连续数日处于**平静夜**（当夜最高警觉峰值 $\le 20$），都市白领与学生注意力被日常学业工作稀释；
  - **过夜结算衰减**：长线防备每日自动回落 **$-1$ 点**。
- **管道 ② · 熟人误导归因（话术消解流 · `misdirection`）**：
  - **前置门槛**：接近度 $\ge 20$（已跨入点头之交/熟人档，建立基础对话权）；
  - **行为申报**：在白天或接触模式申报 `[误导归因]`（词条：`misdirection`），借由闲聊将昨晚的异常动静（脚步、声响、猫叫、路灯闪烁）归因为自然或环境客观原因（“昨晚那条街野猫真多”、“老路灯线路老旧总跳闸”）；
  - **检定公式**：
    $$1\mathrm{d}20 + \text{玩家口才} \text{ vs DC } (12 + \text{她的敏锐} \div 2)$$
  - **效果判定**：
    - **大成功 / 成功**：成功重构其认知记忆，当场消解暗账防备 **$-5 \sim -10$ 点**；
    - **失败**：她半信半疑，防备不增不减；
    - **大失败**：圆场过于突兀，产生“你怎么知道昨晚有动静”的疑窦，防备额外 $+3$ 点。

### 街区网络动线模型（耐玩度与多轮拉扯）
- **单节点多轮博弈**：1 节点 $\ne$ 走 1 步换地，每个场所包含 2~4 轮深层博弈（如便利店停留买夜宵/排队/搭话，暗巷拉扯距离档/屏息/听脚步），单晚行动窗口通常由 8~12 轮（楼）构成；
- **三平行通路动态换线**：
  - **主干大道线**（安全/保守）：路灯明亮、行人零星，不易下手但防备平稳；
  - **市井老巷线**（常规/均衡）：天桥、便利店、里弄，有接触点亦有盲区；
  - **断头近道/小径**（高危/捷径）：施工泥泞路、无光死角，易跟丢但动手条件极佳；
  - **每日扰动换线**：依天气（下雨走大路）、当日心情与疲惫度（赶时间抄近道）动态切换，情报掌握度决定是否跟丢或能提前设伏。

## 二十七、角色生活包与事实池（Fact Pool Schema，v0.7）

### 定位：通用模板的实例化容器

二十六节铁律：四大区是通用功能模板，具体门牌一律由角色生活包实例化。生活包就是往模板里填「她」的那只笔——五维、风味插槽、动线（挂 `places.json` 节点 id）、事实池（具体门牌与生活细节）装配在一个 JSON 容器里成卡。本节定规格与配给协议（P2），首个实例（高中生 or OL）随 P3 填充。

### 容器四件套（`src/config/lifepack.json` 结构）

1. **meta**：模板 id、五维（`str/agi/per/nrv/social`，键名与引擎一致）、开局警觉修正、**日程稳定度 stability**、常驻特质标签 traits（须在词表 tags 注册）；
2. **flavor 四插槽**：`flavor_face/evade/shield/signal`（二十五节规格，纯文本覆盖，不写数值）；
3. **routes 动线模板**：每条挂 places.json 节点 id 序列＋时刻——这就是 L2 可见的「日程骨架」；
4. **factPool 事实池＋conditions 每晚条件族**（下文）。

### 五大槽位

| 槽位 id | 管什么 | 事实举例 |
|---|---|---|
| `home` 住处环境 | 哪个区哪栋、门禁、信箱、窗向 | 「老城B区老旧单元楼，五层无电梯，铁门朝北」 |
| `schedule` 作息动线 | 上下班时刻、常去店、周常 | 「工作日朝九晚七，周五常加班到九点」 |
| `carry` 随身物品 | 包、鞋、防身物、钥匙 | 「黑色托特包，细高跟」「包里挂着防狼喷雾」 |
| `social` 人际同行 | 常伴、人脉网、求助点 | 「和同事小梅每周三同行一段」 |
| `psyche` 心理防线 | 恐惧点、死角、习惯性防线 | 「怕黑，楼道声控灯坏了宁可磨蹭等人」 |

### 事实条目统一字段

`id`（唯一，角色前缀+槽位）｜`slot`｜`level`（1 区域 / 2 场所 / 3 深层）｜`public`（公开事实免解锁）｜`title`（玩家侧情报名，说人话）｜`text`（LLM 可用正文）｜`place`（可选，挂 places 节点 id）｜`reveal_via`（L3 动作票，引用词表动作 id）。

静态事实**一次性解锁，永久可见**（四闸④「知道她住哪永远有效」）；「今晚她结伴吗、灯亮吗」不进池，走每晚条件族。

### L0~L3 四级情报配给协议

四级复用十六节位置系统语义：**L0 未知**（视图空白，盲蹲）→ **L1 区域级**（活动半径，她在哪一片）→ **L2 场所级**（具体节点＋日程骨架，**是推断**，今晚准不准要验证）→ **L3 深层级**（门牌、包里有什么、心理死角——里子）。

**解锁管道三分（每槽位每层一道门）**：

| 槽位 | L1 | L2 | L3 |
|---|---|---|---|
| `home` | PI 7 | PI 15（住处小区） | PI 60＋动作票（`locate`/`check_mailbox`/`ransack`…） |
| `schedule` | PI 5 | PI 10（工作地）/ 8（常去店） | PI 40（完整日程） |
| `carry` | —（`public` 外观免解锁） | 观察票＋PI 8 | 翻找/捡物/入室票（**无 PI 门**） |
| `social` | PI 4 | `watch_peers` 票＋PI 8 | PI 60＋套话票 |
| `psyche` | —（无此层） | —（无此层） | PI 60＋交互票（`chat`/`listen`/`misdirection`） |

**推导与理由（阈值全部锚定八节，无新造数）**：
- **L2 阈值＝八节既有锚**（常去店 8 / 工作地 10 / 住处小区 15），原样不动；
- **L1 阈值 = floor(L2 阈值 ÷ 2)**——信息量折半：L1 只区分四大区（约 2 bit），L2 区分 22+ 场所节点（约 4~5 bit），门槛按半档递进，得出 7 / 5 / 4；
- **L3 双门制＝PI 深层阈值（40 / 60，八节锚）且对应动作成功票**——四闸①「解锁≠突破」的同型纪律：堆情报只知道「有」，摸到「是什么」必须肉身做过事；
- **carry 走票据管道**：捡到随身物本身就是 +5 PI 的产出，若再设 PI 门槛就倒挂了（先攒够情报才配知道自己捡到了什么，不通）；`public` 外观（包、伞、鞋跟声）进场即见；
- **psyche 无 L1/L2 是设计特性**：心理没有「区域级」中间态，要么陌生，要么摸到深处。

**预算制落地（四闸②原文的运行时化）**：事实池开局全量生成（她的一切在开局就定死），`view()` 按解锁态过滤，LLM 只拿过滤后的视图写正文——情报只决定看几层，不决定世界上有什么。

### 每晚条件族（动态层，不占池）

静态事实之外，一族「今晚状态」每晚由 seed 重掷：加班 / 结伴 / 绕路 / 灯亮 / 在家。

- **偏航公式：P(当晚日程扰动) = 1 − stability**（stability＝日程稳定度，meta 字段）；
- **基准锚**：常人 stability 0.8（即 20%/晚 ≈ 一周 1.4 次偏航）；六人定档 P3 随十九节定性填充（高中生「日程极固定」趋高、女警「四班三倒」趋低），届时给推导；
- 单条件可用 `mod` 系数覆盖基准（如 OL 周五酒局），mod 值同样 P3 附推导；
- 与偏航机制咬合：L2 骨架（推断）对上当晚真值，差异即情报事件——她绕开了常走的街＝有事发生（十六节「偏航＝情报信号」落地）。

### [疲惫] 标签补注册（黑户清账）

十九节 OL 与二十五节敏锐竖磨均引用 [疲惫]（敏锐暗修正 −2），但词表与规则表此前未注册。本版补齐：owner＝target，生效管道＝调用侧传 `acuity` 时按标签栈扣减（`checks.js` 的 `acuity` 参数挂点已存在，不新增通道）。[醉态]（夜店小姐双态）同型，灌夜店小姐时一并注册。

### OL 全量实例化（P3 已灌入 `lifepack.json`，跑通闭环）

首个示范角色选 OL（疲惫猎），21 条事实／4 条动线／4 条每晚条件，交叉校验零悬空。定稿数值与推导：

- **stability = 0.7**（30%/晚扰动）：常人锚 0.8（20%），十九节定性 OL「加班晚归常态」→ 扰动高于常人，取 30% ≈ 一周约两天偏航，兼顾「疲惫但作息总体规律」；
- **friday_wine mod = 2**（60%/晚）：十九节把周五定位为结构性机会窗口（酒局＋加班双高发），取常态扰动率的 2 倍；与加班 30% 联合覆盖 $1-0.4\times0.7=72\%$，周五夜「有事」近三成之二，够格叫机会窗口；
- **动线四条**：反向通勤／加班晚归／周五酒局（散场点 river_walk_c，回程打车不进骨架）／周日遛弯；
- **闭环节奏实测**（测试锚）：一晚专注蹲点（PI 10）即开作息与社会 L2（阈值 10/8，好摸），住处 L2 需两晚（15，难摸）——「作息好摸、住处难摸」的定性由阈值表自然涌现，无需额外机制；
- **入室线钥匙**：备用钥匙磁吸盒（`ol_carry_key`，ransack/door_peep/try_handle 票可探）——深层情报与后段墙（进得去靠马甲、器材、体格）的衔接件。

## 二十八、目标动态态势与具象行为系统规范模板（Target State Schema，v0.8 通用规范模板）

### 定位与核心铁律

目标动态态势（Target State）是连接静态角色属性/事实池与动态文学白描/即时检定的中控核心系统。
1. **中控确定性调度（单一真源）**：所有着装、身心、双手行为与破绽全由中控基于确定性种子伪随机流（PRNG）独立运算，大模型不读取百分比，只接收经过计算生成的客观白描指令与真源数值。
2. **术语中立通用化（去特定角色词）**：本架构面向全量目标（OL、高中生、女大学生、夜店小姐、独居人妻、便衣女警及自设角色）统一定制，所有字段规格、抽样分布、破绽机制均采用中立通用的工程标准。
3. **效果只认标签栈**：一切行为带来的玩家跟缀隐蔽增益或对抗修正，必须映射为后台合法注册的真实标签（如 `hand_fumble`、`hand_phone`、`somatic_fatigued` 等），严禁口头自然语言空口生效。
4. **鞋具真源对齐契约**：所有着装绑定的鞋具，必须 1:1 对齐 `rules.json` 中的已注册鞋具池（`rules.targets.generator.shoePool`），并映射前端原生 Web Audio 脚步声码（`leather`, `sneakers`, `platform`, `flats`, `heel`, `boots`），严禁凭空造鞋。

### 四、中控确定性防漂移与生命周期保障

1. **无损属性基底（`targetBase`）**：
   目标的五维（`str/agi/per/nrv/social`）在创角或加载时完整固化至 `g.targetBase`。当晚的身心扰动（如疲惫 `agi: -1`、轻松 `per: -1`、紧绷 `agi: +1`）直接在基底上重算并覆盖当前属性，确保多次过夜或读档结算时数值不发生累积漂移。
2. **动线节点移动感知（时刻表推进 / `herAdvance` / `setRoute`）**：
   - **推进口径（主人定稿 2026-10-19）**：一楼 = 15 分钟，第 1 楼对应 `route.startTime`；越过某节点的发车时刻（`route.times[i]`，来自生活包 `path[].t`）即推进到该站。每楼结算前由 `advanceRouteByClock()` 统一推进，一次跨多站只记一条「目标动向推进」信号。
   - 没有 `times` 的旧动线（老存档 / GM 手搓）**不自动推进**；老存档加载时按同名动线把 `times` 补回（只补不覆盖）。
   - 抵达终点后 `tailing=false`（侦探职业病解锁），与「跟丢」口径一致。
   - 目标推进一步到达新节点时，首先检测当前场所是否存在于 `siteOverrides` 中：
   - 若匹配且 `fumbling: true`，立即挂载 `hand_fumble` 标签（玩家跟缀隐蔽 +3）；
   - 离开该场所或切换为平路状态时，中控自动摘除 `hand_fumble` 标签，恢复平路姿态。
3. **跨夜结算（`nightFall`）**：
   过夜推进至次日时，中控自动检测次日是否为周末（`isWeekend(date)`）：
   - 平日恢复固定 `defaultOutfit`，周末重新掷骰抽取 `weekendOutfitPool`；
   - 同步摘除旧鞋具标签并挂载新鞋具标签，更新脚步声码；
   - 重新抽取次日的主身心状态与具象生活背景理由。
4. **动作条件门槛（`lexicon.requires`，2026-10-19 主人定）**：
   - 词条可声明 `requires.dist`（允许的距离档）／`requires.items`（随身工具，任一即可）／`requires.place`（`door` 门前·楼道·玄关）。
   - `settleAction` 在模式门槛之后、掷骰之前校验：不满足直接 `rejected`，返回人话原因，不掷骰、不进账，回执写「未执行（原因）」——打字申报与胶囊走同一条门。
   - 当前口径：开锁＝门前 + 持有 `lockpick`/`cyber_lockpick` + 人到身后/贴身；撬门、试门把、贴门听、门缝观察、查门禁＝门前 + 身后/贴身；翻找、翻墙＝身后/贴身（在街上十几米外够不着）；下手＝身后或贴身（偷袭另在 UI 收紧到贴身）。
   - **距离与场所是两把独立的锁**：门在，但人在同街（15–20 米）也做不成；两条都过才允许掷骰。UI 侧顺序为「先判有无门（无门整条不出现）→ 再判够不够近（够不着灰条）→ 最后判工具」。
   - **距离边界（2026-10-19 补）**：距离类动作不得越过物理极限——已贴身时「逼近/贴身逼近」灰显（不掷、不结算）；已在远端时「拉开/退回」灰显；目标距离等于当前档的也灰显（白点一次不产生位移）。引擎侧 `approach` 只能把距离改近、`withdraw` 成功后才置远端（此前 withdraw 掷了骰却不动距离，是漏接，已修）。
   - **贴身连带规则**：贴身时「躲藏」不成立（无处可避）；「按制 / 转移」只在贴身成立；心跳 ≤20 时「缓息」无效（下限即 20，不再掉）。
   - **语义边界也归中控**：偷袭（`strike` + `style=ambush`）必须贴身，身后只允许强攻（同一条目按 args 分档）；缓息在 `heart ≤ 20` 时直接拒绝。UI 灰条只是同一套规则的展示层——玩家手打「开锁 / 撬门 / 偷袭 / 缓息」同样被 `settleAction` 挡下，并在回执里写「未执行（原因）」，模型不得写成成功。
5. **输入与动作彻底解耦（2026-10-19 主人定「手打绝对无效」）**：
   - 动作只来自**胶囊点选**；输入框文本**永不**被归一成动作（`settleInput` 的 `allowTextFallback` 仅 GM / 工具 / 单测可用），正文里的 `<动作>` 标签在玩家输入相一律忽略。
   - **默认姿态**：未点选胶囊时以「跟缀 · **保持当前距离**」结算——这是 UI 侧的姿态选择（徽记可点，可切「纯叙事」），不是解析文本；「跟缀」本身不改变距离，只维持当前档继续跟踪。
   - 胶囊门槛里「跟缀」不参与距离变更判定（它不换档），只有「逼近 / 拉开」这类换档动作才受距离边界约束。
   - 未选胶囊且姿态为纯叙事时，回执明确写「本轮玩家未点选任何动作胶囊：纯叙事推进」，不计任何检定与账目。
6. **她的警觉可见性（2026-10-19 补，仍守明暗分离）**：
   - 快照**只给档位** `target.alertStage`（0~4），**不给原始数值**——`tests/game.test.js` 的「明暗分离」用例守着这条契约。
   - 战术终端「环境 · 战术沙盘」与**心跳弹层右栏**共用同一档位函数 `alertTierOf()`：五格刻度 + 档位名，按 `alertStage` 分桶——
     `0–20 毫无察觉 / 21–40 不安 / 41–60 起疑 / 61–80 确认 / 81+ 反应`。
   - **五格配色（主人定，2 绿 1 黄 1 橘 1 红）**：第 1–2 格青绿、第 3 格黄、第 4 格橘、第 5 格红；从下往上点亮＝警觉在涨。弹层内竖排，终端沙盘内横排，同一套颜色。
   - 心跳盘下方的「甜区 40–65 · 变形 70 · 崩溃 90」文字行**已删除**，三个阈值只保留在仪表盘的悬停提示里（手机无 hover 时暂无入口，待补点击说明）。
   - 悬停给档位区间说明，不给精确数字；每楼的「警觉变动 +N」仍在结算面板里（现有账目口径不变）。
   - 若以后决定直显精确数值，属于宪章级改动：要同时改快照契约与那条测试，不能只动界面。
   - UI 侧同一张表：场景不相干的动作整条不渲染（街上无门就不给开锁）；场景相干但条件不足的渲染为灰条并写明缺什么（胶囊门槛不替代引擎判定，只防误点）。
