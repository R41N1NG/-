# 《都市悬疑与心理潜行设计纲领》 (尾行题材设计.md)

> ⚡ **媒介自觉与核心强项**：本项目为现代都市心理潜行角色卡。视觉体验（HUD/UI）是外壳框架，听觉（合成音效）仅为环境氛围底噪，**自由而深刻的文字演绎才是全卡的立足之本与真正强项**。
> 本文件确立动线舞台与生活包事实池在文字层面的创作法则，与 [《写作指导.md》](写作指导.md) 并行生效。

---

## 一、动线设计：三段式心理与感官剥离链

在文本演绎中，动线推进绝非机械的“空间坐标位移”，而是**一步步剥离她的社会防御面具，由喧嚣公共区层层逼近私密禁区的心理剥离链**。每一个场所节点，都是为 LLM 提供的特定感官白描舞台。

```
动线文本推进链（由明入暗，心理剥落）：
┌────────────────────────────────────────────────────────┐
│ 第一阶段 · 喧嚣与面具（CBD / 车站 / 校门口）           │
│ 文本着力点：公共目光的掩护、她端正的社会面具、繁杂的都市底噪  │
├────────────────────────────────────────────────────────┤
│ 第二阶段 · 疲惫与破绽（便利店 / 过街天桥 / 避雨屋檐）    │
│ 文本着力点：面具松动、身体受迫（揉脚腕/呼白气）、独处微动作 │
├────────────────────────────────────────────────────────┤
│ 第三阶段 · 逼仄与失序（无灯老弄堂 / 单元楼道 / 家门玄关）  │
│ 文本着力点：二人世界、呼吸声、脚步回音、空气冷热、封闭压迫 │
└────────────────────────────────────────────────────────┘
```

### 1. 前段 · 喧嚣与面具（公共掩护区）
* **场景氛围**：地铁闸机、晚高峰人流、明亮的写字楼大堂、学校正门。
* **叙事作用**：确立她的社会身份与外在体面。
* **文字着力点**：
  - 描写她在人群中的穿行姿态：挺拔的制服、利落的步频、迎合社会的冷淡或礼貌假笑；
  - 玩家处于公众视线隐蔽中，**动手封印**；此阶段着重白描“在众目睽睽下悄然锁定猎物”的视线压迫，观察她的衣着、佩饰与随身包具。

### 2. 中段 · 疲惫与破绽（半公开过渡区）
* **场景氛围**：24小时便利店、雨夜过街天桥、街角自动贩卖机、昏暗的避雨屋檐。
* **叙事作用**：脱离了公共群体的注视，社会面具出现第一道裂痕，身心受迫显现。
* **文字着力点**：
  - 描写独处时的微动作：长吁一口气卸下防备、借橱窗反光抚平刘海或揉酸痛的脚踝、翻找背包时零碎物品的掉落、在冷柜前挑选廉价单人速食时的茫然；
  - 此时人流散去，她的戒备直觉开始萌动（怀疑背后有人，却因缺乏证据而疑虑重重，陷入“是我太敏感还是真有人”的心理内耗）。

### 3. 后段 · 逼仄与失序（封闭私密区）
* **场景氛围**：年久失修的老弄堂、死胡同、声控灯损坏的单元楼道、家门口生锈的防盗铁门前。
* **叙事作用**：外界干扰完全归零，进入纯粹的二人心理对峙与空间封死。
* **文字着力点**：
  - 放大环境与生理的微小细节：水管漏水的滴答声、脚步敲击水泥台阶的回音、两人粗重交错的呼吸声、钥匙对不准锁孔的金属碰击声；
  - 空间被压缩至极限，六道墙（知识、距离、身心、转移、结算、教育）依次显形，心理张力拉至顶点。

## 二、生活包与事实池（Fact Pool）：文字演绎的三大燃料

事实池中的静态条目（`factPool`）不能是档案表格，必须是能够直接激发出高信息密度文学描摹的**生活物证与心智破绽**：

### 1. 身体受迫的具象微动作（Sensory Anchor）
拒绝“她很累”、“她很害怕”这类抽象概括，必须提供具象的生理直观：
* **肉体的疲劳印记**：细高跟鞋磨破脚跟渗出的血丝、重提包在小臂上勒出的红印、被雨水打湿紧贴皮肤的发丝与衣料、饥饿或寒冷导致的轻微颤栗。
* **戒备的应激体态**：听见背后响动时脖颈绒毛的耸立、手指无意识地紧扣包带、假装看手机却连续按错锁屏键、加快脚步又不敢真正狂奔的拘谨与惊惶。

### 2. 私密物证的生活真实感（Material Evidence）
随身携带物（`carry`）与住处环境（`home`），必须带有都市边缘生活的粗粝质感：
* **不完美的物证**：压皱的单人外卖小票、用旧磨损的钥匙扣、备用防狼喷雾边缘未撕干净的标签、为了省电常年不换的昏暗灯泡、薄板隔断墙传来的隔壁水流声。
* **反差的私密窥探**：白天衣冠楚楚的白领，包里塞着降压药与临期面包；夜场里看似八面玲珑的酒保，玄关处放着治胃病的冲剂。物证是撬开她心理防线的最快钥匙。

### 3. 誓死捍卫之物与心理认知差（The Core Dilemma）
遵循《写作指导.md》法则，角色的痛苦与挣扎之所以动人，是因为她有**拼命想保全的底线**：
* **名誉与体面之争（如人妻、刑警）**：恐惧被邻里、同僚或丈夫察觉异样，为了掩盖私密被侵入的事实，本能地压抑声浪，在封闭空间内忍受盘问与退让。
* **生计与安全之争（如学生、OL、夜店小姐）**：在弱势生存境遇下，既恐惧未知伤害，又恐惧失去眼前的学业、工作或微薄积蓄。面对步步紧逼的猎手，理智渴望逃脱，身体却因受迫陷入战栗与迟疑。

## 三、六大目标角色的文学演绎图谱

## 四、文字执行铁律：零代打与戏剧留白

在生成剧情与事件时，严守酒馆角色卡的交互界限：
1. **只搭舞台，不替玩家做决断**：
   LLM 负责写足夜雨的阴冷、暗巷的狭窄、她的呼吸与脚步凌乱；**严禁代替玩家写出心理欲望、具体言辞或侵入动作**。
2. **高潮定格留白**：
   当二人距离拉至最近、门锁即将插进钥匙、或者她终于忍不住回头的瞬间，**必须果断刹车定格**。
   把接下来的“是搭话、靠近、出手还是悄然退回阴影”，把生杀大权 100% 留给玩家输入。
3. **语言净化禁令**：
   恪守《写作指导.md》红线，严禁堆砌霸总式词汇与极端修饰语，以冷静克制、入骨入髓的五感白描替代夸张虚饰。
