# 女大学生日程交互预览

状态：独立可操作原型，不进入正式角色卡。v0.8.20正式卡仅同步体力百分比、甜区真实加值与判定显示修复；以下全天日程、工作DC15和追找补救仍只在独立预览启用。

## 打开与体验

打开 `previews/college-schedule/index.html`，可下载后在浏览器打开。页面不请求模型，场景文字为固定示意；地图、日程费用、尾行检定及判定动画使用正式模块。试玩只使用本浏览器独立键 `wx_college_schedule_preview_v1`，不接酒馆变量。

建议先走一遍：地图点击大学食堂 → 度过当前时段 → 地图点击大学图书馆 → 度过当前时段 → 地图点击大学正门 → 跟随离开。尾行中使用上方跟随按钮，或选下方正式胶囊再点击“执行下方选中的动作”。开始后会切换到独立尾行界面，显示当前目视、距离、心跳、体力、警觉和已确认路段；每次确认判定后再继续。可以主动结束跟随，已用的2点不退。结束后先查看收获，再点“回到日程安排”。固定演示种子使结果可复测，没有指定必须失败的楼层。

也可以连续移动测试错过机会：晚间在图书馆，依次去食堂、图书馆、校门；到达校门时已是子夜，入口关闭，不会把已过期的目标留在现场等玩家。

## 本轮暂定规则

- 每天4点行动点、每时段最多一次正式行动、尾行入场2点，沿用已定规则。
- 每时段3格时间，同区一次移动1格，跨区2格，均不扣行动点。此处按地图大区计费，暂不细算街道步行距离或交通速度。
- 累计3格进入下一时段。跨区移动超过边界时，余下耗时带入新时段；例如午间已用2格，再跨区用2格，抵达时为午后已用1格。
- 目标是否在场、能否入场，一律在到达后按新时段判断。普通移动不能无限冻结目标日程。
- 查看档案、切换地图地区、缩放和拖动不耗时；点击地图地点即执行移动并耗时。同地重复移动、禁入地点或条件不足不会耗时。
- 正式行动结束当前时段，下一时段时间格重置。尾行进行中普通移动关闭，使用原内部回合计时，不叠扣外层时间格；尾行结束／中断推进一次时段。
- 日终不静默翻日。恰好耗尽本日时间的移动可以完成并结束当天；超过剩余时间的移动拒绝，不改变位置或费用。之后显式进入下一天。
- 午间现场为食堂，午后为图书馆，晚间为校门离校；早间课堂及子夜居家不从公共出入口投影实时位置。未在场、旧目击、未知住处均不冒充当前目视。

界面显示3格时间条，地图旁给出点击方式和耗时说明；地点悬停及无障碍名称提供移动前报价。已移除固定目的地快捷按钮，原二次移动确认按钮在此预览中隐藏；单击地图地点即前往，键盘Enter／空格同样可用。地区、缩放和拖动只浏览，不耗时；拖动超过阈值不会在松手时误触移动。公开地点均使用同一耗时入口，私人区域、北郊未接交通和尾行中的普通移动仍由本地条件拒绝。离校事件当日只用一次，刷新不恢复入口、不再扣费。

## 保存边界

独立试玩保存使用原引擎v2状态，再加 `previewCollege` 的事件使用日、操作序号和 `timeUsed`。移动时间写入原移动回执的 `travel` 字段，操作编号和内容仍由原日程去重逻辑核验；重复提交、刷新后重试都不再扣时间。早先独立试玩缺少时间格字段时补0，非法的新值拒绝恢复，并明确提示是试玩恢复失败。

本预览没有接真实聊天历史，不用它代替正式卡删楼、swipe和切分支验收。未来转为正式功能时，需要把全天日程、时间格和机会状态接入原整卡时间线，并验证旧档迁移；不能把这个浏览器试玩键带进正式卡。

本轮本地验证：15项逻辑测试、76项桌面／手机浏览器检查通过。截图覆盖午间现场、晚间入口、尾行、真实判定、退出、移动跨时段抵达与错过入口。正式角色卡文件未变更。

地图直接操作补充验证：真实鼠标点击、触屏点按、键盘激活、拖动防误触、重复点击当前位置、旧快捷列表以外的书店／运动场、点击区域浏览和尾行中的移动拦截。地图提示采用固定高度，避免手机端悬停／触碰文字换行使地点位置跳动。

## 尾行界面和跟丢说明

入场后切换独立尾行界面，收起普通地图与日程活动，保留正式HUD和胶囊。只显示已确认路段，下一站未确认时仍为未知。

跟丢结果用“已经找不到她了”和最后目击情况说明，不使用“已中断”作为玩家提示。说明仅依据本地真实结果及已确认地点；没有证据时不编造被人流挡住、坐上公交等原因。跟到终点、主动停下和失去目视分别记录，不把主动退出写成跟丢。

尾行实际结算与时段推进保持原规则。结果页停留在收获界面，明确显示最后目击日期／时段、PI实际收益、线索数、行动点及已经进入的日程。玩家点“回到日程安排”只切换界面，不再次结算或推进时间。未查看完结果不能普通移动，避免结果被新操作覆盖。

独立试玩保存增加可选outcome与sessionPiStart，嵌套预览schema为4，正式引擎仍是原v2。结果、是否已返回日程与收益随同一试玩保存恢复；旧预览没有结果字段时不猜测或伪造之前发生过的失败。原TT聊天存档及正式卡未修改。

本轮额外检查：跟丢文案、最后目击白名单、未知后续地点不泄露、结果页刷新恢复、重复返回不重发PI、主动退出与完整跟随分类。新增lost-1100.png／lost-390.png截图。

## 首次普通失败补救与工作判定（v0.8.20）

每次尾行首个普通失败暂不退出尾行屏幕，不推进外层时段或结算PI；出现“追找她的身影”和“停下”两个明确入口。追找沿用已注册follow动作，距离改为远端，真实消耗一次内部行动并重新判定；不回滚失败、资源、警觉或骰子，不再扣2点入场费，也不保证找回。成功可继续，机会已使用；之后再失败直接结算。天然1不触发补救，仍走原危机规则。放弃补救正常结算。

预览schema4保存pending/used/attempted及最后目击，刷新保留待选补救，不再送一次机会。累计floor不在新一晚清零，避免重复相同骰序列。默认示例种子college-preview-9，既有试玩保留原种子；可重置体验新默认。种子只用于复测，不锁定某楼必败。

工作使用college-preview-work.js适配器：DC15，真实对应属性＋甜区1；天然20大成功，普通成功加薪，失败底薪，无跟随勉强带。固定工资工种不掷骰。本职工资倍率、资格、体力、1AP、每日一次及原去重规则保留。结算使用daily.work登记动作，工资和判定回执共同保存；重复请求不重发工资。正式work.js尚未切入此试行规则。

体力条按当前值/实际上限计算百分比，例如115/115显示100%，悬停可看原值。甜区加值真正进入检定，不只是动画标签；判定台按检定当时心跳标记甜区，避免行动后心跳变化误导。
