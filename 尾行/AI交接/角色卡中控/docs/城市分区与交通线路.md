# 城市分区与交通线路 · v0.8.11

用户要求：A/B/C 是市区，D 是郊外；总图表达相对位置、远近和规模，A 区最大且设施最多；老城高中和大学分开，大学城与临江红灯区补足设施；总图仍简洁。

## 地理结构与显示层级

- **A 区**：东侧市中心，960×800 画布单元，为四区最大；商务核心、轨交枢纽、商业生活圈。26 个节点，含既有道路／站点及新增商业生活设施。
- **B 区**：西北侧老城文教区，760×560；大学、高中、大学生活圈与老住宅巷。21 个节点，高中与大学各有独立校门。
- **C 区**：西南侧临江娱乐区，800×560；夜店后门、酒吧街、夜市、歌厅、现场音乐酒吧、旅馆、深夜食堂、沿江步道和城中村。19 个节点，固定黑市仍在城中村。
- **D 区**：远离市区的北郊，600×420；通过长段公路与市区连接，中间以田地／过渡带留出距离。保留 8 个原有节点，不画地铁、公交进入 D 区。

共 74 个地图节点，其中新增 33 个公开设施／公共入口；不是 74 个已完成业务的商店。区域面积与间隔表达相对规模、远近，不对应实际公里数、行驶时间或费用公式。原场所 ID 和整卡存档 schema 保持不变，不移动玩家已保存的地点 ID。

总图仅标主要地标、交通站点、分区名与线路；进入街区才展示全部设施。原有适合屏幕／放大横向浏览仍可使用，新增交通图层开关。切区、缩放、开关线路、选择地点均不写档、不扣 AP。目标仍只显示本地目视／最后目击，地理信息不暴露她的行程。

| 地铁 1 号线 | B 老街站 ↔ A 中城地铁枢纽 | 蓝色实线与站点圆环 |

| 跨江快线公交 | A 站前公交港湾 ↔ C 大桥头 | 棕色虚线，沿外环及跨江桥接入 |

线路依据已有数值策划的跨区端口关系。地铁可穿过地表建筑，因为线路是地下示意；公交折线沿主街与外环，不画成任意建筑之间的关系网。总图显示线路全名，街区保留线路及站点，详情可查看所经线路与连接说明。

**设定交通关系和逐班乘车玩法要区分。** 当前没有新增发车时刻、售票、逐站车厢、打车价格或车辆动画；A/B/C 日常移动沿既有规则不额外扣 AP，D 区出行结算尚未接通，仍禁止从地图直接进入，不能因图上出现公路而免费跳过去。原尾行移动仍由原回合管线处理。

## 新设施与边界

A 区增加综合商场、百货、数码商城、银行、咖啡馆、门诊、酒店、广场、步行街、影城、健身中心、餐厅、快递站、出租车候车点、停车场、公寓广场及办公楼。

B 区增加高中校门、大学图书馆、大学食堂、运动场、书店、咖啡馆、学生生活街和宿舍区入口；不是把高中和大学画成同一所学校。大学沿用 `school_gate_b`，地图名称为“大学正门”；新增高中 `high_school_gate_b`。女高中生**新局**路线与对应线索地点使用高中；旧档保留原节点与旧校门手部覆写别名，不自动改写旧路线或重新开局。学生身份原有校门权限配置补上新高中节点，未扩展校园室内进入玩法。

C 区增加酒吧街、歌厅、旅馆、深夜食堂、现场音乐酒吧、快递站和洗衣店，保留夜市、江堤、私宅与黑市。

新增地点可以查看并在日程待机时前往**公共入口或外侧区域**；均封印终局、无室内天气豁免、未新增庇护所，避免改变既有逃跑寻路结果。设施详情明确场所内活动暂未开放，不把名称当作功能完成：没有自动发工资、治伤、恢复 AP、影院事件或新商品目录。线上仅食品、器材须到固定黑市的采购规则不变。

## 维护入口

| 文件 | 职责 |
| --- | --- |
| `src/config/places.json` | 真实地点、公开入口性质、区域分类、拓扑与设施说明 |
| `src/config/city-layout.json` | 分区范围和地点坐标，按 ID 关联旧存档 |
| `src/config/city-cartography.json` | 地块、道路、郊野过渡、河流与桥梁美术、主要地标名单 |
| `src/config/city-transit.json` | 线路端点、绘图路径与连接说明的唯一配置 |
| `src/runtime/spatial/system.js` | 从同一线路配置派生接驳关系，只读地图投影与实际移动复核 |
| `src/ui/map/transit.js` | 线路与站点绘制，不执行移动 |
| `src/ui/map/cartography.js` | 地理底图与地图标记 |
| `src/ui/map/city-map.js` | 图层开关、地点及线路详情、原移动命令接线 |

新增线路时同时检查端点是真实交通站点、几何首尾引用端点 ID；公交／地铁不得把郊外端点加入市区线路。不要恢复旧 `city-layout.transitLinks` 的第二份配置。增加设施仍需单独接活动注册与结算，不能仅给建筑起名就开放业务。
