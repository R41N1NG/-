# 第二组教程：日程与尾行

状态：只读PPT独立预览。正式卡更新第一组说明；第二组与全天日程继续配套试玩，不自动插入正式零楼，不启用新玩法。

## 玩家顺序

1. 安排一天：4点AP、五时段，每时段一次日程行动；活动费用与内部动作分开。
2. 到达现场：直接点击地图，同区1格／跨区2格，每时段3格，不扣AP；抵达后判断是否目视。
3. 开始尾行：真实出行机会＋现场目视＋AP足够。本例是晚间校门，不把晚间当作所有目标的通用门槛。入场2点，内部回合不重复收取；整段结束推进一次外层时段。
4. 跟随与收获：切换距离判定、首个普通失败追找、确认跟丢、档案路线四张图。远端DC＋2，近距离心跳与暴露代价、敏捷减免、已知相邻下一站加值；补救真实再判定且找回后远端；记录仅保留已证实连接，可改名。

## 保持边界

本章不调用WxGlue、模型、日程操作或保存游戏进度。只有用户点击全跳过才写原教程偏好，读取与其它章节一致；普通完成只记录本次页面内存。不存页号来匹配聊天，不能用课件进度代替真实回合。

照片全为真实原界面，不绘制替代状态栏。桌面与手机分别拍摄，框选按实际DOM坐标转百分比；只显示当前选中的框。可放大2x无损原图。第一组和第二组各自来源校验，玩法／场景改变需重拍，不静默沿用旧图。

预览包含七类原图：day/move/entry/tailing/recovery/lost/profile，各有手机版。样例未公开完整日程、隐藏住处或未知后续路线。补救和跟丢由真实种子结果得到，未指定某楼必败；固定仅为教学复测。
