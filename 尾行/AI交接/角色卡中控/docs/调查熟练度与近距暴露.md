## 明确规则

- 当前目标PI：0–19／20–39／40以上的已知下一站跟随加值为+2／+3／+4；未知一律0。60点保留情报属性优势。
- “已知下一站”要求持有当前相邻地点之间的连接证据；只知道地点、旧版全known标志、高PI或模型叙述均无效。成功跟随本地时钟推进的相邻一站会登记连接；没有目视、跨越多站、目标路线改变不套用。`revealNode(i)`作为已有显式本地揭示接口，也登记该节点与前一站的连接；它不是自由文本解析器。
- 一段有效跟随可获得当天同路线首次保底+2；线索每项首次+3。失败保留此前成果；立即退出或首次就失败不获得保底。多动作同楼至多计一段有效跟随。
- 连接、具备当前地点与`reveal_via`动作证据的事实、首次解锁的基础属性计作线索；照片和套装仅保留收集收益，不额外刷PI。无地点证据的私密事实暂不自动开放。
- 首次线索先登记，整段结束再到账。边界：跟随失败／天然1、路线末端、逃离末端、摊牌、过夜、显式切线、日程活动结束。普通成功、单纯拍照不会立即加PI。
- 身后每次合法跟随动作额外警觉+4；贴身+8。减免=`min(floor(敏捷/3), floor(额外基础/2))`，只减这部分，不动原基础警觉、心跳、脚步声或记忆。天然20也结算物理近距暴露。4和8是本次暂定调参值。
- 侦探既有身份倍率保留，过夜以已经结算的奖励补差。暂未新增整段PI上限。

## 存档和查错

不新建浏览器进度档、不升级存档版本、不动聊天路径匹配算法。新增可选`investigation`对象与原save/timeline同存同退。字段包含目标、确认事实、连接、已奖励线索、当天路线保底、当前段及最近结算回执。

旧档缺字段时用旧版档案视图冻结原已显示的事实，保留PI、已解锁属性、相册；不把旧known全亮转换为新连接证据。新版字段损坏报告`SAVE_INVALID: 存档调查记录无效：investigation`，不静默重开。

删楼／重生成／切分支沿`src/host/chat-sync/`原路径恢复整份状态。重复回执不叠奖励。聊天首次差异楼层仍由原同步诊断负责，不能用游戏回合数冒充聊天楼号。运行`npm run test:sync`及`tests/investigation.test.js`；TT真机验收另行进行。

教程天然20示例即时PI为0，解锁敏锐和侧图；属性首次线索+3标为待尾行结算，避免演示与正式规则相互矛盾。

## 预览与验证入口

运行 `npm run preview:pi` 生成 `previews/pi-familiarity/index.html`、桌面／手机对照截图和checks.json。案例固定PI20、敏捷5、身后距离，下一站已确认加3／未知加0，额外警觉4−1=3；实际引擎大成功完成路线后结算保底与新线索。场景是标明用途的构造案例，不是玩家的实时进度。原属性／五页教程预览也随规则重拍。

既有成功跟进仍可更新当前目击点；重新目视当前位置不会自动补出此前连接与未来路线，本次没有新增搜索或重新捕捉玩法。
