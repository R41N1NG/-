# 第三组第三页：她的警觉与跟随距离

独立入口previews/distance-tutorial/index.html。第三组的心跳→体力→警觉与距离已互相提供顺序导航，仍未自动插入正式零楼。本次不调整玩法规则、聊天同步或存档字段。

## 教学范围

1. 找到实际距离档，以及心跳面板中的目标警觉区域。
2. 同属性、同初始资源、相同骰点16的四个独立对照：远端DC15，其余三档DC13；不是连续靠近四次。远端有距离DC＋2，身后／贴身另有近距暴露。
3. 实际回合后心跳为30／33／37／41，体力消耗5／5／6／6。展示的是包含段末回落的净变化，不能读成远端永不增加心跳；结果不等于所有实战回合的固定费用。
4. 敏捷5的身后额外暴露基础4、减免1、实际3；敏捷8同一部分减免2、实际2。仅解释这部分额外暴露；敏捷同时可能有别的属性／标签收益，不能把不同敏捷样例的全部总检定变化都归到此处。
5. 提速、骤停回头、开跑分别从真实训练初态触发。课件只传公开行为提示、事件名、当前可见档位和距离，不传原始警觉、目标暗账或事件内部对抗数字。实际回头样例反应后降回“不安”，因此明确说明行为不是固定进度表，回头也不是每次必败。
6. 实际动作抽屉展示跟随／拉开／打量；动作是否改变距离取决于其真实执行结果。当前withdraw实现会拉至远端，课件不承诺任意退一档；不把地图浏览作为尾行移动，不承诺未细化的公交赶车流程。
7. 主动结束样例来自独立女大预览：两次实际同街跟随后已有1段连接，结束后仍保留1段，PI＋5、入场共用2AP，结束推进外层时段一次。旧资源不返还。结果图使用真实collegeTailScreen，不手绘另一版界面。

## 模块

- src/ui/zero-floor/distance-lesson.js/html：距离与反应两组选择、结束说明按需加载、完成及全跳过。
- src/ui/styles/distance-lesson.css：独立课程排版。
- tools/build/distance-lesson-sample.js：真实引擎与预览适配器样例，保持视图和原始训练数据隔离。
- tools/build/lesson-capture.js：真UI裁切、DOM坐标与2xPNG的拍摄帮助函数，不编辑图像。
- tools/build/distance-lesson-shots.js：正式UI判定／信号／动作原图，以及独立预览的真实结束回执；desktop/mobile各13张。
- tools/build/distance-lesson-preview.js：来源哈希检查及单文件打包。
- tests/distance-lesson.test.js：真实数值、非空信息保留、只读与跳过边界。
- tools/check-distance-lesson.cjs：1100／390／320三宽度检查与页面截图。

复用screenshot-pictures，框选来自实际DOM测量，每次只显示选中的区域；限制原CSS尺寸，允许查看原图。复用tutorial-policy；全跳过与前两页共用wx_tutorial_preferences_v1，完成状态仅保存在当前挂载会话，不写游戏楼层或游戏进度。
