# v0.8.0 优化与复审

## 已落实

- 同步：聊天会话校验、串行提交、指纹去重、完整回合与分支恢复、写入失败回退、备份、保留窗口和冲突检查。
- 存档：显式 v1→v2 迁移；未知/损坏档停止覆盖；旧随机流保留，新局字符串用途种子独立。
- 引擎：账本先校验再提交；输入文本不再改变模式；回复不清空动作摘要；按当晚回合推进时间并处理午夜；照片抽样覆盖超过 20 个的候选；动作参数不能伪造实际距离。
- 接口：JSDoc/类型契约与边界校验，快照和存档脱离内部引用；UI 命令经同步模块提交。
- 前端：规则/创角数值由配置生成，共享场所和条件门槛；轮询持续刷新并防重叠；监听、定时器、动画和音频按实例卸载；正式脚本不打入预览数据；新局保存失败不会假装创建成功。
- 构建：跨平台编译失败即退出；版本统一，构建清单记录源码和交付文件 SHA-256。

## 重新检查后补充的修复

1. 修复午夜路线节点被当成“已经到达”的情况。
2. 阻止校验失败后的普通保存覆盖原档，并提供显式备份恢复入口。
3. 旧宿主无法移除监听器时，让已卸载的回调失效；更换卡片时状态栏等待引擎明确启用。
4. 回复事件不再误把玩家消息作为回复处理；重复事件不重复播放判定台。
5. 消息前缀包含助手回复与 swipe 标记，避免只按玩家楼号匹配错误分支。
6. 快照通知标记会话，UI 丢弃能确认已过期的聊天通知。
7. 同时核对持久档正文指纹，识别未更新时间线版本的旧脚本直接写档。
8. 回执汇总改用真实账面差值，包含警觉过档和上下限钳制；未注册的结构化动作在推进回合前报错。

## 状态归属

| 数据 | 负责模块 | 消费方式 |
| --- | --- | --- |
| 身份、优势、心跳标签 | `game/player.js` | 回调与快照 |
| 物品、装备 | `game/inventory.js` | `WxGlue.command()` |
| 日期、目标当日状态 | `game/target.js` | 过夜方法及快照 |
| 当前路线节点 | `game/route.js` | 路线方法，不由 UI 修改 |
| 本回合楼号与结果 | `game/turn.js` | 结构化动作入口 |
| 数值账目 | `ledger.js` | commit；先校验完整变更 |
| 会话、检查点、提交状态 | `host/chat-sync/` | 统一同步接口 |
| 显示状态与资源 | `ui/` | 只消费快照，dispose 清理 |

内部仍有单局共享 `g`，旧 `_g`/`ledger.state`/`WxGlue.game` 接口为兼容保留；它们不属于新的推荐修改入口。当前没有将整个项目迁成 TypeScript，类型检查针对共享契约和会话边界。后续新增字段须同步初始化、保存、迁移、恢复与消费者。

## 实际限制

TT 尚未实机验收。完整恢复依赖宿主身份、完整历史、事件和变量 API；降级模式及非原子写入边界详见同步专项。保留窗口以前的历史和升级前没有记录的回合不能凭空重建。

本次未增加白天/夜晚新玩法、冲突系统或素材制作功能，既有玩法待办仍按原设计推进。
