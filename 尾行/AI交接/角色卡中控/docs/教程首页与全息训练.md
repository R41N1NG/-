# PPT 教程第一页与全息训练 · v0.8.13

用户设定：玩家作为特工，为保卫祖国接受潜行训练；故事发生在全拟真现实的全息环境中。战术终端属于训练设备。日程应当隐性，通过观察、调查逐步获得。新手引导必须先给出行动理由，不能要求玩家凭空知道去学校观察。

## 既有接线与保存边界

只制作目标选择后的最初教程页面“入场简报”，作为消息内零楼第三步。不是弹窗；没有创建另一套存档、钱包或行动点。训练背景在本页呈现，其他旧场景文本、身份内容、整个模型提示词尚未统一改写。后续七页教学、教官事件、保证成功的观察、训练专用路线、课程评分和重试流程均未实装，不得宣称教程已完整可玩。

流程：建立角色 → 选择／生成人物 → 确认目标查看训练简报 → 载入训练场。

- 简报显示掩护身份和目标类型，均读取当前实际选择；不额外展示生成姓名、私密性格／爱好、真实属性、行程或住址。
- 大学城插图是无状态教学示意，采用正式 B 区地块／道路，公开点的名称与坐标在构建时从正式配置提取，不读取目标路线或位置，不表示已发现目标。
- 第一页介绍背景与训练目标，展示公开起点示例，指明载入后先打开城市地图。没有提前教授所有设备与数值。
- 返回目标选择保留人物缓存；更换目标／身份后再次进入，更新对应概况。原有摇号、缓存、加点和目标档案切换能力保留。
- 确认前只浏览创角草稿，不建局、不修改世界书、不推进聊天、不扣 AP；草稿尚未持久化，刷新遵循原创角行为，不冒充已保存教程进度。
- 点击“载入训练场”才调用原 `WxGlue.newGame(init)`，同步目标档案并保存；仍接入当前已有开局场景，不新增自动第一课或强制启用未完成的日程玩法。
- 载入期间阻止重复确认与前后跳步。失败保留人物选择并可重试；重挂载、重置或切换会话后的旧应答不得关闭新页面。
- 已有 `wx_save` 的续局不重弹简报，不重建人物。当前没有持久化的教程进度字段，后续真正课程步骤须接整卡完整档与聊天分支机制后再启用。

## 第 1 页内容与呈现

用户已拟定八页总纲：第一项训练、认识终端、每日行动、地图、情报、操作与文字、尾行反馈、成果与后续。本轮只制作第 1 页，不实现后七页、课程评分或调查／尾行新入口。

页面围绕三个问题：为何训练、学会什么、载入后先做什么。上部交代全息特工训练背景并显示实际选择的掩护身份与目标类型；中部左侧说明从公开环境逐步认识目标，右侧通过真实街块示例、高亮框与箭头指向大学正门。下部突出“打开城市地图，确认自己在哪里”，页脚标明第 01 页及下一主题“战术终端”。没有虚设下一页按钮或完成标记。

大学城图是跨目标通用的教学示例，始终明示“教学示意，非实时定位”“实际起点以载入后的场景为准”。不声称已派发新的调查任务；不修改实际开局起点，不创建玩家／目标位置点，不读取隐藏行程、住址或生成属性。五个公开示例点在构建时校验，只投影名称与坐标，不额外打包全量场所规则。绘图模块不接收引擎或保存对象，点击图片不移动或触发任何行动。

桌面采用文字与图解双栏；390px、320px 为纵向布局并保留插图，关键标注放大。图片说明有无障碍文本，按钮支持键盘焦点。保留原建局、返回缓存、目标条目互斥和失败重试流程；没有新增教程独立存档。
