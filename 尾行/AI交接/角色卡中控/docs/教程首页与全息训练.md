# 第一次训练 · 原界面五页图文教程 v0.8.15

当前修订：正式界面截图、判定动画与侧视收录见文末 v0.8.15。本节保留五页内容和开局边界说明，数值案例以本版修订为准。

玩家作为特工学员，为保卫祖国在全拟真全息环境中接受潜行训练，战术终端是训练设备。用户明确：第一项训练包含一段完整教学过程，而不是一页介绍后只确认位置；本轮完成这一组五页课件。

## 内容与实际操作

| 页 | 目的 | 图解与交互 |
| --- | --- | --- |
| 01 接受任务 | 说明训练背景、为什么从公开起点开始 | 正式大学城地块／道路示意，高亮大学正门并以箭头标注；不表示目标实时位置 |
| 02 认识终端 | 找到状态、动作与记录入口 | 状态栏 → 更多／侦查与取证 → 战术终端／观察流水；保留实际入口名称与示例状态 |
| 03 找到起点 | 区分自己、目视目标与最后目击 | 同一案例的大学正门，蓝橙点无字、同地错开；说明未目视不定位、最后目击不跟踪 |
| 04 执行观察 | 学会点选、伴随描写和发送 | 可点“打量”选择／取消，选中后才可“示范发送本轮”；发送后展示真实成功案例，重复点击不累加 |
| 05 查看收获 | 区分新增观察、积累与仍未知事项 | 同一案例行动前后对照、时间流水与未知边界；可返回第4页重看，也可正式载入 |

五页均可通过导航、上一页／下一页或方向键翻阅；方向键在文本输入框里不会翻页。每次只显示一页，翻页聚焦标题。整个课件支持 1100px、390px、320px，手机保留图解和高亮。右侧界面为简化操作图解，不另造一套真实终端。

第一组完成的是图文教学及隔离示范。没有新增日程调查业务、目标全天行程、训练任务派发、课程评分或完整场景演习；原八主题总纲仍可作为后续课程扩展，不能把本组五页说成整个角色卡所有教程已完成。

## 示例的真实来源与边界

`tools/build/training-sample.js` 在构建时运行正式 `createGame(defaultInit())` 与原回合 `scan` 动作，用固定样本 `tutorial-0` 得到一次成功案例，然后仅白名单投影公开信息。浏览器只展示这一案例，没有再次运行生产结算或调用模型。

当前案例：已在大学正门并目视目标 → 打量成功 → 新增 `21:30 · 目标环顾四周，侧向身形清晰` → PI 0→2、体力100→99、日程行动点4→4。本例没有新增档案条目，目标属性仍为未知。页面没有声称随身包、属性或住址是新解锁所得。

这是**原回合打量**，不是尚未接通的“日程调查1点”动作；体力变化包含实际回合消耗。UI 明确原流程示例、日程活动尚未启用。不得为了让教学更好看而虚构费用或给第一下打量增加奖励。未来规则调整时，先核对正式结算，再更新案例和课件说明。

大学城公开点的名称与坐标由 `tools/build/ui-config.js` 白名单提取，仅限 B 区公开地点；构建时复核，拒绝私人节点。插图绘制只接受教学案例，不读取当前目标隐藏路线、属性、住址或人物生成结果。所有目标类型看到同一个明确标注的女大学生案例；实际选择的掩护身份／目标类型在顶部概况独立展示，不把案例的结果当成当前目标的真实信息。

## 开局、阅读与保存

流程：建立角色 → 选择／生成目标 → 五页图文教程 → 最后一页确认载入。熟悉玩法的玩家也可随时“跳过图解，直接载入”。两种入口均调用原 `WxGlue.newGame(init)` 管线。

- 阅读、翻页、输入示范文字、点选／发送示范，不建局、不修改世界书、不扣真实行动点、不推进聊天、不向当前人物写入样本情报。
- 页号、示范状态和文字仅属于当前挂载 UI 内存，不建立 localStorage 或教程独立存档，不表示真实任务完成。刷新不拿课件页号去匹配聊天楼层。
- 返回同一身份与目标类型保留阅读页；切换类型或重置回到第一页并清空演示状态。人物摇号缓存、加点和条目互斥沿用原模块。
- 最终确认／跳过才建档；载入期间禁用翻页、返回、示范和再次确认。保存失败时保留选择与当前页面，可重试；原聊天同步模块负责错误报告。
- 已有有效 `wx_save` 的续局不重弹、不重建。示范 PI 2 不进入正式新局：正式新局仍 floor 0、PI 0。
- 不新增整卡保存字段，不修改原路线、行动点、日期或聊天分支恢复逻辑。

## v0.8.15 原界面截图、判定动画与侧视收录

本版替换此前简化终端与手绘地图。`npm run screenshots:training` 用真实引擎案例和正式 `buildUI` 在 Chromium 中打开状态栏、完整终端、地图、动作抽屉和判定台，得到桌面／手机各七张原始 JPEG；浏览器同时读取真实 DOM 边界，课件按百分比叠加金框、编号和文字。不是重新绘制一个长得相似的界面。

- 第2页先展示原状态栏的终端按钮，再展示完整展开的终端。路线、资产属性、行囊、修正标签、接近度、观察流水、环境／沙盘、账本和深页入口均有编号解释。小屏支持打开原图、横向查看。
- 第3页并排／纵向展示真实目视和真实跟缀失败后的地图：最后目击橙点为空心虚线，原位置冻结，状态栏显示最后目击和日期，不把目标后续位置泄露出来。
- 第4页先保留完整原动作抽屉，再给出打量胶囊原截图裁切，使用脉冲金框和“点这里”箭头。发送示范调用同一 `createSettlement`，显示原 D20 动画；三部分为检定态势与筹码、D20落点、结论与账目。课件也提供判定台真实截图及三部分说明。临时标注只用于教学，动画不另掷骰，不调用模型。
- 示范期间临时关闭并禁用“自动掷”控件；关闭面板后恢复原偏好。判定面板临时移到当前 document.body，避免开局前状态栏壳隐藏导致动画不可见；关闭或销毁时放回原位。示范使用独立负数演出序号，不占正式回合去重号，不改变游戏心跳、账本或存档。
- 第5页直接显示本例收录的“浅米灰连帽卫衣 · 侧面”正式部位素材，记录和结算仍来自同一次原引擎案例。不是完整立绘生成；只展示对应部位图鉴素材。

正式 `scan` 成功也接入同一相册：在当前装束准确匹配的部位中收录一张未拥有侧图，失败、跟丢、远端、素材不足或侧图已齐均不会造图或重复发放。当前示例已改为 `tutorial-3`：新增卫衣侧图一张，PI0→2，体力100→98、心跳30→35（含本例环境与原回合实际消耗），日程AP4→4；没有新增住址、属性或日程。相册补齐真实 catalog 投影，旧已收录图也可显示。正式文件路径／保存字段沿用原相册，新增 source 字段仅标来源，旧档无需重开。

67 张已有正式侧面素材由 `tools/build/wardrobe-assets.py` 生成 `src/ui/generated/wardrobe-images.json` 内嵌缩略图及来源 SHA256；`photo-source.js` 为课件、相册、即时卡片共用解析器。正式侧图无需另装 user/images 目录；没有内嵌的旧正／背面仍沿用原外部图包路径。原始素材不改写，重新打包需 Python/Pillow。

新增维护入口：`tools/build/training-shots.js`、`training-shot-hash.js`、`tools/browser-session.cjs`；截图存在 `previews/training-brief/source/`，内嵌源为 `src/ui/generated/training-shots.json`。源校验覆盖正式 UI 和案例规则；界面或规则变化而截图未更新时，普通构建明确失败，运行 screenshots:training 后再构建。被替换的 training-diagram.js 手绘入口已移除，地图本身仍用原正式模块。

## v0.8.16 清晰度与标注修正

截图统一二倍像素比无损 PNG，保留真实 UI，不再使用 JPEG。截图前等待字体加载、连续两帧及弹窗入场动画完成，再测量和拍摄，避免缩放中测量引起错位。接近度改标完整 `#proxContainer`，不再标零高度 `#proxNodes`；生成器发现无面积区域直接报错。

移除满屏粗框与压在文字上的编号。每张截图只显示一个细角标，点击下方编号说明切换位置；编号只出现在说明区，图上无横贯文字的边线。胶囊保留箭头和可点击区域，脉冲收敛；判定示范去掉三块厚描边。高清大图按原图尺寸的1.5倍展示，使用二倍源图，保持足够像素。旧 JPEG 源图删除，PNG 唯一生成入口仍为 `screenshots:training`。

本轮只修教程表现和截图管线，不修改游戏、奖励或保存机制。本地验证：414 项完整测试、253 项浏览器检查和类型检查通过，含二倍源图、单项标注切换与接近度完整区域检查；TT 真机待验收。

## v0.8.17 属性前置课与全部教程跳过

开局顺序改为：玩家属性课 → 创建角色 → 目标属性课 → 选择目标 → 原五页操作图解 → 确认载入。属性课属于零楼内页，不是弹窗，不产生回合或进度档；同次开局读过后返回修改不会重复拦截。续局直接读取原档，不重新讲课。

玩家课说明体格、敏捷、胆量、情报、口才，及20基础点、每项1～10、身份修正另算与最终封顶10。目标课说明体格、敏捷、敏锐、胆量、社交，以及“？”是未知、情报属性不等于PI、一次打量不保证揭开属性。讲解不暴露实际目标后台数值。图解来自正式加点框和目标选择页的未知属性行，仍为2x无损PNG；源截图现在桌面／手机各9张。

“想直接开始？”区域在零楼各页醒目显示“一键跳过所有教程”。点击后立即跳过当前前置课，后续目标课、原五页教程不再出现；目标确认直接走原 newGame 管线。五页教程底部的旧跳过按钮也升级为全教程跳过。若在五页中跳过，则隐藏教程并直接载入；保存失败回到普通目标确认页显示错误，可以重试，不强制重看教程。

偏好单独存于浏览器 localStorage 的 `wx_tutorial_preferences_v1`，只含 `{version:1,skipAll:true}`，不进入 wx_save、wx_init、楼层状态或时间线。当前浏览器后续开局、重新挂载仍记住；跨设备不自动同步。浏览器禁止写入时，当前实例照常跳过，并实际提示偏好未保存，不伪称持久记忆。重开／聊天切换只重置“本次已读”内存，不清除全跳过偏好。

维护入口：`attribute-lessons.js/html` 管内容与呈现，`attribute-lessons.css` 管独立样式；`training-pictures.js` 统一全部章节的截图、角标与大图；`tutorial-policy.js` 为唯一策略入口。未来教程必须调用 shouldShow(courseId)，或通过 zeroFloor.registerStep(id,{tutorialId,viewId,...}) 注册；带 tutorialId 的扩展受全局跳过守卫，不能绕过该入口直接显示教学内容。zeroFloor.tutorials 提供只读 shouldShow/isSkipped。原注册的非教程扩展不受跳过设置影响。

`npm run preview:attributes` 生成完整开局交互预览 `previews/attributes/index.html`；浏览器回归同时输出 player-WIDTH.png 和 target-WIDTH.png（1100／390／320三档）。原 `preview:training` 仍可直接查看后半段五页图解。预览游戏变量只在页内内存，跳过偏好仍遵守当前浏览器设置。

本轮本地验证：419 项完整测试、283 项浏览器检查和类型检查通过。包含两处前置顺序、读完返回不重播、全跳过后的正式建档、存储恢复／损坏／受限、未来章节守卫、重复提交、保存失败重试及原目标条目互斥回归。TT 真机仍待验收。
