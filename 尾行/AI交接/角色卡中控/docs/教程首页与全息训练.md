# 教程首页与全息训练 · v0.8.10

用户设定：玩家作为特工，为保卫祖国接受潜行训练；故事发生在全拟真现实的全息环境中。战术终端属于训练设备。日程应当隐性，通过观察、调查逐步获得。新手引导必须先给出行动理由，不能要求玩家凭空知道去学校观察。

## 本轮范围

只制作目标选择后的最初教程页面“入场简报”，作为消息内零楼第三步。不是弹窗；没有创建另一套存档、钱包或行动点。训练背景在本页呈现，其他旧场景文本、身份内容、整个模型提示词尚未统一改写。后续六项分步教学、教官事件、保证成功的观察、训练专用路线、课程评分和重试流程均未实装，不得宣称教程已完整可玩。

流程：建立角色 → 选择／生成人物 → 确认目标查看训练简报 → 载入训练场。

- 简报显示掩护身份和目标类型，均读取当前实际选择；不额外展示生成姓名、私密性格／爱好、真实属性、行程或住址。
- 全息城市是无状态的装饰性示意，不读取目标路线或位置，不表示已发现目标。
- 介绍训练背景与“认清位置、读懂线索、谨慎行动”三个要点；本页不提前教学所有设备和数值。
- 返回目标选择保留人物缓存；更换目标／身份后再次进入，更新对应概况。原有摇号、缓存、加点和目标档案切换能力保留。
- 确认前只浏览创角草稿，不建局、不修改世界书、不推进聊天、不扣 AP；草稿尚未持久化，刷新遵循原创角行为，不冒充已保存教程进度。
- 点击“载入训练场”才调用原 `WxGlue.newGame(init)`，同步目标档案并保存；仍接入当前已有开局场景，不新增自动第一课或强制启用未完成的日程玩法。
- 载入期间阻止重复确认与前后跳步。失败保留人物选择并可重试；重挂载、重置或切换会话后的旧应答不得关闭新页面。
- 已有 `wx_save` 的续局不重弹简报，不重建人物。当前没有持久化的教程进度字段，后续真正课程步骤须接整卡完整档与聊天分支机制后再启用。

## 维护入口

| 文件 | 职责 |
| --- | --- |
| `src/ui/zero-floor/training-brief.html` | 教程首页结构，构建时内嵌 |
| `src/ui/zero-floor/training-brief.js` | 概况、装饰图、返回／载入回调、忙碌与失败提示 |
| `src/ui/styles/training-brief.css` | 独立页面样式、宿主按钮皮兼容、窄屏布局 |
| `src/ui/statusbar.js` | 注册第三步、前置条件、最终确认与原建局管线衔接 |
| `tools/build/ui.js` | 合并模板片段和样式，生成正式 UI |
| `tools/build/training-preview*.js` | 正式页面与实际建局模块的独立试玩桥，不进入生产脚本 |
| `tests/zero-floor.test.js` | 返回／切换不重抽、浏览不建档、载入失败重试、重复确认、目标档案与续局 |
| `tools/check-browser.cjs` | 实际桌面、390px、320px 布局和交互检查及截图 |

新增教程后续页应注册独立步骤与视图，不把页面状态当成结算事实。不得把“载入训练场”按钮改为显示完成提示却没有实际衔接，也不能仅靠 CSS 隐藏绕过前置条件。

## 预览

`npm run preview:training` 生成 `previews/training-brief/index.html`；下载后可直接打开。初始代选阿宅和女大学生，通过正式按钮进入第三步；可返回改选，最终载入会使用正式引擎建局，但预览变量只在当前页内存，和酒馆存档隔离。

截图为实际页面：`desktop.png`、`mobile.png`、`mobile-320.png`。`npm run test:browser` 自动更新截图。TT 真机仍需验收零楼消息重绘与宿主样式，浏览器自动检查不等同实际酒馆验收。

本轮本地验证：398 项完整测试、170 项浏览器检查及类型检查通过；TT 真机仍待验收。
