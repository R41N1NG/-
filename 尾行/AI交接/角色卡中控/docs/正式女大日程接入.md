# 正式女大日程接入（v0.8.25）

本轮把已确认的女大标准日程从独立原型提取到正式运行时，教程仍保留现有挂载范围，未将后续课件直接拼进零楼。

## 玩家现在能做什么

- 新建女大学生目标时，零楼会提交collegeDaily标记，载入早间、4点行动点、玩家据点。已选身份／自设属性／生成目标完整保留，不换成原型的固定阿宅或固定人物。
- 每时段3格，地图点地点直接移动；同区1格、跨区2格，跨时段余量保留，移动不扣AP。切分区／缩放／拖动只是浏览。
- 正式已实现午间食堂、午后图书馆和晚间校门的现场目视；公开地图不公开目标完整日程。现场符合条件后，日程区“跟随离开”才可用，费用2AP。
- 入场进入尾行界面，地图普通移动与日程活动收起。距离下拉框只排入跟随动作，仍需通过聊天框发送后本地判定；不直接移动或自动保证成功。原有动作抽屉和文字伴随表达保留。
- 首个普通跟随失败可追找一次，天然1不提供该补救。追找消耗一个实际内部回合和资源，不再扣入场AP、不返还原失败费用、不保证找到；成功从远端继续。
- 主动结束、最终跟丢或完成路线后显示明确反馈、真实最后目击及本次收获。结束只推进一次外层时段；确认收获不重复扣点／结算。
- 休息、食品、购物沿原正式模块；女大日程中的非固定工资工作接入暂定DC15、成功加薪／天然20大成功，右侧列出额外收入。固定工资仍免检。
- 全息训练背景已同步至描述／场景／系统提示；默认开场改为训练准备，日期／地点服从实际状态栏，不再固定周三21:30在校门外。

当前标准出行仅覆盖周一至周四的女大样例，周五／周末和其它目标的日程尚未扩充；不是设定所有目标只能晚间尾行。其它目标新局及旧存档沿用旧流程。本轮没有强制改写旧档的时段、资源、骰序或开始位置。

## 保存与回退边界

原save v2和聊天时间线版本保持不变，新增可选collegeSession（内部schema1）：时间余量、当日机会、补救状态、结束反馈、一次补救的幂等回执。其余账户、位置、路线、PI和日程仍用原字段，未另开浏览器游戏进度。

- 读取含collegeSession的存档时自动装配正式会话；不含它的旧档不会仅因targetId=college而切换流程。
- 迁移入口校验新字段，损坏报告SAVE_INVALID，不静默清零或新建角色。
- 会话快照是只读投影，不在轮询时消耗时间、登记机会、追加收益。补救回执仅保存于状态，公共快照不透出其内部结果包。
- recoverTailing、acknowledgeTailingOutcome进入原宿主命令白名单，使用scope／epoch与日期／时段／序号／内部回合守卫，并沿现有检查点保存。
- 补救操作号随完整存档保存。写入成功但应答丢失时先重读，重复操作复用回执，不重新掷骰或再扣资源。结果确认重复执行同样不重结算。
- 普通条件错误COLLEGE_CONDITION不记成存档同步故障；真正的存储／时间线错误仍走原同步专项和楼层诊断。UI收到旧聊天的迟到结果或错误时不写入新聊天界面。
