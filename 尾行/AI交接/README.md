# AI交接

先读[项目状态](项目状态.md)，再读[用户最终要求](用户最终要求.md)和[协作流程](协作流程.md)。原始附件为来源材料，遇到冲突以用户后续修正为准。

| 文件 | 用途 |
| --- | --- |
| [项目状态](项目状态.md) | 已完成、未完成、目录及素材计数 |
| [用户最终要求](用户最终要求.md) | 累计修正与不得丢失的约束 |
| [协作流程](协作流程.md) | 接手、路径、生成、核对、提交及打包流程 |
| [原始附件](原始附件-jk-for-gpt.md) | 用户上传的原始制作需求，保留来源 |
| [制作规范](../图片/制作规范.md) | 项目完整制作约定 |
| [逐张清单](../图片/生成清单.json) | 目标文件、实际尺寸、SHA-256、修订与自检 |
| [最新样张清单](../图片/背景风格样张/藏青西装套装/样张清单.json) | 7张样张及参考的提示词、来源、状态 |
| [未完成项目](../图片/背景风格样张/藏青西装套装/未完成项目.json) | 两项下装动态尚未完成的原因 |

脚本均使用Python标准库，可从任意工作目录运行，无需旧工作区的`/tmp`脚本：

```bash
python 尾行/AI交接/脚本/校验图包.py
python 尾行/AI交接/脚本/更新索引.py
python 尾行/AI交接/脚本/打包图包.py
```
