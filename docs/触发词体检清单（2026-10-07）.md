# 触发词体检清单（2026-10-07）

> 用途：主人划勾用。**只体检触发词（keys）本身** —— 闸门（身份／准入／上界）另算。

## 口径

- 样本：`chats/仙姝堕/` 下 7 条聊天记录，**共 19 个楼**（每条记录逐楼回放）；
- 对每条条目：按**它自己的 `scan_depth`**（缺省 6）取窗口文本，看它的哪些 key 出现在窗口里；
- `floorsHit`＝这条被唤醒的楼数；`占比`＝floorsHit ÷ 19；
- **常驻条**（`constant:true`）本就每回合注入，单列，不进"高频词"判定；
- **高危**＝占比 ≥ 40%：等于这条几乎常驻（它按触发词算，却在每回合都进上下文）。

## 四、建议改法（供划勾）

| 做法 | 适用 | 代价 |
| :--- | :--- | :--- |
| **把高频 key 换成长词/专名** | 上表「换掉 X」那些 | 逐条改 keys；改错会漏注入，所以先划勾再动 |
| **加次键互斥** | 想留着短词但降噪 | 次键不保证同场景（GPT 复核结论），只降噪 |
| **整条改成常驻** | 占比 ≥ 80% 且确实每回合都要用的（如人物档案） | 没有额外代价，反而语义更清楚 |
| **停用/删条** | 占比高又没什么用的（如按月名唤醒的中立条） | 直接少几百字/回合 |
