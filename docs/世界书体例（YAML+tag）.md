## 一、铁的规则（不合就判失败）

1. **每条必须被一个 `<tag>` 完整包住** —— 首行 `<tag>`，末行 `</tag>`，中间不留空标签。
   - 规则类用语义化名字：`<card_rules>`／`<status_block_spec>`／`<tracked_fields>`／`<output_contract>`／
     `<writing_style>`／`<info_gate>`／`<ban_leak>`／`<stage_drive>`／`<Feminine_Narrative_Engine>`。
   - 资料类按分区用同一个词根（见下表），**不许一条一个花样**。
2. **内部一律 YAML 层级**：
   - `# ` 条名（一条只有一个，紧跟开标签）
   - `## ` 小节
   - `### ` 细分（需要才用）
   - `- ` 条目（**废掉 `·` 与中文序号「零、一、二、三…」**）
   - `- 键: 值` 用于字段式内容（如 `- 修为: 金丹中期`）——**冒号后留一个半角空格**
3. **不许两种符号混用**：同一条里不出现 `·`；不出现「（一）」「1、」「①」这类序号（正文引用原文数字除外）。
4. **语义一字不改**：这一轮只动**排版与符号**。每条改完要与改前的正文做
   **归一化比对**（去掉 `#`／`-`／空白／加粗星号后必须完全一致）。
5. **标签名不许拿来当内容**：`<tag>` 只用英文小写与下划线，不许中文、不许空格。

## 三、样例（常驻条，已落地的真实改法）

```text
<tracked_fields>
# 状态字段台账
## 会被脚本读走的栏
- `身份`、`修为`、`地点`…（照录）
## 锚点事件（14 个，自己记）
- 写进 `<实际发生>` 栏…
- 可写字段名: 玄机子胁迫过叶红缨、红缨分裂成形…
</tracked_fields>
```

## 四、两类例外

1. **分区标记条**（`━━━ 【设定】共 53 条 ━━━`）是给人看目录用的，不包裹、不进模型关注；保持原样。
2. **停用条**（`〔待解锁〕…`）同样按本规范包裹 —— 它们只是默认不进上下文，格式仍要一致。
