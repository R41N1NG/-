`getVariables` 返回克隆；`insertOrAssignVariables` 用 `_.mergeWith` 深合并，数组替换。普通对象旧键顺序与未涉及属性会保留。同步 updater 在当前层变量副本上执行，然后同步 `replaceVariables`；回调写返回对象，不能传异步 updater 来取得本版的同步保证。chat/message 写入在内存立即生效，磁盘保存用 debounce，并非变量回读滞后一拍。

我们在同步回调内再核聊天/最新楼，从调用瞬间的当前副本只赋这笔叶路径；来源记录等原子对象整体赋值，其他变量保留。传给 updater 的函数不含 await。这是统一事务通路的修订，GM/状态机使用同一实现。

## 原样摘录

```ts
export function getVariables(option: VariableOption = { type: 'chat' }): Record<string, any> {
  return klona(get_variables_without_clone(option));
}

```

```ts
export function updateVariablesWith(
  updater:
    | ((variables: Record<string, any>) => Record<string, any>)
    | ((variables: Record<string, any>) => Promise<Record<string, any>>),
  option: VariableOption = { type: 'chat' },
): Record<string, any> | Promise<Record<string, any>> {
  const variables = getVariables(option);
  const result = updater(variables);
  if (isPromise(result)) {
    return result.then((result: Record<string, any>) => {
      replaceVariables(result, option);
      return result;
    });
  }
  replaceVariables(result, option);
  return result;
}

```

```ts
export function insertOrAssignVariables(
  variables: Record<string, any>,
  option: VariableOption = { type: 'chat' },
): Record<string, any> {
  return updateVariablesWith(
    old_variables => _.mergeWith(old_variables, variables, (_lhs, rhs) => (_.isArray(rhs) ? rhs : undefined)),
    option,
  );
}

```

宿主 `getTavernHelper()` 返回 `getVariables`、`updateVariablesWith`、`insertOrAssignVariables`；`initTavernHelperObject()` 将该对象注册给 `globalThis.TavernHelper`。故按钮运行时可从宿主取 API，不必保留已销毁 iframe 的 API 闭包。上游源契约不等于本机所有插件组合已验收。
