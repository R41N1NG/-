# 接口与行为说明

身份：gpt。本轮从第三阶段正式工程真源继续，不从旧说明文档重新抄写规则。

## 酒馆接口与读写边界

`createXsdHostPorts` 注入 window/globalThis、安全 getter、日志出口，保持原词法函数及多窗口/助手探测顺序，保留可变 API 对象。新增可选 eventRemoveListener/stopGeneration 用于退出解绑与真实取消请求。`createXsdMessageReader` 接受 API/msgOf/日志，负责正文、新聊天与最新楼读取；世界书和身份联动仍走原入口。

各业务核依赖表在兼容适配文件集中列出，函数桥延迟解析；创建业务实例不挂消息监听，不创建持久化队列。`createXsdInventoryRules`、`createXsdInitializer`、`createXsdMilestoneApplication`、`createXsdStatusApplication` 都可以用每条消息的独立依赖装配，旧调用名称保留。Node 状态解析入口加载同一主体证据核，禁止维护两套算法。

`createXsdLedgerReader` 合并消息层普通字段与聊天层控制记录，当前聊天的人工覆盖先参与资格，再恢复账本。名器成形恢复要求完整前置；双姝缺一不能恢复，楚灵夜缺额外前置不能恢复。已知 NPC 持有不等于玩家获得；没有可信新来源的历史 true 不被全局清除。

## 剧情、主体与来源资格

段位表/楼层表保持原版，状态协调器按选定时间基准及本楼合法历时计算当前日期，禁止由当前段位的预设日期反过来证明事件已到。自动固定锚点新增门槛：南域大劫 1578.08；天溪城兽潮与兽潮血战 1579.01；天溪城破 1579.03。缺有效年月或日期未到则拒绝；达到日期仍须正文事实证据。已有提前 true 不再自动参与这些事件的快速推进，明确人工 true 保留其权限。

状态块只是申报；本轮已验证锚点缓存不能充当资格。正文传闻、计划、否定不能自动写真。主体证据按分句及动作的明确主体确定，被动句读受影响者，旁观角色不因距离近而获同一事实；无法明确的复杂汉语叙事保守拒绝并可由人工确认。

同楼来源指纹包括正文哈希和分支，不再只有申报名单/动作名单。新版首次自动破处记录另存楼层/指纹来源，同楼重生成撤去证据时撤销自身贡献与簿条目，不让读盘自愈复活；其它楼、人工记录和无来源旧簿不自动清除。自动名器获得只在玩家归属条件成立时授予。原自由字段按分句识别事实/计划、模糊战事待核与原数值互动试点保持。

## 总调度与事务

`main.js` 是生产装配入口，不再存放整套事件处理算法。`createXsdDispatcher` 注入宿主、业务、统一服务、计时器与取消出口；`createXsdMessageTransactions` 管理聊天、楼号、分支/正文签名、实例 epoch、队列和成功去重。

事件收到与面板 tick 共用同一路径和同一并发 Promise；只处理最新 AI 楼，成功提交及回读之后才去重，失败释放可重试。宿主正文可读时，旧 iframe 原文与当前正文不符则拒绝；初始已知的签名后续读不到也中止。换聊天/最新楼/正文分支/退出实例后，旧任务 guard 失败。

每楼由 `createXsdStatusOperation` 克隆当前状态为隔离草稿，库存、初始化、字段、日历、锚点与账本在草稿上规划；人工保护参与规划，延迟成功通知与面板刷新。规划完成只调用一次现有 writeStat/service.write，统一服务仍负责双层持久化、读回及可执行时的补偿，不新增第二持久化器。writeStat 透传事务 guard 到统一服务 API 视图，统一队列等待和每层操作之间都重新核签名，不能在第一层 await 后把旧分支写进第二层。

“一个统一提交”不等于数据库式原子性：宿主两层接口不能提供真正原子提交。若第一层已写后聊天/分支变动，停止继续写入且返回失败；为避免写进错误上下文，不强行进行已失效的补偿，重试当前正文后核双层一致。普通同上下文写失败仍由既有服务读回/补偿。报告必须区分成功、失败、部分写入及可重试。

首次生成前置由实例持有，不再引用未定义 runtime；真实初始化和双层身份/阵营/全部 known 回读一致才标完成。失败尝试真实停止生成接口，区分请求已发与返回 true 确认，缺接口不声称已取消；失败不会置完成标志，命令不继续执行。

事件使用实际 EVENTS 常量，包括原生 MESSAGE_SENT；start 幂等，替换旧实例先 dispose，退出清理自有计时器、可移除监听与自身全局入口。宿主 eventOn 既不返回清理句柄也不提供移除接口时，无法物理解绑，但已停用实例 guard 会阻止遗留回调写状态。菜单有自身清理职责，旧实例不删除其它实例入口。

## 明确边界

没有本机完整成卡、最新世界书主源及真实 Windows/酒馆访问。本轮不能自动清除未知旧档污染、恢复被旧文档覆盖的全部原著条目，不能证明所有自然语言都被识别，也不扩展 MVU 自动升阶玩法。自由字段使用提交前可信日期作保守门禁，跨越门槛同楼可能要下一楼才允许展示；不能据此另改时间或推断新世界事实。
