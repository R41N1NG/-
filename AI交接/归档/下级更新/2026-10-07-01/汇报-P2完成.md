## 二、为什么我前面失败五次（真因，已复现）

**日期行不是独立语句，而是多行字符串拼接链中的一段**：

```js
return '【启卷入世 · 自设命途】\n' +
  '• 道号名讳：' + name + '\n' +
  '• 当前时点：' + (values.custom_timepoint || '第一章（…）') + '\n' +   // ← 我五次都想把 const 插在它旁边
```

⇒ `const … = …;` 被插进**表达式中间**，必然语法错。**正确做法**：`const startTime = …` 插到 **`return` 之前**，日期处只做**片段替换** `(values.custom_timepoint || '…')` → `startTime.value`。改法落地后一次通过。
（教训：在这个文件里**任何"日期行/返回行附近"的插入都要先判断它是不是拼接链的一段**。）
