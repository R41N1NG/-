# 幽寂谷可点击模板 v0.2

下载 ZIP，解压后双击 `幽寂谷-点击试玩.html`。单文件 HTML 内嵌地图、引擎和界面，不需要服务器、Python、模型或外部 API。

推荐试走：幽寂谷 → 探索洞府 → 开启暗格 → 离开洞府 → 结束第一轮 → 前往密室 → 打开左边暗格 → 离开密室。另一条路线选山涧，离开后点击结束第一轮再进入山谷采集草药、从出口离开。

试行设置可重开、切身份和测试1578年其它日期；初始3月1日，开放期3月1日至4月30日。按钮直接调用状态引擎，显示自然语言，不显示内部稳定代码。保存采用当前浏览器 localStorage，刷新恢复；浏览器限制本地文件存储时会提示。撤回最近一步同时恢复时间、奖励、条件、互斥及轮数；导出仅保存试玩数据。

## 采用的规则与测试配置

- 按主人原始树实现，洞府3轮、山涧5轮，期限从本次事件进入开始计算；每次“记录一轮自由活动”模拟一个成功故事回复。点击选择和重绘不耗轮。进入子区域后不会因入口过期被踢出。
- 离开洞府/山涧返回第一轮选择面板，未访问且未过期的另一入口保留。返回不重置期限；已探索区域本次不重复进入。点击“结束第一轮”才进入第二轮；仍有可探索入口时弹确认，提醒剩余入口将关闭。
- 香炉/暗格、密室左/右各自互斥；地图条件由指定暗格点击获得。自由活动文字不能直接授予物品/条件或加时。
- 奖励均为无数量的演示物品；丹药/草药/法宝/秘籍名称待定。正常退出推进2日、提前退出1日、本次叙事预算2日均是测试配置，不是正式剧情规则。未连接模型，活动记录不生成故事。测试奖励点击时记录，退出回执汇总；提前退出保留本次已取物品的规则仅用于试玩。
- 日历使用每月30日整数日序，不采用1578.0315浮点增量；界面显示年/月/日。整数方式与既有日历方向兼容，但尚未替换生产时钟。
- 地图标记坐标为试排，地图底图来自本次上传；全部身份相同开放，没有编造身份特殊奖励。
- 重复/旧步骤代码、过期选项、未满足前置、已消费互斥组由引擎拒绝。结束不能重复进入或结算；“重开”显式清空本次数据。

已核用户三份试玩存档：三份最终状态turn均为0，确认旧版离开第一轮区域会提前跳第二轮。现已修复返回选择面板。结果提示采用高对比提示框，明确获得物品、互斥关闭、返回位置；第一轮入口常驻显示剩余轮数/已探索/已过期。

模板仍共用旧试玩存储键，刷新时恢复已有存档；旧版已结束事件不会自动重写。测试新流程请“试行设置→以此日期重开”，或撤回到第一轮子区域再离开。此版无存档导入按钮，附件只用于核对，未公开提交私人存档。

轻量DOM仿真额外覆盖三种最终退出的取消/确认、第一轮跳转确认取消、状态不变；未做真实浏览器视觉验收。
