## 三、gpt §2.2 要的**环检查**：结论 **无死环**

判据：闸门里 `!(known[X] === true)` 这类**否定块是上界**（X 发生后本条关闭）—— **凡有这种上界的条目，就是产生 X 的那条**；
只要它的**准入**不要求 X 自己，就不成环。逐一实测 **10 个锚点全部不成环**：

| 锚点 | 产生它的那条（上界＝¬它） | 它的准入要求它自己吗 |
| --- | --- | --- |
| 南域大劫 | 剧情四(id53)、中立三(id54) | 否 |
| 兽潮血战 | 剧情七(id58) | 否 |
| 天溪城兽潮 | 中立四(id59) | 否（只要南域大劫） |
| 天溪城破 | 剧情十一(id64)、中立五(id66) | 否 |
| 已抵达天溪 | 剧情六(id57) | 否 |
| 赠送冰心泪 | 剧情五(id56) | 否 |
| 极乐引入手 | 剧情二(id48) | 否（准入恒开） |
| 进入幽寂谷 / 玄机子胁迫过叶红缨 | 剧情三(id52) | 否 |
| 灵犀同心成形 | 剧情八(id61) | 否 |
| 赵无忧坠渊 | 剧情十二(id65) | 否 |

**新加闸门后的链也通**：`中立五(城破) ← 天溪城兽潮 ← 中立四 ← 南域大劫 ← 剧情四(id53，准入不要求大劫)`。
另外查出**大劫在中立三是「不限身份」可产生的** ⇒ 殿主专轨（暗度天溪／要塞陷落）不会因为身份不同而卡死。
