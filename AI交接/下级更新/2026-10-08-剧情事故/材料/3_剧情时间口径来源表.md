## 3.3 「哪个是作者规则、哪个只是调度参考」——**我判不了，需要主人给**

可交的客观事实：

1. **`SEG_TIME` 是脚本里的调度表**（源码在 `卡片脚本/状态机.js`），它的第 7 段＝1578.12；
2. **滑块预设与菜单 chips 是 UI 层的日期标签**（源码在 `src/first_floor_rebuild/`），天溪兽潮＝1579.01、天溪城破＝1579.03；
3. **「1579年一月／1579年三月」同时还写在两条【中立】条的 `keys` 里**（`1579年一月`／`1579年三月`）——即它不只是 UI 标签，也是**世界书唤醒词**；
4. **剧情条自己的「## 时点」跟 UI 一致**（七＝1579.01、十一＝1579.03），**跟 `SEG_TIME` 不一致**（段 7＝1578.12）。

⇒ 按「同一件事有两套日期、且剧情条站在 UI 那边」这个事实，**倾向：`SEG_TIME` 是调度参考、条目「## 时点」＋中立窗口是口径**。**但这是我的判断，不是可引的作者规则**；作者的规则出处（原著章节对应关系／主人当面指定）我**没有找到**，**如实标：未找到，需主人给一句。**
