## 当前维护内容

- `src/core/`：后台结算、活动、事件与状态校验。
- `src/app/`：人物和地点数据、住宿与时间规则、存档、叙事标签解析及正式状态栏。
- `scripts/`：构建和测试脚本。
- `地图预览/`：全域、镇内、室内场景与职业图标。

以当前 `src/` 为源码依据。已清理旧 R4 角色卡、两份旧构建脚本、旧配套压缩包和过时的源码快照；不再混列旧成品的安装说明。

## 人物与旅店

玩家伯里为见习战士；古兰是伯里与妮丝的母亲，作为独立住客，不称为领队或冒险者小队成员。妮丝为见习法师，伊丝娜为斥候，奥萝拉为见习牧师，爱德为随行后勤。

当前旅店导览按用户要求展示同一侧一排六间客房：伯里、古兰、伊丝娜、妮丝、奥萝拉、爱德分别有入口。房间归属、队伍身份及角色是否在房分开处理；预览中的动向为演示，尚未接入后台。

## 构建与资料

构建入口为 `scripts/build.cjs`，按脚本中的工程路径读取源码与 UI 素材；测试入口也在 `scripts/`。运行需要相应完整工程资源。

新测试引用的 `最新角色卡/奥克赫斯.json`（32 条正式世界书）未随本次源码上传；当前目录不提供它的替代卡，也不提供已重建的正式运行包。
