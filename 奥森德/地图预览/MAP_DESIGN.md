# 奥克赫斯地图规范

本文件记录用户已确认要求。人物身份以用户最新明确修订为准；地图不擅自更改后台规则。

## 人物与住宿

- 玩家是伯里，见习战士；妮丝是妹妹，古兰是两人的母亲。
- 古兰是女性独立角色，不是领队、不属于冒险者小队；仍保留她在旅店的住宿与访问入口。
- 用户明确要求旅店二层为**同一排六个房间**。当前从左到右为伯里、古兰、伊丝娜、妮丝、奥萝拉、爱德，每人一个访问入口。
- 六间房沿同一侧走廊排列，楼梯位于东北端；不画两排房间或上下叠加两层。
- 爱德的实际出现与入住须服从获救、加入和当前状态，不因图上留有房间就预先使其在场。
- 房间归属、队伍身份、落脚地点、实际位置和是否在房分别处理。location=inn 不等于人在卧室。
- 现有 playerRoomTarget 为夜间同住目标，不能当成固定房号；保留原有同住、离店和清晨解除规则。
- 01–06 是当前图面编号，不擅自加入后台地点 ID 或宣称已有完整入住存档。

## 地理与三层地图

- 全域图包含镇子整体、四周散户农夫与田地、镇外山上庄园、敌对兽人前哨。
- 庄园位于安全的西北山上，树林位于东北；河面略宽，保持合理河谷与桥梁关系。
- 西南进镇路线险隘，表现峡口、窄桥与曲折山路。
- 兽人营地位于东南恶劣荒地，以乱石、干裂地表、枯木与稀疏植被区别于农耕区；没有人类道路直通营地。
- 农舍与田地沿镇外四周自然分布，服从地形。
- 全域图的镇子只显示整体边界与少量概括屋顶，不展开具体镇内地标。
- 镇内图对应同一城墙朝向与出入口。西门接庄园方向，西南门接峡口，东门接农田。
- 镇内建筑按相对实际占地绘制，保留庭院、街区空地、菜圃和合理未标注地块，既有地点不占满画面。
- 庄园不画在镇内。地下赌场在镇内只画地面入口，内部另画。
- 旅店、教堂、赌场等内部采用独立的第三层导览；三层控制信息颗粒度，不用一张图连续放大充当三层。
- 已注册地点仍为 inn、town、training_grounds、church、manor、casino、wilds、wilds_camp；珠宝铺、农户和图面房号不擅自新增后台地点键。
- 未有尺寸依据时不标数字比例尺，不把草案尺寸宣称为测绘结果。

## 室内视觉与操作

- 保持西幻古旧羊皮纸、细墨线、少量排线和淡彩。简洁且精致，避免儿童画与密集无用装饰。
- 采用用户选择的“单层斜俯视场景，切换楼层”。同一时刻只显示一层。
- 墙体、楼板、门、家具、楼梯共用统一平行投影；上下层楼梯对应。
- 房门与通道比床位和家具清单重要；不展开逐间床铺矩阵。
- 职业图标背景透明、尺寸克制：地图约 20px，姓名旁 16–18px，角色面板 32px；图标旁保留姓名。
- 伯里使用战士职业图标并在角色面板明确为玩家房间；古兰重剑、伊丝娜双匕、妮丝法杖、奥萝拉圣徽、爱德行囊羽笔。
- 点房门先展开房间与角色，再选行动填入输入框；浏览不改变游戏位置，不自动发送消息，不自动加关系值。
- 玩家房间提供休息、整理行囊等操作；其他住客按已确认的在房、外出或未知状态提供访问、寻找或留言。
- 角色未公开的去向和后台秘密不能直接打点揭露。
- 桌面可点门旁姓名；窄屏使用小图标对应位置与图下姓名入口，保持至少 44px 可点击区域。
- 当前六间预览使用独立演示状态，不把在房演示当成后台事实。
